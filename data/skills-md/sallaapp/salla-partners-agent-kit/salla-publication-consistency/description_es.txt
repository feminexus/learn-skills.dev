Úselo cuando se vaya a revisar una aplicación PÚBLICA de Salla (lista de App Store): la habilidad maestra para la publicación paso a paso a través de app_publish. Lee el borrador actual, dirige cada paso a su propietario y HARD-GATES envía la revisión al administrador detrás de una validación limpia más la confirmación explícita del socio. Las aplicaciones privadas se publican desde el Portal; consulte salla-app-builder. Transferencias: listado/imágenes → salla-app-ui-builder; precios + ciclo de facturación → salla-app-billing; ámbitos → salla-app-auth; webhooks → salla-webhooks; configuración → salla-app-settings.
