Используйте, когда ПУБЛИЧНОЕ приложение Salla собирается просмотреть (листинг App Store): основной навык для поэтапной публикации через app_publish. Он читает текущий черновик, направляет каждый шаг своему владельцу и отправляет HARD-GATES на проверку администратору после чистой проверки и явного подтверждения партнера. Частные приложения публикуются с Портала — см. salla-app-builder. Передача: листинг/изображения → salla-app-ui-builder; ценообразование + биллинговый цикл → salla-app-биллинг; области → salla-app-auth; вебхуки → Салла-вебхуки; настройки → salla-app-settings.
