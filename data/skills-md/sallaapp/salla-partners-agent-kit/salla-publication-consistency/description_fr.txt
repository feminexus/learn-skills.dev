À utiliser lorsqu'une application PUBLIC Salla va être révisée (liste App Store) : la compétence principale pour la publication par étapes via app_publish. Il lit le brouillon actuel, achemine chaque étape vers son propriétaire et HARD-GATES l'envoie à l'administrateur derrière une validation propre et la confirmation explicite du partenaire. Les applications privées sont publiées à partir du portail — voir salla-app-builder. Transferts : listing/images → salla-app-ui-builder ; tarification + cycle de facturation → salla-app-billing ; portées → salla-app-auth ; webhooks → salla-webhooks ; paramètres → paramètres de l'application Salla.
