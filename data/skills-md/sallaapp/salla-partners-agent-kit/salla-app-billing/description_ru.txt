Монетизация приложения Salla: планы и дополнения доступны в разделе цен публикации (без отдельной конечной точки ценообразования), счета за которые выставляет Salla. Используйте при определении цены на приложение, отслеживании состояния плана/дополнения или использовании функций по праву. Отслеживайте состояние по событиям app.subscription.* / app.trial.* (одно семейство — item_type разделяет план и аддон), согласовывайте через salla_apps action=subscriptions, измеряйте использование по балансу. Подписи → salla-webhooks; токены → salla-app-auth; проводка → жизненный цикл salla-app; Пользовательский интерфейс покупки в приложении → salla-addon-purchase / salla-addon-purchase-embedded.
