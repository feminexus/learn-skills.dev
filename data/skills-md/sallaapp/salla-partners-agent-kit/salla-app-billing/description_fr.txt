Monétisation de l'application Salla : les forfaits et les modules complémentaires sont disponibles dans la section de tarification de la publication (pas de point final de tarification distinct), facturés par Salla. À utiliser pour la tarification de l'application, le suivi de l'état du plan/du module complémentaire ou la sélection des fonctionnalités par droit. Suivez l'état des événements app.subscription.* / app.trial.* (une famille — item_type divise le plan par rapport au module complémentaire), rapprochez-vous via salla_apps action=subscriptions, mesurez l'utilisation par rapport au solde. Signatures → salla-webhooks ; jetons → salla-app-auth ; câblage → cycle de vie de l'application salla ; Interface utilisateur d'achat in-app → salla-addon-purchase / salla-addon-purchase-embedded.
