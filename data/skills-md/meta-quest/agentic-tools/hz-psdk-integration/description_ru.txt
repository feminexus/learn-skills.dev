Для 3P/EXTERNAL разработчиков: руководит интерактивной интеграцией Horizon Platform SDK (PSDK) для приложений Meta Quest и Horizon OS Android/Kotlin — анализирует кодовую базу, рекомендует функции общедоступной платформы, планирует интеграцию и проверяет на устройстве. Использует внешнюю цепочку инструментов (Gradle, Metavr, идентификатор приложения Developers.meta.com/Rocksteady). Для 1P-приложений внутри fbsource (buck, Chesterfield/ni, adb) вместо этого используйте psdk_1p_onboarding_agent.
