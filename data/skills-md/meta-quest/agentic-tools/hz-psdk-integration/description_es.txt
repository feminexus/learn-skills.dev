Para desarrolladores 3P/EXTERNOS: guía la integración interactiva de Horizon Platform SDK (PSDK) para aplicaciones Meta Quest y Horizon OS Android/Kotlin: analiza el código base, recomienda funciones de plataforma pública, planifica la integración y valida en el dispositivo. Utiliza la cadena de herramientas externa (Gradle, metavr, un Developers.meta.com/Rocksteady App ID). Para aplicaciones 1P dentro de fbsource (buck, Chesterfield/ni, adb), use psdk_1p_onboarding_agent en su lugar.
