Pour les développeurs 3P/EXTERNES : guide l'intégration interactive du SDK Horizon Platform (PSDK) pour les applications Meta Quest et Horizon OS Android/Kotlin – analyse la base de code, recommande les fonctionnalités de la plate-forme publique, planifie l'intégration et valide sur l'appareil. Utilise la chaîne d'outils externe (Gradle, métavr, un Developers.meta.com / Rocksteady App ID). Pour les applications 1P dans fbsource (buck, Chesterfield/ni, adb), utilisez plutôt psdk_1p_onboarding_agent.
