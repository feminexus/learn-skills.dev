Управляет интеграцией Horizon Platform SDK для приложений Meta Quest и Horizon OS Android/Kotlin — достижения, IAP, пользователи, списки лидеров, присутствие, уведомления, отчеты о злоупотреблениях, права, файлы ресурсов, жизненный цикл приложения, согласие, целостность устройства, языковые пакеты, возрастные категории пользователей, а также оценки и обзоры. Охватывает настройку, инициализацию, использование API, типы данных, обработку ошибок и лучшие практики для всех 17 пакетов SDK общедоступной платформы.
