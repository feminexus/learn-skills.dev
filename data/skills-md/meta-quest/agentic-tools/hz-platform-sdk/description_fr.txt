Guide l'intégration du SDK Horizon Platform pour les applications Meta Quest et Horizon OS Android/Kotlin : réalisations, IAP, utilisateurs, classements, présence, notifications, rapports d'abus, droits, fichiers d'actifs, cycle de vie de l'application, consentement, intégrité de l'appareil, modules linguistiques, catégories d'âge des utilisateurs, ainsi que évaluation et révision. Couvre la configuration, l'initialisation, l'utilisation de l'API, les types de données, la gestion des erreurs et les meilleures pratiques pour les 17 packages SDK de plateforme publique.
