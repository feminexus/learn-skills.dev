Configura e modifica il retargeting Meta Movement SDK (MSDK) per un modello di personaggio. Utilizzalo ogni volta che l'utente desidera eseguire il retargeting di un FBX/prefabbricato umanoide per il tracciamento del corpo di Meta Quest, generare una configurazione di retargeting o modificare manualmente il `<asset>.json` risultante (correggere le mappature dei giunti noti, escludere i giunti dalla mappatura automatica, rinominare i giunti di destinazione, regolare i pesi di mappatura per giunto, modificare un comportamento di mappatura in twist/childAlignedTwist, modificare i valori di posa T). Il punto di ingresso headless è `Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject asset)`: chiamalo prima tramite Unity MCP, quindi modificalo manualmente se necessario. **Salta** se l'utente sta modificando il codice di retargeting runtime, l'origine "OVRSkeletonData.json" o file non MSDK.
