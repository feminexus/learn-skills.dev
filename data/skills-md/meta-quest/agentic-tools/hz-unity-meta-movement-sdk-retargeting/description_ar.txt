قم بإعداد وتعديل إعادة استهداف Meta Movement SDK (MSDK) لنموذج الشخصية. استخدم هذا عندما يريد المستخدم إعادة استهداف FBX/هيكل بشري جاهز لتتبع جسم Meta Quest، أو إنشاء تكوين إعادة استهداف، أو تحرير ملف `<asset>.json` الناتج يدويًا (إصلاح تعيينات المفاصل المعروفة، واستبعاد المفاصل من التعيين التلقائي، وإعادة تسمية المفاصل المستهدفة، وضبط أوزان التعيين لكل مفصل، وتغيير سلوك التعيين إلى تطور/childAlignedTwist، وتحرير قيم T-pose). نقطة الإدخال بدون رأس هي `Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject الأصول)` - اتصل بها عبر Unity MCP أولاً، ثم قم بالتحرير اليدوي إذا لزم الأمر. **تخطي** إذا كان المستخدم يقوم بتحرير تعليمات برمجية لإعادة الاستهداف في وقت التشغيل، أو المصدر `OVRSkeletonData.json`، أو الملفات غير التابعة لـMSDK.
