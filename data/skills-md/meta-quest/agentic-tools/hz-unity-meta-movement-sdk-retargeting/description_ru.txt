Настройте и настройте ретаргетинг Meta Movement SDK (MSDK) для модели персонажа. Используйте это всякий раз, когда пользователь хочет перенацелить гуманоидный FBX/префаб для отслеживания тела Meta Quest, сгенерировать конфигурацию перенацеливания или вручную отредактировать полученный `<asset>.json` (исправить сопоставления известных суставов, исключить суставы из автоматического сопоставления, переименовать целевые суставы, настроить веса сопоставления для каждого сустава, изменить поведение сопоставления на Twist/childAlignedTwist, отредактировать значения T-позы). Безголовая точка входа — `Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject assets)` — сначала вызовите ее через Unity MCP, а затем отредактируйте вручную, если необходимо. **Пропустить**, если пользователь редактирует код ретаргетинга во время выполнения, исходный файл OVRSkeletonData.json или файлы, отличные от MSDK.
