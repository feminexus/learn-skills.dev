為角色模型設定和調整 Meta Movement SDK (MSDK) 重定向。每當使用者想要重新定位人形 FBX/預製件以進行 Meta Quest 身體追蹤、產生重新定位配置或手動編輯產生的「<asset>.json」（修正已知關節映射、從自動映射中排除關節、重命名目標關節、調整每個關節映射權重、將映射行為更改為扭曲/childAlignedTwist、編輯 T 姿勢值），請使用此功能值），請使用此功能。無頭入口點是「Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject asset)」－首先透過 Unity MCP 呼叫它，然後根據需要進行手動編輯。如果使用者正在編輯運行時重定向程式碼、來源「OVRSkeletonData.json」或非 MSDK 文件，則 **跳過**。
