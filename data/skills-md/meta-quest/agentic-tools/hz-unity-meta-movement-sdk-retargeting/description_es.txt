Configure y modifique la reorientación de Meta Movement SDK (MSDK) para un modelo de personaje. Use esto siempre que el usuario quiera redirigir un FBX/prefabricado humanoide para el seguimiento corporal de Meta Quest, generar una configuración de redireccionamiento o editar manualmente el `<asset>.json` resultante (corregir asignaciones de articulaciones conocidas, excluir juntas del mapeo automático, cambiar el nombre de las articulaciones objetivo, ajustar los pesos de mapeo por articulación, cambiar un comportamiento de mapeo a twist/childAlignedTwist, editar valores de pose en T). El punto de entrada sin cabeza es `Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject active)`; primero llámelo a través de Unity MCP y luego edítelo manualmente si es necesario. **Omitir** si el usuario está editando código de retargeting en tiempo de ejecución, el código fuente `OVRSkeletonData.json` o archivos que no sean MSDK.
