为角色模型设置和调整 Meta Movement SDK (MSDK) 重定向。每当用户想要重新定位人形 FBX/预制件以进行 Meta Quest 身体跟踪、生成重新定位配置或手动编辑生成的“<asset>.json”（修复已知关节映射、从自动映射中排除关节、重命名目标关节、调整每个关节映射权重、将映射行为更改为扭曲/childAlignedTwist、编辑 T 姿势值）时，请使用此功能。无头入口点是“Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject asset)”——首先通过 Unity MCP 调用它，然后根据需要进行手动编辑。如果用户正在编辑运行时重定向代码、源“OVRSkeletonData.json”或非 MSDK 文件，则 **跳过**。
