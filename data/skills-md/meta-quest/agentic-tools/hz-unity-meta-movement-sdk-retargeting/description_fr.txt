Configurez et peaufinez le reciblage du Meta Movement SDK (MSDK) pour un modèle de personnage. Utilisez-le chaque fois que l'utilisateur souhaite recibler un FBX/préfabriqué humanoïde pour le suivi du corps Meta Quest, générer une configuration de reciblage ou modifier manuellement le `<asset>.json` résultant (corriger les mappages de joints connus, exclure les joints du mappage automatique, renommer les joints cibles, ajuster les poids de mappage par joint, modifier un comportement de mappage en twist/childAlignedTwist, modifier les valeurs de pose en T). Le point d'entrée sans tête est « Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup (GameObject Asset) » — appelez-le d'abord via Unity MCP, puis modifiez-le manuellement si nécessaire. **Ignorer** si l'utilisateur modifie le code de reciblage d'exécution, la source `OVRSkeletonData.json` ou des fichiers non MSDK.
