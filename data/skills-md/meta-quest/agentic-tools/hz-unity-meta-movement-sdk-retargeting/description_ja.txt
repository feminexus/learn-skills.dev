キャラクター モデルの Meta Movement SDK (MSDK) リターゲットを設定および調整します。ユーザーが Meta Quest ボディ トラッキング用にヒューマノイド FBX/プレハブをリターゲットする場合、リターゲット構成を生成する場合、または結果の `<asset>.json` を手動で編集する場合にこれを使用します (既知のジョイント マッピングの修正、自動マッピングからのジョイントの除外、ターゲット ジョイントの名前変更、ジョイントごとのマッピングのウェイトの調整、ツイスト/チャイルドアラインドツイストへのマッピング動作の変更、T ポーズ値の編集)。ヘッドレス エントリ ポイントは「Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObjectasset)」です。最初に Unity MCP 経由で呼び出してから、必要に応じて手動で編集します。ユーザーがランタイム リターゲット コード、ソース `OVRSkeletonData.json`、または MSDK 以外のファイルを編集している場合は、**スキップ**してください。
