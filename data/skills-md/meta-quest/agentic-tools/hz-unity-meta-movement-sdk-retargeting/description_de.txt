Richten Sie das Meta Movement SDK (MSDK)-Retargeting für ein Charaktermodell ein und optimieren Sie es. Verwenden Sie dies immer dann, wenn der Benutzer ein humanoides FBX/Fertighaus für die Meta Quest-Körperverfolgung neu ausrichten, eine Retargeting-Konfiguration generieren oder die resultierende „<asset>.json“ manuell bearbeiten möchte (Korrektur bekannter Gelenkzuordnungen, Gelenke von der automatischen Zuordnung ausschließen, Zielgelenke umbenennen, Zuordnungsgewichte pro Gelenk anpassen, ein Zuordnungsverhalten in „Twist/childAlignedTwist“ ändern, T-Pose-Werte bearbeiten). Der kopflose Einstiegspunkt ist „Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject asset)“ – rufen Sie ihn zuerst über Unity MCP auf und bearbeiten Sie ihn dann bei Bedarf manuell. **Überspringen**, wenn der Benutzer Laufzeit-Retargeting-Code, die Quelle „OVRSkeletonData.json“ oder Nicht-MSDK-Dateien bearbeitet.
