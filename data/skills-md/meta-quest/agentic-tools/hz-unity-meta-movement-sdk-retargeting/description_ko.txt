캐릭터 모델에 대한 MSDK(Meta Movement SDK) 재타겟팅을 설정하고 조정합니다. 사용자가 Meta Quest 신체 추적을 위해 휴머노이드 FBX/프리팹의 대상을 변경하거나, 대상 변경 구성을 생성하거나, 결과 `<asset>.json`을 직접 편집하려고 할 때마다 이 기능을 사용합니다(알려진 관절 매핑 수정, 자동 매핑에서 관절 제외, 대상 관절 이름 바꾸기, 관절당 매핑 가중치 조정, 매핑 동작을 Twist/childAlignedTwist로 변경, T 포즈 값 편집). 헤드리스 진입점은 `Meta.XR.Movement.Editor.MSDKUtilityEditor.RunDefaultRetargetingSetup(GameObject 자산)`입니다. 먼저 Unity MCP를 통해 호출한 다음 필요한 경우 직접 편집하세요. **건너뛰기** 사용자가 런타임 대상 변경 코드, 소스 `OVRSkeletonData.json` 또는 비MSDK 파일을 편집하는 경우.
