Предоставляет полный справочник по метавру (Meta VR CLI) для разработки ОС Meta Quest и Horizon — установка, настройка устройства, обнаружение команд, режим сервера MCP, поиск документации, развертывание приложений, настройка тестирования устройств, управление звуком, снимки экрана и анализ производительности. Используйте, когда пользователю необходимо установить Metavr, он спрашивает, какие команды доступны, ему нужна помощь по синтаксису CLI или он хочет узнать, что может сделать Metavr.
