Proporciona la referencia completa de metavr (Meta VR CLI) para el desarrollo de Meta Quest y Horizon OS: instalación, configuración de dispositivos, descubrimiento de comandos, modo de servidor MCP, búsqueda de documentación, implementación de aplicaciones, configuración de pruebas de dispositivos, control de audio, capturas de pantalla y análisis de rendimiento. Úselo cuando el usuario necesite instalar metavr, pregunte qué comandos están disponibles, necesite ayuda de sintaxis CLI o quiera saber qué puede hacer metavr.
