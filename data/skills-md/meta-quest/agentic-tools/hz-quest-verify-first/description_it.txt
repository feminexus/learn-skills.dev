Controllo pre-volo OBBLIGATORIO prima di rispondere a qualsiasi domanda o scrivere qualsiasi codice relativo ai visori Meta Quest VR (Quest 2, Quest 3, Quest 3S, Quest Pro) o alle app destinate ad essi. Forza la verifica rispetto a fonti Meta autorevoli tramite gli strumenti metavr CLI/metavr MCP PRIMA di fare affidamento sulla conoscenza dei dati di training. Contrasta la modalità di errore in cui gli agenti rispondono a domande relative a Quest dalla memoria obsoleta e forniscono API deprecate, manifest Android non funzionanti e build rifiutate dallo store. Si carica automaticamente quando l'utente si trova in un progetto Quest (qualsiasi riferimento a pacchetti Oculus/Meta Quest/Horizon OS, Unity OVR o Meta XR, ID pacchetto com.meta.*/com.oculus.*, AndroidManifest mirato a Quest, file .meta o URL sviluppatori.meta.com/developer.oculus.com).
