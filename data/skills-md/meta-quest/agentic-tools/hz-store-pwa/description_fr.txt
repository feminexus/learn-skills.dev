Guide l'expédition d'une application Web vers Meta Quest et Horizon OS Store en tant que PWA/TWA — à la fois des panneaux fenêtrés 2D et des WebXR/VR immersifs. Couvre la création de l'application Web (IWSDK pour WebXR, toute PWA réactive pour 2D), le déploiement de Vercel, le manifeste de l'application Web + les icônes, l'étape d'entrée automatique de session WebXR uniquement, le choix du mode 2D ou immersif dans @meta-quest/bubblewrap-cli, keystore/Digital-Asset-Links et le téléchargement du magasin ovr-platform-util. À utiliser avant tout travail de build IWSDK/WebXR, d'empaquetage PWA, de papier bulle ou de téléchargement Horizon Store.
