Meta Quest Passthrough Camera Access (PCA) für Unity – greifen Sie auf die nach vorne gerichteten RGB-Kameras auf Quest 3 / Quest 3S zu, um Computer Vision- und Machine Learning-Pipelines zu versorgen. Wird verwendet, wenn Sie das Bild/die Textur der Passthrough-Kamera erfassen, die Kameraposition und ihre Eigenschaften lesen, Kamerapixel über „PassthroughCameraAccess.ViewportPointToRay“ in den Weltraum projizieren, Kamerarahmen mit ML/CV-Modellen verbinden oder Überlegungen zu Auflösung, Berechtigungen, Hersteller-Tags und dem Lochblenden-/Hauptpunktmodell anstellen. Informationen zum Projizieren des Bildes auf eine flache Weltraumoberfläche (Frustum-Slice-Quad / Bildebenen-Overlay) finden Sie unter references/principal-point-offset.md; Informationen zum Platzieren von 2D-ML-Erkennungen als weltraumbezogene 3D-Begrenzungsrahmen finden Sie unter references/detection-bounding-boxes.md. Überspringen Sie, wenn der Benutzer nur den POV des Benutzers umwandeln möchte (verwenden Sie stattdessen die Media Projection API) oder Overlays nur für den Bildschirmbereich erstellt.
