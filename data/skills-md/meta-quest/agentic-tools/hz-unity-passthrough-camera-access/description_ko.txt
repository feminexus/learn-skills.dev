Unity용 Meta Quest PCA(패스스루 카메라 액세스) — Quest 3/Quest 3S의 전방 RGB 카메라에 액세스하여 컴퓨터 비전 및 머신 러닝 파이프라인을 제공합니다. 패스스루 카메라 이미지/텍스처 캡처, 카메라 포즈 및 내장 기능 읽기, `PassthroughCameraAccess.ViewportPointToRay`를 통해 카메라 픽셀을 월드 공간에 투영, 카메라 프레임을 ML/CV 모델에 연결 또는 해상도, 권한, 공급업체 태그 및 핀홀/주요점 모델에 대한 추론에 사용합니다. 이미지를 평평한 월드 공간 표면(절두체-슬라이스 쿼드/이미지-평면 오버레이)에 투영하려면 reference/principal-point-offset.md를 참조하세요. 2D ML 감지를 월드 공간 3D 경계 상자로 배치하려면 reference/Detection-bounding-boxes.md를 참조하세요. 사용자가 사용자의 POV만 전송하기를 원하거나(대신 Media Projection API 사용) 화면 공간 전용 오버레이를 수행하는 경우 건너뜁니다.
