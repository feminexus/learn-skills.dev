适用于 Unity 的 Meta Quest 直通摄像头访问 (PCA) — 访问 Quest 3 / Quest 3S 上的前置 RGB 摄像头，为计算机视觉和机器学习管道提供数据。在捕获直通相机图像/纹理、读取相机姿势和内在特性、通过“PassthroughCameraAccess.ViewportPointToRay”将相机像素投影到世界空间、将相机框架连接到 ML/CV 模型或推理分辨率、权限、供应商标签和针孔/主点模型时使用。要将图像投影到平坦的世界空间表面（视锥体切片四边形/图像平面覆盖），请参阅引用/principal-point-offset.md；有关将 2D ML 检测放置为世界空间 3D 边界框的信息，请参阅references/detection-bounding-boxes.md。如果用户只想投射用户的 POV（改为使用媒体投影 API）或正在进行仅屏幕空间覆盖，请跳过。
