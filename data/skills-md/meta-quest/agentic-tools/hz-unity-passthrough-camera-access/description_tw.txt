適用於 Unity 的 Meta Quest 直通相機存取 (PCA) — 存取 Quest 3 / Quest 3S 上的前置 RGB 相機，為電腦視覺和機器學習管道提供資料。在捕捉直通相機影像/紋理、讀取相機姿勢和內在特性、透過「PassthroughCameraAccess.ViewportPointToRay」將相機像素投影到世界空間、將相機框架連接到 ML/CV 模型或推理解析度、權限、供應商標籤和針孔/主點模型時使用。要將影像投影到平坦的世界空間表面（視錐體切片四邊形/影像平面覆蓋），請參閱引用/principal-point-offset.md；有關將 2D ML 檢測放置為世界空間 3D 邊界框的信息，請參閱references/detection-bounding-boxes.md。如果使用者只想投射使用者的 POV（改為使用媒體投影 API）或正在進行僅螢幕空間覆蓋，請跳過。
