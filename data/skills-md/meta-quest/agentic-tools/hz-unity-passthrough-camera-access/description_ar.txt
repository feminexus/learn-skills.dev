Meta Quest Passthrough Camera Access (PCA) لـ Unity - يمكنك الوصول إلى كاميرات RGB الأمامية في Quest 3 / Quest 3S لتغذية مسارات رؤية الكمبيوتر والتعلم الآلي. يُستخدم عند التقاط صورة/نسيج كاميرا العبور، أو قراءة وضعية الكاميرا وجوهرها، أو عرض وحدات بكسل الكاميرا في الفضاء العالمي عبر "PassthroughCameraAccess.ViewportPointToRay"، أو توصيل إطارات الكاميرا إلى نماذج ML/CV، أو التفكير في الدقة والأذونات وعلامات البائع ونموذج الثقب/النقطة الرئيسية. لعرض الصورة على سطح فضاء عالمي مسطح (شرائح رباعية / تراكب مستوى الصورة) راجع المراجع/principal-point-offset.md؛ لوضع اكتشافات ML ثنائية الأبعاد كمربعات محيطة ثلاثية الأبعاد للفضاء العالمي، راجع المراجع/detection-bounding-boxes.md. قم بالتخطي إذا كان المستخدم يريد فقط إرسال وجهة نظر المستخدم (استخدم Media Projection API بدلاً من ذلك) أو إذا كان يقوم بتراكبات مساحة الشاشة فقط.
