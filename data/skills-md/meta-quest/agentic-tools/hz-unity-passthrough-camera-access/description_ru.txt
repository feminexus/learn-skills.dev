Доступ к камере Meta Quest Passthrough (PCA) для Unity — доступ к передним камерам RGB на Quest 3 / Quest 3S для передачи данных в конвейеры компьютерного зрения и машинного обучения. Используйте при захвате изображения/текстуры сквозной камеры, чтении позы и встроенных характеристик камеры, проецировании пикселей камеры в мировое пространство с помощью PassthroughCameraAccess.ViewportPointToRay, подключении кадров камеры к моделям ML/CV или рассуждениях о разрешении, разрешениях, тегах поставщика и модели точечной/основной точки. Для проецирования изображения на плоскую поверхность мирового пространства (квадрат усеченного среза / наложение плоскости изображения) см. ссылки/principal-point-offset.md; для размещения обнаружений 2D ML в виде 3D-ограничивающих рамок мирового пространства см. ссылки/detection-bounding-boxes.md. Пропустите, если пользователь хочет транслировать только точку зрения пользователя (вместо этого используйте API Media Projection) или выполняет наложение только на экранное пространство.
