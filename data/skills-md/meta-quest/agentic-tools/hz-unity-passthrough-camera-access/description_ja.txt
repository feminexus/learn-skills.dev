Unity 用 Meta Quest パススルー カメラ アクセス (PCA) — Quest 3 / Quest 3S の前向き RGB カメラにアクセスして、コンピューター ビジョンと機械学習のパイプラインにフィードします。パススルー カメラの画像/テクスチャをキャプチャする場合、カメラのポーズと内部関数を読み取る場合、「PassthroughCameraAccess.ViewportPointToRay」を介してカメラ ピクセルをワールド空間に投影する場合、カメラ フレームを ML/CV モデルに配線する場合、または解像度、権限、ベンダー タグ、およびピンホール/主点モデルについて推論する場合に使用します。平坦なワールド空間表面 (錐台スライス クワッド / イメージプレーン オーバーレイ) にイメージを投影する場合は、references/principal-point-offset.md を参照してください。 2D ML 検出をワールド空間 3D バウンディング ボックスとして配置する場合は、references/detection-bounding-boxes.md を参照してください。ユーザーがユーザーの POV をキャストするだけの場合 (代わりに Media Projection API を使用する)、または画面スペースのみのオーバーレイを実行している場合はスキップします。
