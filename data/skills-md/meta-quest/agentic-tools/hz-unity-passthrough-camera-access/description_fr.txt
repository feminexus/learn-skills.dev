Meta Quest Passthrough Camera Access (PCA) pour Unity : accédez aux caméras RVB orientées vers l'avant sur Quest 3 / Quest 3S pour alimenter les pipelines de vision par ordinateur et d'apprentissage automatique. À utiliser pour capturer l'image/texture de la caméra passthrough, lire la pose et les éléments intrinsèques de la caméra, projeter les pixels de la caméra dans l'espace mondial via `PassthroughCameraAccess.ViewportPointToRay`, câbler les cadres de la caméra dans des modèles ML/CV ou raisonner sur la résolution, les autorisations, les balises du fournisseur et le modèle sténopé/point principal. Pour projeter l'image sur une surface plate de l'espace mondial (quad de coupe tronconique / superposition de plan d'image), voir references/principal-point-offset.md ; pour placer les détections ML 2D en tant que cadres de délimitation 3D dans l'espace mondial, voir references/detection-bounding-boxes.md. Ignorer si l'utilisateur souhaite uniquement diffuser son point de vue (utilisez plutôt l'API Media Projection) ou s'il effectue des superpositions sur l'espace d'écran uniquement.
