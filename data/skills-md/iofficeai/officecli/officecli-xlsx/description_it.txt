Utilizza questa abilità ogni volta che è coinvolto un file .xlsx: come input, output o entrambi. Ciò include: creazione di fogli di calcolo, modelli finanziari, dashboard o tracker; leggere, analizzare o estrarre dati da qualsiasi file .xlsx; modificare, modificare o aggiornare cartelle di lavoro esistenti; lavorare con formule, grafici, tabelle pivot o modelli; importare dati CSV/TSV in formato Excel. Si attiva ogni volta che l'utente menziona "foglio di calcolo", "cartella di lavoro", "Excel", "modello finanziario", "tracker", "dashboard" o fa riferimento a un nome file .xlsx/.csv.
