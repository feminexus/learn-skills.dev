Code de conduite que les contributeurs – y compris les assistants de codage IA – DOIVENT suivre lors de l'écriture, de la modification ou de la révision du code de tout module du kit de développement de portefeuille Tether (WDK) (portefeuilles, protocoles, noyau). Couvre le flux de travail du projet (demandes d'extraction atomiques à fonctionnalité unique, spécifications de conception avant implémentation), la qualité du code (éviter les odeurs de code, ne jamais violer les principes SOLID, documenter chaque composant public/protégé, utiliser des types étroits, éviter la programmation défensive, marquer chaque erreur générée avec @throws) et les tests (organiser-agir-affirmer, tester uniquement l'API publique, affirmer des valeurs réelles et non des modèles, définir des plaisanteries au niveau supérieur, se moquer de toutes les dépendances de services externes).
