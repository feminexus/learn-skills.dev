Кодекс поведения, которому ДОЛЖНЫ следовать участники, в том числе помощники по программированию на базе искусственного интеллекта, при написании, изменении или проверке кода для любого модуля Tether Wallet Development Kit (WDK) (кошельки, протоколы, ядро). Охватывает рабочий процесс проекта (атомарные запросы на извлечение одной функции, спецификации проектирования перед реализацией), качество кода (избегайте запахов кода, никогда не нарушайте принципы S.O.L.I.D., документируйте каждый общедоступный/защищенный компонент, используйте узкие типы, избегайте защитного программирования, отмечайте каждую возникающую ошибку с помощью @throws) и тестирование (организуйте-действуйте-утверждайте, тестируйте только общедоступный API, утверждайте реальные значения, а не шаблоны, определяйте шуточные макеты на верхнем уровне, имитируйте все зависимости от внешних сервисов).
