Código de conducta que los contribuyentes, incluidos los asistentes de codificación de IA, DEBEN seguir al escribir, modificar o revisar el código de cualquier módulo del Tether Wallet Development Kit (WDK) (billeteras, protocolos, núcleo). Cubre el flujo de trabajo del proyecto (solicitudes de extracción atómicas de una sola característica, especificaciones de diseño antes de la implementación), calidad del código (evite olores de código, nunca viole los principios S.O.L.I.D., documente cada componente público/protegido, use tipos restringidos, evite la programación defensiva, marque cada error arrojado con @throws) y pruebas (organizar-afirmar-afirmar, probar solo la API pública, afirmar valores reales, no patrones, definir simulacros de broma en el nivel superior, burlarse de todas las dependencias de servicios externos).
