Verhaltenskodex, den Mitwirkende – einschließlich KI-Codierungsassistenten – befolgen MÜSSEN, wenn sie Code für ein Tether Wallet Development Kit (WDK)-Modul (Wallets, Protokolle, Kern) schreiben, ändern oder überprüfen. Behandelt den Projektworkflow (atomare Single-Feature-Pull-Requests, Design-vor-Implementierungs-Spezifikationen), Codequalität (Code-Gerüche vermeiden, niemals S.O.L.I.D.-Prinzipien verletzen, jede öffentliche/geschützte Komponente dokumentieren, enge Typen verwenden, defensive Programmierung vermeiden, jeden ausgelösten Fehler mit @throws markieren) und Tests (arrange-act-assert, nur die öffentliche API testen, echte Werte und keine Muster behaupten, Scherz-Mocks auf der obersten Ebene definieren, alle Abhängigkeiten von externen Diensten simulieren).
