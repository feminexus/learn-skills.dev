Безопасно записывайте, выполняйте и утверждайте HTTP-запросы, используя текстовые файлы Hurl. Срабатывает при тестировании API, генерации HTTP-запроса, проверке REST/GraphQL или при упоминании файлов .hurl. НЕ используйте этот навык для тестирования пользовательского интерфейса/браузера или для внутреннего модульного тестирования.
