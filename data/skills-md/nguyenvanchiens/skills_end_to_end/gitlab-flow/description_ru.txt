Стандартный комплексный рабочий процесс для доставки функции/исправления ошибки из задачи Jira в объединенный GitLab MR. Используйте, когда пользователь ссылается на идентификатор задачи Jira (WRA-XX и т. д.), просит «запустить задачу», «создать ветку из задачи», «переименовать ветку», «просмотреть последнее изменение» / «просмотреть изменение» (необязательно с ключевым словом «упростить», например «просмотреть изменение упрощенно», для автоматической очистки перед проверкой), «просмотреть всю ветку», «зафиксировать и отправить», «создать запрос на слияние», «просмотреть MR !N», «отправить результат проверки в MR», «исправить все проблемы» или «объединить запрос».
