Betreiben Sie ein von Treasures delegiertes Wallet über die HTTP-API: Onboarding (Bereitstellen eines Wallets + Prägen eines bereichsbezogenen API-Schlüssels), Einholen von Angeboten, Ausführen von Käufen/Verkäufen (asynchron – das Wallet ist nicht verwahrt; der Agent unterschreibt NIEMALS, Treasures unterschreibt als delegierter Unterzeichner, der ausschließlich auf RWA-Geschäfte beschränkt ist), Salden/Portfolio/Handelsverlauf lesen und API-Schlüssel verwalten. Wird immer dann ausgelöst, wenn ein Agent tokenisierte Aktien (xStocks/Ondo) gegen USDC auf einer Treasures-Wallet handeln, den Saldo oder die Gewinn- und Verlustrechnung einer Treasures-Wallet überprüfen oder den Zugriff auf die Treasures-Wallet einrichten muss. Der Agent benötigt nur HTTPS + einen API-Schlüssel – keine Web3-Bibliotheken, keine privaten Schlüssel, kein RPC.
