قم بتشغيل محفظة Treasures المفوضة عبر واجهة برمجة تطبيقات HTTP: على متن الطائرة (توفير محفظة + سك مفتاح API محدد النطاق)، والحصول على عروض الأسعار، وتنفيذ عمليات الشراء/البيع (غير متزامن - المحفظة غير وصاية؛ لا يوقع الوكيل أبدًا، وتوقع الكنوز كموقع مفوض يتم تحديد نطاقه بدقة لصفقات RWA)، وقراءة الأرصدة/المحفظة/سجل التجارة، وإدارة مفاتيح واجهة برمجة التطبيقات. يتم تفعيله عندما يحتاج الوكيل إلى تداول الأسهم المرمزة (xStocks / Ondo) مقابل USDC على محفظة Treasures، أو التحقق من رصيد محفظة Treasures أو الربح والخسارة، أو إعداد الوصول إلى محفظة Treasures. يحتاج الوكيل فقط إلى HTTPS + مفتاح API - لا مكتبات web3، ولا مفاتيح خاصة، ولا RPC.
