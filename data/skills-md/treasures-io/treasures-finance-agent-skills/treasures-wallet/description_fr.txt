Gérez un portefeuille délégué Treasures via l'API HTTP : intégré (fournir un portefeuille + créer une clé API limitée), obtenir des devis, exécuter des achats/ventes (asynchrone : le portefeuille n'est pas dépositaire ; l'agent ne signe JAMAIS, Treasures signe en tant que signataire délégué limité strictement aux transactions RWA), lire les soldes/portefeuille/historique des échanges et gérer les clés API. Déclenchez-le chaque fois qu'un agent a besoin d'échanger des actions tokenisées (xStocks / Ondo) contre USDC sur un portefeuille Treasures, de vérifier le solde ou le P&L d'un portefeuille Treasures, ou de configurer l'accès au portefeuille Treasures. L'agent n'a besoin que de HTTPS + une clé API : pas de bibliothèques web3, pas de clés privées, pas de RPC.
