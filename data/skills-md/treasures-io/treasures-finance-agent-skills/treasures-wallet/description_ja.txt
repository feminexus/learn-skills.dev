Treasures の委任ウォレットを HTTP API 経由で操作します: オンボード (ウォレットのプロビジョニング + スコープ付き API キーのミント)、相場の取得、売買の実行 (非同期 - ウォレットは保管されていません。エージェントは決して署名しません。Treasures は厳密に RWA 取引を対象とした委任署名者として署名します)、残高/ポートフォリオ/取引履歴の読み取り、API キーの管理。エージェントが Treasures ウォレットでトークン化された株式 (xStocks / Ondo) と USDC を取引する必要がある場合、Treasures ウォレットの残高または損益を確認する場合、または Treasures ウォレットへのアクセスを設定する必要がある場合にトリガーします。エージェントに必要なのは HTTPS + API キーのみです。Web3 ライブラリ、秘密キー、RPC は必要ありません。
