Opere una billetera delegada de Treasures a través de la API HTTP: a bordo (proporcione una billetera + genere una clave API con alcance), obtenga cotizaciones, ejecute compras/ventas (asíncrono: la billetera no tiene custodia; el agente NUNCA firma, Treasures firma como un firmante delegado con alcance estrictamente para operaciones RWA), lea saldos/cartera/historial comercial y administre claves API. Se activa cada vez que un agente necesita negociar acciones tokenizadas (xStocks / Ondo) frente a USDC en una billetera Treasures, verificar el saldo de una billetera Treasures o P&L, o configurar el acceso a la billetera Treasures. El agente solo necesita HTTPS + una clave API: sin bibliotecas web3, sin claves privadas, sin RPC.
