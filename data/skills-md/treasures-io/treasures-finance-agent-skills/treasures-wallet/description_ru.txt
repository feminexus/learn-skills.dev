Управляйте делегированным кошельком Treasures через HTTP API: встроенный (предоставьте кошелек + создайте ограниченный ключ API), получайте котировки, выполняйте покупки/продажи (асинхронно — кошелек не является кастодиальным; агент НИКОГДА не подписывает, Treasures подписывает как делегированное подписывающее лицо, ограниченное исключительно сделками RWA), считывает балансы/портфель/торговую историю и управляет ключами API. Запускается, когда агенту необходимо торговать токенизированными акциями (xStocks / Ondo) и USDC в кошельке Treasures, проверить баланс кошелька Treasures или прибыли и убытки или настроить доступ к кошельку Treasures. Агенту нужен только HTTPS + ключ API — никаких библиотек Web3, приватных ключей и RPC.
