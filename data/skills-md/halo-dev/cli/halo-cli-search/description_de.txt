Verwenden Sie diese Option, wenn Sie öffentliche Inhalte auf einer Halo-Site mit Halo CLI durchsuchen. Dazu gehören Stichwortsuche, Website-URL-basierte Suche, Ergebnisbeschränkungen oder jede Suche, die keinen authentifizierten Konsolenzugriff erfordert. Lösen Sie diesen Skill immer dann aus, wenn der Benutzer vom Terminal aus eine Halo-Site durchsuchen möchte, auch wenn er „Suchen“ nicht ausdrücklich erwähnt.
