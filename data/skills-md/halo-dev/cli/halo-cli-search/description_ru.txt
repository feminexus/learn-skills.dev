Используйте при поиске общедоступного контента на сайте Halo с помощью Halo CLI. Сюда входит поиск по ключевым словам, поиск по URL-адресу сайта, ограничения результатов или любой поиск, не требующий доступа к консоли с аутентификацией. Активируйте этот навык всякий раз, когда пользователь хочет выполнить поиск на сайте Halo с терминала, даже если он явно не упоминает «поиск».
