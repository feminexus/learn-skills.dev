À utiliser lorsqu'une tâche implique Halo CLI, des opérations de ligne de commande Halo CMS ou une gestion Halo basée sur un terminal. À utiliser également lorsque vous avez besoin de règles partagées pour les profils, la sortie JSON, la découverte d'aide, les chemins de configuration et les actions destructrices. Déclenchez cette compétence chaque fois que l'utilisateur mentionne « halo », « Halo CLI » ou des opérations de terminal pour Halo CMS, même si la zone de commande spécifique n'est pas encore claire.
