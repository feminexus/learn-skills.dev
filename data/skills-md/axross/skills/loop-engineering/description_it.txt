La capacità di guidare un'unità di lavoro (un problema di GitHub, una richiesta pull o una richiesta in formato libero) dall'assunzione a una richiesta pull pronta per la revisione in una sessione continua, attraverso il "loop" di modifica dell'ingegneria del software end-to-end. Copre il modello di esecuzione (avanzare autonomamente all'interno di una fase, fermare il turno per gli esseri umani), i cancelli di chiarimento prima della costruzione e di approvazione obbligatoria del piano, l'implementazione e la verifica su un ramo con spazio dei nomi dell'agente, la richiesta di una revisione indipendente separata e l'indirizzo dei risultati e dell'IC alla convergenza. Autonomo; presuppone un cablaggio Claude Code + GitHub MCP.
