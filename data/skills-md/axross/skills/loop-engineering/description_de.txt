Die Fähigkeit, eine Arbeitseinheit – ein GitHub-Problem, eine Pull-Anfrage oder eine Freiform-Anfrage – in einer fortlaufenden Sitzung von der Aufnahme bis zu einer überprüfungsbereiten Pull-Anfrage durch die End-to-End-Änderungsschleife der Softwareentwicklung zu leiten. Behandelt das Ausführungsmodell (autonom innerhalb einer Phase voranschreiten, die Wende für Menschen stoppen), die Gates „Klärung vor dem Erstellen“ und obligatorische Plangenehmigung, die Implementierung und Überprüfung auf einem Agent-Namespace-Zweig, die Anforderung einer separaten unabhängigen Überprüfung und die Behandlung seiner Ergebnisse und CI zur Konvergenz. Eigenständig; geht von einem Claude Code + GitHub MCP-Harness aus.
