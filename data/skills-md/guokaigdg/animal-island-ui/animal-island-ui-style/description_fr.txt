Créez des interfaces utilisateur React dans le style animal-island-ui – une bibliothèque de composants inspirée d'Animal Crossing (tons chauds de la terre, formes de pilules, profondeur des boutons de jeu 3D, mouvement doux). À utiliser lors de (1) la création de pages ou de composants avec le package npm animal-island-ui dans un projet React ; (2) générer une page HTML autonome à fichier unique dans ce style sans étape de construction ; (3) l'utilisateur demande un "style Animal Crossing", un "style animal island" ou une interface utilisateur arrondie et confortable semblable à un jeu.
