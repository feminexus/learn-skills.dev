Cree interfaces de usuario de React en el estilo animal-island-ui: una biblioteca de componentes inspirada en Animal Crossing (tonos tierra cálidos, formas de píldoras, profundidad de botones de juegos en 3D, movimiento suave). Úselo cuando (1) cree páginas o componentes con el paquete npm animal-island-ui en un proyecto de React; (2) generar una página HTML independiente de un solo archivo con este estilo sin ningún paso de compilación; (3) el usuario solicita "estilo Animal Crossing", "estilo isla animal" o una interfaz de usuario acogedora y redondeada similar a un juego.
