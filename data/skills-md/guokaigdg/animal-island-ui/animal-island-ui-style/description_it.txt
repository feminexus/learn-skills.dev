Costruisci interfacce utente React in stile isola-animali: una libreria di componenti ispirata a Animal Crossing (caldi toni della terra, forme di pillole, profondità dei pulsanti di gioco 3D, movimento morbido). Da utilizzare quando (1) si creano pagine o componenti con il pacchetto Animal-Island-ui npm in un progetto React; (2) generare una pagina HTML a file singolo autonoma in questo stile senza alcuna fase di creazione; (3) l'utente richiede "stile Animal Crossing", "stile isola degli animali" o un'interfaccia utente accogliente e arrotondata simile a un gioco.
