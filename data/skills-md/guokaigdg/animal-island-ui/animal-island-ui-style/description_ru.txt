Создавайте пользовательские интерфейсы React в стиле Animal-Island-UI — библиотеке компонентов, вдохновленной Animal Crossing (теплые землистые тона, формы таблеток, глубина трехмерных игровых кнопок, мягкое движение). Используйте при (1) создании страниц или компонентов с помощью npm-пакета Animal-Island-UI в проекте React; (2) создание отдельной однофайловой HTML-страницы в этом стиле без этапа сборки; (3) пользователь запрашивает «стиль Animal Crossing», «стиль острова животных» или уютный округлый игровой интерфейс.
