Erstellen Sie React-Benutzeroberflächen im Animal-Island-UI-Stil – eine von Animal Crossing inspirierte Komponentenbibliothek (warme Erdtöne, Pillenformen, 3D-Spieltastentiefe, sanfte Bewegung). Wird verwendet, wenn (1) Seiten oder Komponenten mit dem npm-Paket animal-island-ui in einem React-Projekt erstellt werden; (2) Generieren einer eigenständigen Einzeldatei-HTML-Seite in diesem Stil ohne Build-Schritt; (3) Der Benutzer fragt nach „Animal Crossing-Stil“, „Animal Island-Stil“ oder einer gemütlichen, abgerundeten, spielähnlichen Benutzeroberfläche.
