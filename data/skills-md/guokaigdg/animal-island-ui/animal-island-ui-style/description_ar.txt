أنشئ واجهات مستخدم React بأسلوب واجهة المستخدم لجزيرة الحيوانات - مكتبة مكونات مستوحاة من Animal Crossing (ألوان ترابية دافئة، وأشكال حبوب منع الحمل، وعمق أزرار اللعبة ثلاثية الأبعاد، وحركة ناعمة). تُستخدم عند (1) إنشاء صفحات أو مكونات باستخدام حزمة Animal-island-ui npm في مشروع React؛ (2) إنشاء صفحة HTML مستقلة بملف واحد بهذا النمط بدون خطوة إنشاء؛ (3) يسأل المستخدم عن "أسلوب Animal Crossing" أو "نمط جزيرة الحيوان" أو واجهة مستخدم مريحة تشبه اللعبة.
