Animal-Island-UI スタイルで React UI を構築します。これは、Animal Crossing にインスピレーションを得たコンポーネント ライブラリ (温かみのあるアースカラー、錠剤の形状、3D ゲームボタンの深さ、ソフトな動き) です。 (1) React プロジェクトでanimal-island-ui npm パッケージを使用してページまたはコンポーネントを構築する場合に使用します。 (2) ビルドステップを行わずに、このスタイルでスタンドアロンの単一ファイルの HTML ページを生成します。 (3) ユーザーは「どうぶつの森風」、「どうぶつ島風」、または丸みを帯びたゲーム風の心地よい UI を要求します。
