Создает или обновляет частный локальный веб-сайт Coding Wrapped на основе истории сеансов Claude Code и Codex. Используйте для Coding Wrapped, интересных фактов об агенте кодирования, анализа поведения AI-кодирования, личной информационной панели кодирования на локальном хосте, новых карточек с информацией или экспорта существующего Wrapped. Сканирует локально, исключает необработанные расшифровки из сгенерированного состояния и создает один язык с совокупными показателями, обзором кодирования и четырьмя иллюстрированными сведениями за раз.
