إنشاء أو تحديث موقع ويب خاص بـ Coding Wrapped من Claude Code وسجل جلسات Codex. يُستخدم لـ Coding Wrapped، أو الحقائق الممتعة لعامل الترميز، أو رؤى سلوك ترميز الذكاء الاصطناعي، أو لوحة معلومات ترميز المضيف المحلي الشخصية، أو بطاقات الرؤى الجديدة، أو تصدير ملف مغلف موجود. يقوم بالمسح محليًا، ويستبعد النصوص الأولية من الحالة التي تم إنشاؤها، وينتج لغة واحدة بمقاييس مجمعة، ونظرة عامة على الترميز، وأربعة رؤى مصورة في كل مرة.
