Richten Sie die Überwachung der Critical User Journey (CUJ) in Bitdrift ein. Stellt einen vollständigen Observability-Stack bereit: Pfaderkennung (Sankey), Conversion-Trichter, Abschlussrate-SLO, Benachrichtigung über die Dauer wichtiger Schritte, Sitzungserfassung und ein Dashboard mit zwei Registerkarten. Wird ausgelöst, wenn ein Benutzer eine Reise durchgängig überwachen, Konversionen und Abbrüche verfolgen, die Schrittdauer messen oder SLOs für einen geschäftskritischen Ablauf wie Checkout, Onboarding, Anmeldung oder Suche einrichten möchte.
