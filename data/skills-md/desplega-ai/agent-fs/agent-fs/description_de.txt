Verwenden Sie diese Option, wenn der Benutzer Dateien in agent-fs speichern, abrufen, durchsuchen oder verwalten möchte – einem Agent-First-Dateisystem, das von S3 unterstützt wird. Wird ausgelöst bei: „Speichern Sie dies in Agent-FS“, „finden Sie diese Datei“, „Speichern Sie dieses Dokument“, „Suchen Sie Agent-FS“, „Listen Sie meine Dateien auf“, „Anzeigen des Versionsverlaufs“, „Zurücksetzen der Datei“, „Setzen Sie Agent-FS ein“, „holen Sie sich eine signierte URL“, „teilen Sie diese Datei“, „Mitglieder verwalten“, „Benutzer einladen“, „Mitglieder auflisten“, „Mitglied entfernen“, „Aktualisieren Sie die Rolle“, Dateipersistenz für Agenten, gemeinsames Agent-Dateisystem oder jede Erwähnung der Agent-FS-CLI. Verwenden Sie es auch, wenn der Benutzer Laufwerke verwalten, Organisations-/Laufwerksmitglieder verwalten, vorsignierte URLs generieren, aktuelle Aktivitäten überprüfen oder eine semantische Suche in gespeicherten Dateien verwenden muss. Wird auch verwendet, wenn der Benutzer SQL über gespeicherte Datendateien ausführen möchte („diese CSV abfragen“, „sql über meine Dateien“, „duckdb“, „die Parkettdatei aggregieren“, „die SQLite-Datenbank abfragen“, „diese Tabellen verknüpfen“). Wird auch verwendet, wenn der Benutzer agent-fs als Linux-FUSE-Dateisystem mounten oder unmounten möchte („Agent-FS mounten“, „Fuse Mount“, „Fuse“, „Remote-Mount“, „Sandbox-Mount“, „Laufwerke als Dateien verfügbar machen“, „cat/grep/mv für meine Agent-FS-Dateien verwenden“, „Laufwerk umounten“, „ein Remote-Laufwerk mounten“, „von Sprite mounten“, „von e2b mounten“, „von Hetzner mounten“). Wird auch verwendet, wenn der Benutzer agent-fs als Just-Bash-Dateisystem verwenden möchte. Auch verwenden, wenn der Benutzer agent-fs ohne Docker oder S3 einrichten möchte („lokales Dateisystem-Backend“, „Dateisystemspeicher“, „kein Docker“, „onboard --filesystem“, „Dateien auf Festplatte speichern“). Wenn der Benutzer agent-fs in irgendeinem Kontext erwähnt, ziehen Sie immer diesen Skill zu Rate.
