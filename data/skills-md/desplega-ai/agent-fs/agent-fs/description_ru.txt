Используйте, когда пользователь хочет хранить, извлекать, искать или управлять файлами в агенте-fs — файловой системе с приоритетом агента, поддерживаемой S3. Срабатывает при: «сохранить это в агенте-fs», «найти этот файл», «сохранить этот документ», «поиск агента-фс», «перечислить мои файлы», «показать историю версий», «вернуть файл», «настроить агент-фс», «получить подписанный URL-адрес», «поделиться этим файлом», «управлять участниками», «пригласить пользователя», «составить список участников», «удалить участника», «обновить роль», сохранение файла для агентов, общую файловую систему агента или любое упоминание о агент-FS CLI. Также используйте, когда пользователю необходимо управлять дисками, управлять участниками организации/диска, создавать заранее назначенные URL-адреса, проверять недавнюю активность или использовать семантический поиск по хранимым файлам. Также используйте, когда пользователь хочет запустить SQL над сохраненными файлами данных («запросить этот CSV», «sql поверх моих файлов», «duckdb», «агрегировать файл паркета», «запросить базу данных sqlite», «присоединиться к этим электронным таблицам»). Также используйте, когда пользователь хочет смонтировать или размонтировать агент-fs как файловую систему Linux FUSE («монтировать агент-fs», «монтировать с помощью предохранителя», «предохранитель», «удаленное монтирование», «монтировать в песочнице», «выставлять диски как файлы», «использовать cat/grep/mv для файлов моего агента-fs», «размонтировать диск», «монтировать удаленный диск», «монтировать из спрайта», «монтировать из e2b», «монтировать из hetzner»). Также используйте, когда пользователь хочет использовать агент-fs в качестве файловой системы just-bash. Также используйте, когда пользователь хочет настроить агент-fs без Docker или S3 («серверная часть локальной файловой системы», «хранилище файловой системы», «без докера», «встроенная --filesystem», «хранить файлы на диске»). Если пользователь упоминает агент-fs в каком-либо контексте, всегда обращайтесь к этому навыку.
