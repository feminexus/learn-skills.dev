ユーザーが、S3 によって支援されるエージェントファーストのファイルシステムである、agent-fs にファイルを保存、取得、検索、または管理する場合に使用します。トリガー: 「これをagent-fsに保存」、「そのファイルを検索」、「このドキュメントを保存」、「agent-fsを検索」、「ファイルをリスト表示」、「バージョン履歴を表示」、「ファイルを元に戻す」、「agent-fsをセットアップ」、「署名付きURLを取得」、「このファイルを共有」、「メンバーを管理」、「ユーザーを招待」、「メンバーをリスト表示」、「メンバーを削除」、「ロールを更新」、エージェントのファイル永続化、共有エージェント ファイルシステム、または Agent-fs CLI に関する言及。また、ユーザーがドライブの管理、組織/ドライブのメンバーの管理、署名付き URL の生成、最近のアクティビティの確認、保存されたファイル全体のセマンティック検索の使用を行う必要がある場合にも使用します。ユーザーが保存されたデータ ファイルに対して SQL を実行する場合にも使用します (「この CSV をクエリする」、「ファイルに対して SQL を実行する」、「duckdb」、「寄木細工のファイルを集計する」、「SQLite データベースをクエリする」、「これらのスプレッドシートを結合する」)。ユーザーが Agent-fs を Linux FUSE ファイルシステムとしてマウントまたはアンマウントしたい場合にも使用します (「エージェント fs のマウント」、「ヒューズ マウント」、「ヒューズ」、「リモート マウント」、「サンドボックス マウント」、「ドライブをファイルとして公開」、「エージェント fs ファイルで cat/grep/mv を使用」、「ドライブをアンマウント」、「リモート ドライブをマウント」、「スプライトからマウント」、「e2b からマウント」、「からマウント」ヘッツナー」）。ユーザーが Agent-fs を just-bash ファイルシステムとして使用したい場合にも使用します。ユーザーが Docker や S3 を使用せずに Agent-fs をセットアップしたい場合にも使用します (「ローカル ファイルシステム バックエンド」、「ファイルシステム ストレージ」、「Docker なし」、「onboard --filesystem」、「ディスクにファイルを保存」)。ユーザーが何らかのコンテキストでagent-fsに言及した場合は、常にこのスキルを参照してください。
