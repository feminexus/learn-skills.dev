Esegui la scansione dei dischi locali o delle root selezionate per i repository Git e trasforma i commit, i file modificati e il lavoro significativo non impegnato da un intervallo di tempo predefinito o personalizzato in un conciso report settimanale cinese o inglese. Da utilizzare quando l'utente richiede un report settimanale Git, un riepilogo del lavoro, un aggiornamento del venerdì, un riepilogo dello sviluppo recente, 周报, 本周工作总结 o un report sulle attività multi-repository.
