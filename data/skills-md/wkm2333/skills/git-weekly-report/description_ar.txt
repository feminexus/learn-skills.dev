قم بمسح الأقراص المحلية أو الجذور المحددة بحثًا عن مستودعات Git وقم بتحويل الالتزامات والملفات التي تم تغييرها والأعمال غير الملتزم بها ذات المغزى من نطاق زمني افتراضي أو مخصص إلى تقرير أسبوعي موجز باللغة الصينية أو الإنجليزية. يُستخدم عندما يطلب المستخدم تقرير Git الأسبوعي، أو ملخص العمل، أو تحديث الجمعة، أو ملخص التطوير الأخير، أو تقرير النشاط متعدد المستودعات.
