Discipline de recherche Web efficace pour les agents d'IA : commencez par parcourir, puis recherchez avec rigueur. L'étape 0 détermine si une question nécessite une recherche Web externe ou si elle peut être répondue à partir de la base de code/de la documentation interne ; lorsqu'il est externe, le mode par défaut applique automatiquement 4 maximes ; sur des demandes explicites de « recherche stricte/approfondie », il effectue une évaluation de la crédibilité des sources en 7 dimensions (CRAAP + E-E-A-T) avec un rapport vérifiable. Lorsque la couche statique (WebSearch/WebFetch/curl) ne peut pas atteindre le contenu (connexion requise/rendu JS/anti-scraping comme 小红书·公众号), elle est transmise au navigateur réel via la compétence d'accès Web (CDP, porte l'état de connexion). Déclencheurs : 「Web调研」「外部调研」「查资料」「有效调研」「严格调研」「深度调研」「严格查证」「 Meilleur pratique 是什么」 / recherche sur le Web, recherche, enquête, recherche stricte, recherche approfondie, vérification des faits, accès à l'état de connexion, page dynamique, anti-scraping. Ne PAS utiliser pour : rechercher la base de code locale, lire les fichiers de dépôt, saisir le code.
