Эффективная дисциплина веб-исследований для агентов ИИ — сначала маршрут, затем тщательные исследования. Шаг 0 определяет, требует ли вопрос внешнего поиска в Интернете или на него можно ответить из внутренней базы кода/документов; во внешнем режиме по умолчанию автоматически применяются 4 максимы; по явным запросам на «строгие/глубокие исследования» он проводит семимерную оценку достоверности источника (CRAAP + E-E-A-T) с поддающимся аудиту отчетом. Когда статический уровень (WebSearch/WebFetch/curl) не может достичь контента (требуется вход в систему/отрисовка JS/защита от очистки, например 小红书·公众号), он передается в реальный браузер через навык веб-доступа (CDP, переносит состояние входа в систему). Триггеры: 「сеть调研」「外部调研」「查资料」「有效调研」「严格调研」「深度调研」「严格查证」「 Лучшие песни практика 是什么」 / веб-исследование, поиск, исследование, строгое исследование, глубокое исследование, проверка фактов, доступ к состоянию входа, динамические страницы, защита от парсинга. НЕ используйте для: поиска в локальной базе кода, чтения файлов репозитория, поиска кода.
