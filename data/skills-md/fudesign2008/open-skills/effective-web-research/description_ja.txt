AI エージェントのための効果的な Web リサーチの規律 - まずルートを決め、次に厳密にリサーチします。ステップ 0 では、質問が外部の Web 検索を必要とするか、内部のコードベース/ドキュメントから回答できるかを優先順位付けします。外部の場合、デフォルト モードでは 4 つの格率が自動的に適用されます。明示的な「厳密/詳細な調査」リクエストに応じて、監査可能なレポートを使用して 7 次元の情報源の信頼性評価 (CRAAP + E-E-A-T) を実行します。静的レイヤー (WebSearch/WebFetch/curl) がコンテンツ (ログイン必須 / JS レンダリング / 小红书・公众号のようなアンチスクレイピング) に到達できない場合、Web アクセス スキル (CDP、ログイン状態を保持) を介して実際のブラウザーにエスカレートします。トリガー: 「ウェブ」调研」「外部调研」「查资料」「有效调研」「严格调研」「深度调研」「严格查证」登录态访问」「動态页面」「反逆」「这个库/框架怎么用」「有没有漏洞」「最高実践とは何か」 / ウェブ調査、検索、調査、厳密な調査、詳細な調査、事実確認、ログイン状態へのアクセス、動的ページ、アンチスクレイピング。ローカル コードベースの検索、リポジトリ ファイルの読み取り、コードの grep には使用しないでください。
