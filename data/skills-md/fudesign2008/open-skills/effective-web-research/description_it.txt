Disciplina efficace della ricerca web per gli agenti IA: prima il percorso, poi la ricerca con rigore. Il passaggio 0 valuta se una domanda necessita di una ricerca Web esterna o se è possibile rispondere dalla base di codice/documenti interni; quando esterna, la modalità predefinita applica automaticamente 4 massime; su richieste esplicite di "ricerca rigorosa/approfondita" esegue una valutazione della credibilità della fonte a 7 dimensioni (CRAAP + E-E-A-T) con un rapporto verificabile. Quando il livello statico (WebSearch/WebFetch/curl) non riesce a raggiungere il contenuto (è richiesto l'accesso/con rendering JS/anti-scraping come 小红书·公众号), passa al browser reale tramite la capacità di accesso al Web (CDP, trasporta lo stato di accesso). Trigger: 「web调研」「外部调研」「查资料」「有效调研」「严格调研」「深度调研」「严格查证」「登录态访问」「动态页面」「反爬」「这个库/框架怎么用」「有没有漏洞」「best pratica 是什么」 / ricerca web, ricerca, indagine, ricerca rigorosa, ricerca approfondita, verifica dei fatti, accesso con stato di accesso, pagina dinamica, anti-scraping. NON utilizzare per: ricerca nella codebase locale, lettura di file repository, grepping di codice.
