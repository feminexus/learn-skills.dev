Disciplina de investigación web eficaz para agentes de IA: primero la ruta y luego la investigación con rigor. El paso 0 clasifica si una pregunta necesita una búsqueda web externa o si se puede responder desde la base de código/documentos internos; cuando es externo, el modo predeterminado aplica automáticamente 4 máximas; en solicitudes explícitas de 'investigación estricta/profunda', ejecuta una evaluación de credibilidad de la fuente de 7 dimensiones (CRAAP + E-E-A-T) con un informe auditable. Cuando la capa estática (WebSearch/WebFetch/curl) no puede acceder al contenido (requiere inicio de sesión/representado por JS/anti-scraping como 小红书·公众号), escala al navegador real a través de la habilidad de acceso web (CDP, lleva el estado de inicio de sesión). Desencadenantes: 「web调研」「外部调研」「查资料」「有效调研」「严格调研」「深度调研」「严格查证」「 Mejor practicar 是什么」 / investigación web, buscar, investigar, investigación estricta, investigación profunda, verificación de datos, acceso al estado de inicio de sesión, página dinámica, anti-scraping. NO lo use para: buscar en la base de código local, leer archivos de repositorio, buscar código.
