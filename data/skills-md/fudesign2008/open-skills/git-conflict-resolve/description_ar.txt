يُستخدم عندما ينتج عن دمج Git أو إعادة الأساس تعارضات في التعليمات البرمجية، خاصةً عندما يكون حل التعارض الآلي بواسطة الذكاء الاصطناعي عرضة للخطأ (اختيار الجانب الخطأ، أو فقدان عامل إعادة البناء، أو العودة إلى إصدار أقدم) ويلزم إجراء تحليل دلالي بالإضافة إلى التحقق المنطقي. ينطبق أيضًا عند توقف إعادة الأساس متعدد الجولات بشكل متكرر ويجب تجميع ملفات التعارض عبر الجولات. المشغلات — 「حل الصراع، حل الدمج، rebase 冲突」「冲突解决」 / حل الصراع، حل دمج الصراع، حل الصراع rebase.
