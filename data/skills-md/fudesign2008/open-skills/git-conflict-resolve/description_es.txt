Úselo cuando una fusión o rebase de Git produce conflictos de código, especialmente cuando la resolución de conflictos automatizada por IA es propensa a errores (elegir el lado equivocado, perder una refactorización, volver a una versión anterior) y se necesita análisis semántico más verificación lógica. También se aplica cuando una rebase de múltiples rondas se detiene repetidamente y los archivos de conflicto deben agregarse entre rondas.
