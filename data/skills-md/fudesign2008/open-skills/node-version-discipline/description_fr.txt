Discipline de version du nœud — avant d'exécuter tsc / eslint / build / test / install dans n'importe quel projet Node, alignez la version du nœud sur la version déclarée du projet (.nvmrc / .node-version / .tool-versions / volta / moteurs.node) et divulguez-la dans le rapport de vérification, empêchant ainsi les fausses réussites/faux échecs lorsque le nœud par défaut de l'hôte ne correspond pas à la version épinglée par le projet ; lorsque le projet ne déclare aucune version de Node, demandez la version à l'utilisateur et proposez de conserver un fichier de déclaration afin que les futures sessions/CI s'alignent automatiquement. Utilisez cette compétence chaque fois que l'utilisateur est sur le point d'exécuter une commande Node sensible à la version ou qu'il mentionne une incompatibilité de version du nœud/un mauvais conflit de nœud/version.
