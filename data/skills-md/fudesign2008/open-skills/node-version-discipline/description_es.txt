Disciplina de la versión del nodo: antes de ejecutar tsc / eslint / build / test / install en cualquier proyecto de Node, alinee la versión del Nodo con la versión declarada del proyecto (.nvmrc / .node-version / .tool-versions / volta /engines.node) y divulguelo en el informe de verificación, evitando errores falsos/fallos falsos cuando el Nodo predeterminado del host no coincide con la versión fijada en el proyecto; cuando el proyecto no declara ninguna versión de Nodo, solicite al usuario la versión y ofrézcale conservar un archivo de declaración para que futuras sesiones/CI se alineen automáticamente.
