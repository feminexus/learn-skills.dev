节点版本规则 - 在任何 Node 项目中运行 tsc / eslint / build / test / install 之前，将 Node 版本与项目声明的版本（.nvmrc / .node-version / .tool-versions / volta /engines.node）对齐，并在验证报告中披露，以防止当主机默认 Node 与项目固定版本不匹配时出现 false-pass / false-fail；当项目根本声明没有 Node 版本时，请向用户询问版本并提供保留声明文件，以便将来的会话/CI 自动对齐。每当用户要运行版本敏感的 Node 命令，或提到 Node 版本不匹配/错误的 Node/版本冲突时，请使用此技能。 中文触发词「节点版本调整」「nvm 调整」「.nvmrc」「节点版本纪律」「调整节点版本」「切换节点版本」「版本不匹配」「初始化节点版本管理」「为工程增加节点版本声明」「给工程加 .nvmrc」「无 .nvmrc 时补一个」「工程无节点版本管理」，英文别名节点版本纪律，nvm 使用，对齐节点版本，切换节点版本，添加 nvmrc，初始化节点版本。
