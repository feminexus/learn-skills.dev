ノード バージョンの規律 — ノード プロジェクトで tsc / eslint / build / test / install を実行する前に、ノード バージョンをプロジェクトの宣言されたバージョン (.nvmrc / .node-version / .tool-versions / volta / Engines.node) に合わせて検証レポートで公開し、ホストのデフォルト ノードがプロジェクトに固定されたバージョンと一致しない場合の false-pass / false-fail を防ぎます。プロジェクトがノードのバージョンをまったく宣言していない場合は、ユーザーにバージョンを尋ね、将来のセッション/CI が自動調整されるように宣言ファイルを永続化するよう提案します。ユーザーがバージョンに依存するノード コマンドを実行しようとしている場合、またはノードのバージョンの不一致/間違ったノード/バージョンの競合について言及する場合は必ず、このスキルを使用してください。 中文接触词「node バージョン本对齐」「nvm 对齐」「.nvmrc」「Node バージョン本纪律」「对齐 Node バージョン本」「切换ノード バージョン本」「バージョン本不適合」「初期化ノード バージョン管理」「工程增加ノード バージョン確認」「给工程加.nvmrc」「無 .nvmrc 時間补一个」「工程没有ノード バージョン管理」、英語のエイリアス ノード バージョン規律、nvm の使用、ノード バージョンの調整、ノード バージョンの切り替え、nvmrc の追加、ノード バージョンの初期化。
