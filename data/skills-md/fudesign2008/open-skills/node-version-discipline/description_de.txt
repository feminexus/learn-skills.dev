Node-Versionsdisziplin – bevor Sie tsc / eslint / build / test / install in einem Node-Projekt ausführen, richten Sie die Node-Version an der deklarierten Version des Projekts aus (.nvmrc / .node-version / .tool-versions / volta / engine.node) und legen Sie sie im Überprüfungsbericht offen, um ein falsches Bestehen/falsches Scheitern zu verhindern, wenn der Host-Standardknoten nicht mit der im Projekt angehefteten Version übereinstimmt; Wenn das Projekt überhaupt keine Knotenversion deklariert, fragen Sie den Benutzer nach der Version und bieten Sie an, eine Deklarationsdatei beizubehalten, damit zukünftige Sitzungen/CI automatisch ausgerichtet werden. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen versionabhängigen Node-Befehl ausführen möchte oder eine Nichtübereinstimmung der Node-Version bzw. einen falschen Node-/Versionskonflikt erwähnt. 中文触发词「node 版本对齐」「nvm 对齐」「.nvmrc」「Node 版本纪律」「对齐 Node 版本」「切换 node版本」「版本不匹配」「初始化 node 版本管理」「为工程增加 node 版本声明」「给工程加.nvmrc」「无 .nvmrc 时补一个」「工程没有 node 版本管理」, englische Aliase-Knotenversionsdisziplin, NVM-Verwendung, Knotenversion ausrichten, Knotenversion wechseln, nvmrc hinzufügen, Knotenversion initialisieren.
