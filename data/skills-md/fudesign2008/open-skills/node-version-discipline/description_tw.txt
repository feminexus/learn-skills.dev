節點版本規則 - 在任何 Node 專案中執行 tsc / eslint / build / test / install 之前，將 Node 版本與專案宣告的版本（.nvmrc / .node-version / .tool-versions / volta /engines.node），並在預設版本中與主機揭露，以防止版本/ 7 揭露項目，不符合版本主機，不符合版本主機false-fail；當專案根本聲明沒有 Node 版本時，請向使用者詢問版本並提供保留聲明文件，以便將來的會話/CI 自動對齊。每當使用者要執行版本敏感的 Node 指令，或提到 Node 版本不符/錯誤的 Node/版本衝突時，請使用此技能。 中文觸發詞「節點版本調整」「nvm 調整」「.nvmrc」「節點版本紀律」「調整節點版本」「切換節點版本」「版本不符」「初始化節點版本管理」「為工程增加節點版本聲明」「給工程加 .nvmrc」「無 .nvmrc 時補一個節點，「工程化版本，」「給工程加 .nvmrc」「無 .nvmrc 時補一個節點，「工程化版本，」節點管理不符版本，nvmc版本，nvmcc節點，cc節點。
