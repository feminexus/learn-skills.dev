Дисциплина версии узла — перед запуском tsc / eslint / build / test / install в любом проекте Node согласуйте версию Node с заявленной версией проекта (.nvmrc / .node-version / .tool-versions / VOLTA / Engines.node) и раскройте ее в отчете о проверке, предотвращая ложное прохождение / ложную неудачу, когда узел по умолчанию хоста не соответствует версии, закрепленной за проектом; когда проект вообще не объявляет версию Node, запросите у пользователя версию и предложите сохранить файл объявления, чтобы будущие сеансы/CI автоматически выравнивались. Используйте этот навык всякий раз, когда пользователь собирается запустить команду узла, чувствительную к версии, или упоминает несоответствие версии узла/неправильный узел/конфликт версий. 中文触发词「node 版本对齐」「nvm 对齐」「.nvmrc」「Node 版本纪律」「对齐 Node 版本」「切换 node版本」「版本不匹配」「初始化 node 版本管理」「为工程增加 node 版本声明」「给工程加.nvmrc」「无 .nvmrc 时补一个」「工程没有 node 版本管理」, английские псевдонимы, дисциплина версии узла, использование nvm, выравнивание версии узла, переключение версии узла, добавление nvmrc, инициализация версии узла.
