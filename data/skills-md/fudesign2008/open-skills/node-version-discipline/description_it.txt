Disciplina della versione del nodo: prima di eseguire tsc / eslint / build / test / install in qualsiasi progetto Node, allinea la versione del nodo alla versione dichiarata del progetto (.nvmrc / .node-version / .tool-versions / volta / Engines.node) e divulgala nel rapporto di verifica, impedendo falsi passaggi / falsi fallimenti quando il nodo predefinito dell'host non corrisponde alla versione bloccata nel progetto; quando il progetto non dichiara alcuna versione del nodo, chiedi all'utente la versione e offri di persistere un file di dichiarazione in modo che le future sessioni/CI si allineino automaticamente.
