Base de conocimientos de optimización del rendimiento del frontend (incluido el escritorio Electron), que cubre conocimientos de optimización específicos de la versión para React 16-19, Angular 9-18+ y Electron 12-28+. Funciona junto con la habilidad perf-workflow: perf-workflow impulsa el proceso de análisis, mientras que esta habilidad proporciona estándares cuantitativos específicos del frontend, estrategias de optimización con reconocimiento de versiones, patrones de cuello de botella y referencias de herramientas. Úselo al analizar problemas de rendimiento en la interfaz web (React/Angular/Vue) o aplicaciones de escritorio de Electron. Activadores: 「前端性能」「前端性能优化」「Electron 性能」 / rendimiento frontend, optimización del rendimiento frontend, rendimiento de Electron.
