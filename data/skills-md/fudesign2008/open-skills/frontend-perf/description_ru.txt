База знаний по оптимизации производительности внешнего интерфейса (включая настольную систему Electron), охватывающая знания по оптимизации для конкретных версий React 16-19, Angular 9-18+ и Electron 12-28+. Работает вместе с навыком perf-workflow: perf-workflow управляет процессом анализа, в то время как этот навык предоставляет количественные стандарты для конкретного интерфейса, стратегии оптимизации с учетом версий, шаблоны узких мест и ссылки на инструменты. Используйте при анализе проблем с производительностью в веб-интерфейсе (React/Angular/Vue) или настольных приложениях Electron. Триггеры — 「前端性能」「前端性能优化」「Electron 性能」 / производительность внешнего интерфейса, оптимизация производительности внешнего интерфейса, производительность Electron.
