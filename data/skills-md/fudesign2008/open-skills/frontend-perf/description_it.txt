Base di conoscenza per l'ottimizzazione delle prestazioni del frontend (incluso desktop Electron), che copre le conoscenze sull'ottimizzazione specifiche della versione per React 16-19, Angular 9-18+ ed Electron 12-28+. Funziona insieme alla competenza perf-workflow: perf-workflow guida il processo di analisi mentre questa competenza fornisce standard quantitativi specifici del frontend, strategie di ottimizzazione basate sulla versione, modelli di colli di bottiglia e riferimenti a strumenti. Da utilizzare quando si analizzano i problemi di prestazioni nel frontend Web (React/Angular/Vue) o nelle app desktop Electron. Trigger — 「前端性能」「前端性能优化」「Electron 性能」 / prestazioni frontend, ottimizzazione delle prestazioni frontend, prestazioni Electron.
