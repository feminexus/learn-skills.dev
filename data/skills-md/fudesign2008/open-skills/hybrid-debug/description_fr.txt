Application hybride (shell natif + WebView/WKWebView/Electron + H5) méthodologie de débogage full-stack — force l'analyse sur quatre couches (exécution Web, pont Web natif, configuration native, exécution de la plate-forme) au lieu de s'arrêter à une seule couche, empêchant ainsi les corrections de surface. À utiliser lors du débogage de problèmes d'interface utilisateur/thème/comportement d'applications hybrides, en particulier les écarts de plate-forme (une plate-forme se reproduit, l'autre non), les échecs répétés de correction d'une seule extrémité ou les échecs silencieux impliquant la communication native H5, le changement de thème ou le comportement d'exécution de la plate-forme. Déclencheurs - Déclencheurs hybrides - WebView et WKWebView Débogage natif et débogage hybride H5, débogage multiplateforme, problème de vue Web, pont Web natif, débogage full-stack, débogage RN/Electron.
