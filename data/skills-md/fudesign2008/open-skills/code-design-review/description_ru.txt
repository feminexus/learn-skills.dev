Авторитетная структура для проверки качества разработки предлагаемых изменений кода — перед реализацией. Оценивает метрики на уровне кода (случайная сложность, связь по Майерсу/Коннасценции, сплоченность, усиление изменений, технический долг, цикломатическая/когнитивная сложность, Закон Деметры) и атрибуты качества на уровне архитектуры (тестируемость, модульность, надежность, масштабируемость, направление зависимостей по ISO 25010 + Чистая архитектура + SDP), а также проход безопасности (OWASP Top 10). Используйте этот навык всякий раз, когда предлагаемое решение включает в себя изменения кода и вам нужно оценить, хорошо ли он спроектирован — не только работает ли он, но и пригоден ли он для сопровождения, тестирования и не приводит ли он к задержкам при проектировании. Триггеры — 「代码审查」「代码设计审查」「代码设计质量」「审查代码设计」「代码架构审查」「设计质量评估」「代码质量评审」「这个代码设计合理吗」「耦合度审查」「代码可维护性」 / обзор дизайна кода, обзор архитектуры кода, оценка качества дизайна, анализ сопряженности, обзор ремонтопригодности.
