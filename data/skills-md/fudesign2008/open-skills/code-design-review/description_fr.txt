Cadre faisant autorité pour examiner la qualité de la conception des modifications de code proposées – avant la mise en œuvre. Évalue les métriques au niveau du code (complexité accidentelle, couplage via Myers/Connascence, cohésion, amplification du changement, dette technologique, complexité cyclomatique/cognitive, loi de Déméter) et les attributs de qualité au niveau de l'architecture (testabilité, modularité, fiabilité, évolutivité, direction des dépendances via ISO 25010 + Clean Architecture + SDP) plus un laissez-passer de sécurité (OWASP Top 10). Utilisez cette compétence chaque fois qu'une solution proposée implique des modifications de code et que vous devez évaluer si le code est bien conçu - non seulement s'il fonctionne, mais s'il est maintenable, testable et n'introduit pas de dette de conception.
