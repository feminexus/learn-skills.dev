Maßgeblicher Rahmen zur Überprüfung der Designqualität vorgeschlagener Codeänderungen – vor der Implementierung. Bewertet Metriken auf Codeebene (zufällige Komplexität, Kopplung über Myers/Connascence, Zusammenhalt, Änderungsverstärkung, Tech Debt, zyklomatische/kognitive Komplexität, Gesetz von Demeter) und Qualitätsattribute auf Architekturebene (Testbarkeit, Modularität, Zuverlässigkeit, Skalierbarkeit, Abhängigkeitsrichtung über ISO 25010 + Clean Architecture + SDP) sowie einen Sicherheitspass (OWASP Top 10). Verwenden Sie diese Fähigkeit immer dann, wenn eine vorgeschlagene Lösung Codeänderungen beinhaltet und Sie beurteilen müssen, ob der Code gut gestaltet ist – nicht nur, ob er funktioniert, sondern auch, ob er wartbar und testbar ist und keine Designschulden mit sich bringt. Auslöser – 「代码审查」「代码设计审查」「代码设计质量」「审查代码设计」「代码架构审查」「设计质量评估」「代码质量评审」「这个代码设计合理吗」「耦合度审查」「代码可维护性」 / Überprüfung des Codedesigns, Überprüfung der Codearchitektur, Bewertung der Designqualität, Kopplungsanalyse, Überprüfung der Wartbarkeit.
