Workflow PDCA en huit étapes pour résoudre systématiquement les bogues, les refactors et les tâches de développement de fonctionnalités : clarifier → analyser → explorer des solutions → examiner → planifier → exécuter → vérifier → rétrospecter. Le mode manuel (par défaut) fait une pause pour la confirmation de l'utilisateur à chaque sortie d'étape ; le mode automatique fonctionne de bout en bout. Déclencheurs — 「明确问题」「分析问题」「探索方案」「审查方案」「制定计划」「执行计划」「检查验证」「复盘改进」(alias「回顾总结」)；「继续分析」「深入分析」「修改方案」「完善方案」「优化方案」「更新计划」「修订计划」「修改计划」；「自动模式」「自动分析」「自动解决」 / Clarifier le problème, analyser le problème, explorer les solutions, examiner la solution, élaborer un plan, exécuter le plan, vérifier, rétrospective, mode automatique.
