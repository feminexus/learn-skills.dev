Flujo de trabajo PDCA de ocho etapas para resolver sistemáticamente errores, refactorizaciones y tareas de desarrollo de características: aclarar → analizar → explorar soluciones → revisar → planificar → ejecutar → verificar → retrospectiva. El modo manual (predeterminado) se detiene para la confirmación del usuario en cada salida de etapa; El modo automático se ejecuta de un extremo a otro. Desencadenantes 「明确问题」「分析问题」「探索方案」「审查方案」「制定计划」「执行计划」「检查验证」「复盘改进」(alias「回顾总结」)；「继续分析」「深入分析」「修改方案」「完善方案」「优化方案」「更新计划」「修订计划」「修改计划」；「自动模式」「自动分析」「自动解决」 / aclarar problema, analizar problema, explorar soluciones, revisar solución, hacer plan, ejecutar plan, verificar, retrospectiva, modo automático.
