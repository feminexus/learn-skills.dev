Восьмиэтапный рабочий процесс PDCA для систематического устранения ошибок, рефакторинга и задач по разработке функций: уточнить → проанализировать → изучить решения → просмотреть → спланировать → выполнить → проверить → ретроспективно. Ручной режим (по умолчанию) приостанавливается для подтверждения пользователя при каждом выходе из этапа; автоматический режим работает непрерывно. Триггеры — 「明确问题」「分析问题」「探索方案」「审查方案」「制定计划」「执行计划」「检查验证」「复盘改进」(псевдоним「回顾总结」)；「继续分析」「深入分析」「修改方案」「完善方案」「优化方案」「更新计划」「修订计划」「修改计划」；「自动模式」「自动分析」「自动解决」 / уточнить проблему, проанализировать проблему, изучить решения, просмотреть решение, составить план, выполнить план, проверить, ретроспектива, автоматический режим.
