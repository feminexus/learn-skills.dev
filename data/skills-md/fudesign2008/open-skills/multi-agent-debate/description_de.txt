Unterziehen Sie eine Absturzanalyse, eine Hypothese oder eine technische Schlussfolgerung einem Stresstest, indem Sie drei gegnerische Agenten parallel einsetzen – einer verteidigt, einer greift an, einer sucht nach neuen Beweisen – und lösen Sie Streitigkeiten mit physischen Beweisen statt mit Argumenten. Verwenden Sie diese Fähigkeit immer, wenn die Analyse mehr als zwei konkurrierende Erklärungen enthält, die beide plausibel erscheinen, wenn eine Schlussfolgerung auf einer einzelnen Protokollstichprobe oder einer abgeleiteten Kette basiert, die länger als drei Schritte ist, oder wenn jemand fragt: „Sind Sie sicher?“, „Das hört sich nicht richtig an“ oder eine Annahme in Frage stellt. Auslöser: 辩论、求真、挑战假设、质疑分析、multi-agent-debate, „debattieren Sie dies“, „stellen Sie meine Analyse in Frage“, „finden Sie Lücken in“, „Ich bin nicht sicher, ob das richtig ist“, „überprüfen Sie dies“.
