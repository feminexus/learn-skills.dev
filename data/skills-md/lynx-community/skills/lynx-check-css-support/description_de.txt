Wird verwendet, wenn Sie gefragt werden, ob CSS in Lynx oder ReactLynx unterstützt wird, welche Backends es unterstützen, wann Unterstützung hinzugefügt wurde, ob eine Stiländerung kompatibel ist, ob die gebündelten Daten aktuell sind oder wenn Sie die JSON-Rohdefinition überprüfen.
