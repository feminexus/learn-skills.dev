Eseguire una query su @lynx-js/css-defines compat_data per verificare la proprietà CSS Lynx e il supporto di funzionalità/valori nidificati eseguendo il rendering del backend e della versione Lynx oppure verificare se esiste una versione del set di dati più recente. Da utilizzare quando viene chiesto se CSS è supportato in Lynx o ReactLynx, quali backend lo supportano, quando è stato aggiunto il supporto, se una modifica di stile è compatibile, se i dati in bundle sono aggiornati o quando si controlla la definizione grezza JSON.
