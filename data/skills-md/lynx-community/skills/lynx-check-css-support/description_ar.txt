الاستعلام @lynx-js/css-يحدد compat_data للتحقق من خاصية Lynx CSS ودعم الميزة/القيمة المتداخلة من خلال عرض الواجهة الخلفية وإصدار Lynx، أو التحقق من وجود إصدار أحدث لمجموعة البيانات. يُستخدم عند السؤال عما إذا كان CSS مدعومًا في Lynx أو ReactLynx، أو ما إذا كانت الواجهة الخلفية تدعمه، أو عند إضافة الدعم، أو ما إذا كان تغيير النمط متوافقًا، أو ما إذا كانت البيانات المجمعة حالية، أو عند فحص التعريف الأولي JSON.
