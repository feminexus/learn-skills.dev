Используйте при работе с Gravity SMTP: установка, настройка или устранение неполадок доставки транзакционной электронной почты WordPress через SendGrid, Mailgun, Postmark, Brevo, SES или пользовательский SMTP. Критично: всегда проверяйте версию ≥ 2.1.5 для защиты от CVE-2026-4020, которая приводит к утечке ключей API через неаутентифицированную конечную точку REST.
