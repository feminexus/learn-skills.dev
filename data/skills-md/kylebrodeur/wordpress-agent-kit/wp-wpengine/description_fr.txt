Facultatif : utilisation pour les workflows d'hébergement de WP Engine – git push basé sur SSH, WP-CLI à distance via la passerelle SSH, GitHub Actions CI/CD avec déploiements sécurisés vers le développement/la mise en scène/la production, la gestion des installations/domaines/cache/sauvegardes via les compétences Claude Code de wpe-labs et l'accès à l'API de WP Engine. Nécessite la configuration de la clé SSH et les variables d'environnement WPE_USERNAME/WPE_PASSWORD pour les opérations d'API.
