Créez un plan d'installation ECC fondé sur des preuves pour un dépôt spécifique en triant les compétences, les commandes, les règles, les hooks et les extras dans les compartiments DAILY et LIBRARY à l'aide de passes de révision parallèles prenant en compte les dépôts. À utiliser lorsque l'ECC doit être réduit à ce dont un projet a réellement besoin au lieu de charger le bundle complet.
