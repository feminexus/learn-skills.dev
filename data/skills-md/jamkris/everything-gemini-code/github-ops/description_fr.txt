Opérations, automatisation et gestion du référentiel GitHub. Triage des problèmes, gestion des relations publiques, opérations CI/CD, gestion des versions et surveillance de la sécurité à l'aide de la CLI gh. À utiliser lorsque l'utilisateur souhaite gérer les problèmes GitHub, les PR, le statut CI, les versions, les contributeurs, les éléments obsolètes ou toute tâche opérationnelle GitHub au-delà des simples commandes git.
