Operaciones, automatización y gestión del repositorio de GitHub. Clasificación de problemas, gestión de relaciones públicas, operaciones de CI/CD, gestión de versiones y supervisión de seguridad mediante la CLI de gh. Úselo cuando el usuario desee administrar problemas de GitHub, relaciones públicas, estado de CI, lanzamientos, contribuyentes, elementos obsoletos o cualquier tarea operativa de GitHub más allá de los simples comandos de Git.
