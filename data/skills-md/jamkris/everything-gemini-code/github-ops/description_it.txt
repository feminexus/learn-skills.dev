Operazioni, automazione e gestione del repository GitHub. Valutazione dei problemi, gestione delle PR, operazioni CI/CD, gestione dei rilasci e monitoraggio della sicurezza utilizzando la CLI gh. Da utilizzare quando l'utente desidera gestire problemi di GitHub, PR, stato del CI, versioni, contributori, elementi obsoleti o qualsiasi attività operativa di GitHub oltre ai semplici comandi git.
