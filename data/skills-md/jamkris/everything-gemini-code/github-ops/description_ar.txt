عمليات مستودع GitHub والأتمتة والإدارة. فرز المشكلات وإدارة العلاقات العامة وعمليات CI/CD وإدارة الإصدار ومراقبة الأمان باستخدام gh CLI. يُستخدم عندما يريد المستخدم إدارة مشكلات GitHub، أو العلاقات العامة، أو حالة CI، أو الإصدارات، أو المساهمين، أو العناصر التي لا معنى لها، أو أي مهمة تشغيلية لـ GitHub تتجاوز أوامر git البسيطة.
