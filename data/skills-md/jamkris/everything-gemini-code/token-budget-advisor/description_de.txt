Bietet dem Benutzer eine fundierte Auswahl darüber, wie viel Antworttiefe er nutzen möchte, bevor er antwortet. Verwenden Sie diese Fähigkeit, wenn der Benutzer explizit die Länge, Tiefe oder das Token-Budget der Antwort steuern möchte. TRIGGER, wenn: „Token-Budget“, „Token-Anzahl“, „Token-Nutzung“, „Token-Limit“, „Antwortlänge“, „Antworttiefe“, „Kurzversion“, „Kurze Antwort“, „Detaillierte Antwort“, „Erschöpfende Antwort“, „Kurz-gegen-Lang-Antwort“, „Token-Wechsel“, „Token-Mindestwert“, „Auf 50 % antworten“, „Herzliche Version“, „Wenn Sie uns kontrollieren“, oder klare Varianten, bei denen der Benutzer ausdrücklich darum bittet, die Größe oder Tiefe der Antwort zu steuern. NICHT AUSLÖSEN, wenn: der Benutzer bereits eine Ebene in der aktuellen Sitzung angegeben hat (diese beibehalten), die Anfrage eindeutig eine Ein-Wort-Antwort ist oder sich „Token“ eher auf Authentifizierungs-/Sitzungs-/Zahlungstokens als auf die Antwortgröße bezieht.
