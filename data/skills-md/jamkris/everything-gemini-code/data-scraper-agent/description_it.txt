Costruisci un agente di raccolta dati basato sull'intelligenza artificiale completamente automatizzato per qualsiasi fonte pubblica: bacheche di lavoro, prezzi, notizie, GitHub, sport, qualsiasi cosa. Raschia secondo una pianificazione, arricchisce i dati con un LLM gratuito (Gemini Flash), memorizza i risultati in Notion/Sheets/Supabase e apprende dal feedback degli utenti. Funziona gratuitamente al 100% su GitHub Actions. Utilizzare quando l'utente desidera monitorare, raccogliere o tenere traccia automaticamente dei dati pubblici.
