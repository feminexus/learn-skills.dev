Cree un agente de recopilación de datos totalmente automatizado impulsado por IA para cualquier fuente pública: bolsas de trabajo, precios, noticias, GitHub, deportes, cualquier cosa. Raspa según un cronograma, enriquece los datos con un LLM (Gemini Flash) gratuito, almacena los resultados en Notion/Sheets/Supabase y aprende de los comentarios de los usuarios. Se ejecuta 100% gratis en GitHub Actions. Úselo cuando el usuario desee monitorear, recopilar o rastrear cualquier dato público automáticamente.
