Créez un agent de collecte de données entièrement automatisé, alimenté par l'IA, pour toute source publique : sites d'emploi, prix, actualités, GitHub, sports, etc. Gratte selon un calendrier, enrichit les données avec un LLM gratuit (Gemini Flash), stocke les résultats dans Notion/Sheets/Supabase et apprend des commentaires des utilisateurs. Fonctionne 100 % gratuitement sur GitHub Actions. À utiliser lorsque l'utilisateur souhaite surveiller, collecter ou suivre automatiquement des données publiques.
