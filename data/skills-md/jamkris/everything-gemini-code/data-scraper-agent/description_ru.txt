Создайте полностью автоматизированный агент сбора данных на базе искусственного интеллекта из любого общедоступного источника — досок объявлений о вакансиях, цен, новостей, GitHub, спорта и всего остального. Собирает данные по расписанию, пополняет данные с помощью бесплатного LLM (Gemini Flash), сохраняет результаты в Notion/Sheets/Supabase и учится на отзывах пользователей. Работает на 100 % бесплатно на GitHub Actions. Используйте, когда пользователь хочет автоматически отслеживать, собирать или отслеживать любые общедоступные данные.
