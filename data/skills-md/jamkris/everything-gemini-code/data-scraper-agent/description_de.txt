Erstellen Sie einen vollautomatischen KI-gestützten Datenerfassungsagenten für jede öffentliche Quelle – Jobbörsen, Preise, Nachrichten, GitHub, Sport, alles. Scrapt nach einem Zeitplan, reichert Daten mit einem kostenlosen LLM (Gemini Flash) an, speichert Ergebnisse in Notion/Sheets/Supabase und lernt aus Benutzerfeedback. Läuft zu 100 % kostenlos auf GitHub Actions. Verwenden Sie diese Option, wenn der Benutzer öffentliche Daten automatisch überwachen, sammeln oder verfolgen möchte.
