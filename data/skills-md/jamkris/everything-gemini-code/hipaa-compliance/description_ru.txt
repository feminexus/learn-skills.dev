Точка входа, специфичная для HIPAA, для обеспечения конфиденциальности и безопасности в сфере здравоохранения. Используйте, когда задача явно связана с HIPAA, обработкой закрытой медицинской информации, охватываемыми организациями, BAA, ситуацией с нарушениями или требованиями соответствия требованиям здравоохранения США.
