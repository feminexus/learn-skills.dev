إجراء مراجعة أمنية للمربع الأبيض لتطبيقات Atlassian Forge باستخدام قواعد أمان منظمة خاصة بـ Forge وإعداد التقارير المستندة إلى الأدلة. يُستخدم عندما يطلب المستخدم إجراء مراجعة أمان Forge، أو تدقيق الأمان، أو تقييم vuln، أو مراجعة التعليمات البرمجية على نمط pentest، أو مراجعة authz، أو تحليل عزل المستأجر، أو تقوية مشغلات الويب، أو تنفيذ التحليل الثابت لتطبيق Forge.
