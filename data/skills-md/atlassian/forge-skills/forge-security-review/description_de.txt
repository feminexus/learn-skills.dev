Führt eine White-Box-Sicherheitsüberprüfung von Atlassian Forge-Apps mithilfe strukturierter, Forge-spezifischer Sicherheitsregeln und evidenzbasierter Berichterstattung durch. Wird verwendet, wenn der Benutzer eine Forge-Sicherheitsüberprüfung, ein Sicherheitsaudit, eine Schwachstellenbewertung, eine Codeüberprüfung im Pentest-Stil, eine Authentifizierungsüberprüfung, eine Mandantenisolationsanalyse, eine Web-Trigger-Härtung oder die Ausführung einer statischen Analyse für eine Forge-App anfordert.
