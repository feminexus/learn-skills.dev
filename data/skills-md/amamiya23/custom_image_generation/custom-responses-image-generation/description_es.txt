Utilice esta habilidad siempre que el usuario solicite generar, editar, pintar, cambiar el estilo o crear imágenes de mapa de bits a través de la herramienta de generación de imágenes de la API de respuestas de OpenAI del Codex. Esta habilidad llama a la API de Responses, guarda los resultados de las imágenes base64 generadas en archivos, no utiliza dependencias de npm o pip, funciona en Linux/macOS/Windows con Node.js 18+ o Python 3 y reutiliza la URL base, el modelo y la clave de la API configurada de Codex en lugar de solicitar credenciales al usuario.
