Используйте этот навык всякий раз, когда пользователь запрашивает создание, редактирование, дорисовку, изменение стиля или создание растровых изображений с помощью инструмента генерации изображений OpenAI Responses API из Кодекса. Этот навык вызывает API ответов, сохраняет сгенерированные результаты изображений в формате Base64 в файлы, не использует зависимости npm или pip, работает в Linux/macOS/Windows с Node.js 18+ или Python 3 и повторно использует настроенный Codex базовый URL-адрес, модель и ключ API вместо запроса учетных данных у пользователя.
