استخدم هذه المهارة عندما يطلب المستخدم إنشاء صور نقطية أو تحريرها أو طلاءها أو إعادة تصميمها أو إنشاءها من خلال أداة إنشاء الصور API الخاصة بـ OpenAI من Codex. تستدعي هذه المهارة واجهة API للاستجابات، وتحفظ نتائج الصور الأساسية 64 التي تم إنشاؤها في الملفات، ولا تستخدم تبعيات npm أو pip، وتعمل على Linux/macOS/Windows مع Node.js 18+ أو Python 3، وتعيد استخدام عنوان URL الأساسي لواجهة برمجة التطبيقات التي تم تكوينها والنموذج والمفتاح بدلاً من مطالبة المستخدم ببيانات الاعتماد.
