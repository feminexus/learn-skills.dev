Получение результатов стороннего тестирования и мониторинга в Dynatrace Grail через API приема событий платформы (platform/ingest/custom/events/). Используйте при отправке результатов внешнего синтетического тестирования, данных мониторинга CI или результатов сторонних проверок в Dynatrace. Охватывает область действия токена, полную схему событий для external_test_run и external_test_step (включая dt.security_context, ci.*, корреляцию трассировки и поля, добавленные в конвейер), примеры Curl и Java DTO, а также проверку DQL. Триггер: «прием результатов теста», «отправка результатов монитора», «сторонний монитор», «прием внешнего теста», «отправка синтетических результатов в Grail», «отправка данных внешнего теста в Dynatrace», «результаты внешнего монитора», «схема событий запуска внешнего теста». НЕ используйте для проверки браузера/HTTP встроенного синтетического мониторинга Dynatrace или мониторинга реальных пользователей (используйте dt-obs-frontend для RUM).
