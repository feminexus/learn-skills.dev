サードパーティによる、プラットフォーム イベント取り込み API (platform/ingest/custom/events/) を介した Dynatrace Grail への結果の取り込みをテストおよび監視します。外部の合成テスト結果、CI モニター データ、またはサードパーティのチェック結果を Dynatrace に送信するときに使用します。トークンのスコープ、external_test_run および external_test_step の完全なイベント スキーマ (dt.security_context、ci.*、トレース相関、パイプライン追加フィールドを含む)、curl および Java DTO の例、DQL 検証について説明します。トリガー: 「テスト結果の取り込み」、「モニター結果の送信」、「サードパーティモニター」、「外部テスト取り込み」、「合成結果を Grail に送信」、「外部テストデータを Dynatrace にプッシュ」、「外部モニター結果」、「外部テスト実行イベントスキーマ」。 Dynatrace ネイティブの合成モニタリング ブラウザ/HTTP チェック、またはリアル ユーザー モニタリング (RUM には dt-obs-frontends を使用) には使用しないでください。
