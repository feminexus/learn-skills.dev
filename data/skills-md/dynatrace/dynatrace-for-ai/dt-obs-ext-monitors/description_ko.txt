플랫폼 이벤트 수집 API(플랫폼/수집/사용자 정의/이벤트/)를 통해 Dynatrace Grail에 대한 제3자 테스트 및 모니터링 결과 수집. 외부 합성 테스트 결과, CI 모니터 데이터 또는 타사 확인 결과를 Dynatrace로 보낼 때 사용합니다. 토큰 범위, external_test_run 및 external_test_step에 대한 전체 이벤트 스키마(dt.security_context, ci.*, 추적 상관 관계 및 파이프라인 추가 필드 포함), 컬 및 Java DTO 예제, DQL 확인을 다룹니다. 트리거: "테스트 결과 수집", "모니터 결과 보내기", "타사 모니터", "외부 테스트 수집", "합성 결과를 Grail로 보내기", "외부 테스트 데이터를 Dynatrace에 푸시", "외부 모니터 결과", "외부 테스트 실행 이벤트 스키마". Dynatrace 기반 종합 모니터링 브라우저/HTTP 확인 또는 실제 사용자 모니터링(RUM의 경우 dt-obs-frontends 사용)에는 사용하지 마십시오.
