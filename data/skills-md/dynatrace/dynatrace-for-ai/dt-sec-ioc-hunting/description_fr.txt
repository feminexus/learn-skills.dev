Recherchez les indicateurs de compromission (IoC) des renseignements sur les menaces dans les journaux et les étendues Dynatrace et générez un score d'exposition aux menaces de 0 à 100. Extrait et normalise les IoC — IP, domaines (noms d'hôte inclus), URL, e-mails, CVE, hachages de fichiers (md5/sha1/sha256), MITRE TTP — à partir de rapports non structurés, d'avis, d'URL d'avis, de texte collé ou STIX, puis les recherche dans les journaux de récupération et les étendues de récupération. Déclencheur : chasser ces IoC, suis-je exposé à cette menace, vérifier ces indicateurs dans mes logs et traces, rapport d'exposition aux menaces, extraire les IoC de cette URL d'avis, rechercher ces hachages/domaines/IP dans mon environnement. Achemine les segments CVE vers vulnérabilité et IP/MITRE vers détection vers dt-sec-insights. Ne PAS utiliser pour : interroger directement security.events (vulnérabilités, détections, conformité, THREAT_REPORT — utilisez dt-sec-insights) ; requêtes de journaux générales non liées à une recherche IoC (utilisez dt-obs-logs) ; analyse générale de portée/trace (utiliser dt-obs-tracing) ; expliquer la syntaxe DQL (utilisez dt-dql-essentials).
