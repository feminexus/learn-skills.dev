Configura Dynatrace iOS SDK (OneAgent) in un progetto iOS utilizzando Swift Package Manager. Automatizza l'aggiunta della dipendenza SPM, la creazione di un file di configurazione Dynatrace.plist, l'aggiunta dell'istruzione di importazione, l'aggiunta del codice di attivazione della privacy e la creazione del progetto. Utilizza questa competenza quando l'utente desidera integrare, installare, aggiungere o configurare il monitoraggio Dynatrace nella propria app iOS. Parole chiave: Dynatrace, iOS, SDK, OneAgent, configurazione, installazione, integrazione, SPM, Swift Package Manager, Info.plist, DTXApplicationID, DTXBeaconURL, monitoraggio mobile, RUM.
