Configurez le SDK Dynatrace iOS (OneAgent) dans un projet iOS à l'aide de Swift Package Manager. Automatise l'ajout de la dépendance SPM, la création d'un fichier de configuration Dynatrace.plist, l'ajout de l'instruction d'importation, l'ajout du code d'adhésion à la confidentialité et la création du projet. Utilisez cette compétence lorsque l'utilisateur souhaite intégrer, installer, ajouter ou configurer la surveillance Dynatrace dans son application iOS. Mots clés : Dynatrace, iOS, SDK, OneAgent, configuration, installation, intégration, SPM, Swift Package Manager, Info.plist, DTXApplicationID, DTXBeaconURL, surveillance mobile, RUM.
