Richten Sie das Dynatrace iOS SDK (OneAgent) in einem iOS-Projekt mit Swift Package Manager ein. Automatisiert das Hinzufügen der SPM-Abhängigkeit, das Erstellen einer Dynatrace.plist-Konfigurationsdatei, das Hinzufügen der Importanweisung, das Hinzufügen des Datenschutz-Opt-In-Codes und das Erstellen des Projekts. Verwenden Sie diesen Skill, wenn der Benutzer die Dynatrace-Überwachung in seine iOS-App integrieren, installieren, hinzufügen oder einrichten möchte. Schlüsselwörter: Dynatrace, iOS, SDK, OneAgent, Einrichtung, Installation, Integration, SPM, Swift Package Manager, Info.plist, DTXApplicationID, DTXBeaconURL, mobile Überwachung, RUM.
