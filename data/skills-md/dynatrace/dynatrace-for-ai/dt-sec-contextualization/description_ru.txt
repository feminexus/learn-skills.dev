Преобразуйте сигналы безопасности, совпадения IoC или узлы Smartscape в объекты Dynatrace во время выполнения и связывайте результаты на разных уровнях объектов через общий объект во время выполнения. Охватывает сопоставление идентификаторов со Smartscape (включая дайджест образа контейнера/идентификатор рабочей нагрузки), межуровневую топологию (обнаружение модуля K8s по сравнению с CVE узла через модуль модуля к узлу), суммирование рисков для каждого объекта и рецепты сопоставления покрытия, общие для dt-sec-insights. Триггер: «сопоставить эти результаты с рабочими нагрузками/хостами», «под какой рабочей нагрузкой запускается этот образ контейнера», «связаны ли эти результаты с одним и тем же объектом времени выполнения», «дополнить это соответствие IoC контекстом объекта», «в каком отчете об угрозах упоминается этот IoC». Запрашивает Security.events ТОЛЬКО для обогащения IoC THREAT_REPORT (сопоставляет IoC с атрибутами отчетов); НЕ используйте для широкого обзора/состояния событий безопасности (используйте dt-sec-insights), общего DQL (используйте dt-dql-essentials), поиска IoC в журналах/промежутках (используйте dt-sec-ioc-hunting) или наблюдаемости K8s вне межуровневого контекста безопасности (используйте dt-obs-kubernetes).
