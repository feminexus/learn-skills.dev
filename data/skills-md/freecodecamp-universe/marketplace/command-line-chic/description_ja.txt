freeCodeCamp の「Command-line Chic」UI デザイン システムと美的ガイドライン。 Web アプリ、ダッシュボード、ランディング ページ、管理ツール、コンポーネント ライブラリ、またはテーマなど、freeCodeCamp 製品のような外観と操作性を必要とする UI を構築、スタイル設定、またはレビューするときは常に、これらのルールを適用してください。このスキルは、ユーザーが freeCodeCamp スタイル、fCC デザイン、「コマンドライン シック」、fCC のダーク テーマ開発について言及する場合、または freeCodeCamp のビジュアル アイデンティティに従う UI を要求する場合に使用します。ユーザーがデザイン システムについて明示的に言及していない場合でも、freeCodeCamp リポジトリで作業する場合、freeCodeCamp プロジェクトに貢献する場合、または freeCodeCamp スタッフ向けのツールやダッシュボードを構築する場合にも使用します。
