قاعدة معارف تطوير Odoo 19 مع 18 دليلًا متخصصًا يغطي الإجراءات (ir.actions.*، وظائف cron، إجراءات الخادم)، وحدات التحكم (توجيه HTTP، نقاط النهاية، أنواع المصادقة)، ملفات البيانات (سجلات XML/CSV، الاختصارات، التحديث)، API Decorators (@api.depends، @api.constrains، @api.ondelete، @api.onchange، @api.model، @api.private)، قيود SQL (models.Constraint تحل محل _sql_constraints)، فهارس قاعدة البيانات (models.Index)، تطوير الوحدة النمطية (البيان، المعالجات، التقارير)، أنواع الحقول (Char، نص، نقدي، حقول علائقية)، تكوين البيان (__manifest__.py، التبعيات، حزم الأصول)، Mixins (mail.thread، mail.activity.mixin، mail.alias.mixin، utm.mixin)، أساليب نموذج ORM (البحث، CRUD، مرشحات المجال، مجموعات السجلات، تسمية نموذج CamelCase)، البرامج النصية للترحيل (خطافات ما قبل/بعد/نهاية، ترحيل البيانات)، مكونات الواجهة الأمامية لـ OWL (الخطافات، الخدمات، دورة الحياة)، تحسين الأداء (منع N+1، العمليات المجمعة، _read_group)، تقارير QWeb (PDF/HTML، تنسيقات الورق، الرموز الشريطية، t-out)، الأمان/ACL (قواعد السجل، الحقل) الأذونات، المجموعات القائمة على الامتيازات، @api.private)، الاختبار (TransactionCase، HttpCase، الاستهزاء، تأكيدات عدد الاستعلامات)، المعاملات (نقاط الحفظ، UniqueViolation، فشل التسلسل)، الترجمات (i18n، ملفات PO، الحقول القابلة للترجمة)، طرق عرض XML (قائمة/نموذج/بحث، قوالب بطاقة كانبان، وراثة xpath، قوالب QWeb). يُستخدم عند كتابة أو مراجعة أو تصحيح أي كود Odoo 19 Python أو XML، أو إنشاء وحدات نمطية أو تعديلها، أو إصلاح مشكلات الأداء، أو البحث عن أنماط Odoo 19 API وأفضل الممارسات.
