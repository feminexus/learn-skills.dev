Guide la création de commits de style Odoo en suivant les directives officielles d'Odoo git. Rédige le module `[TAG] : brève description` des messages, vérifie s'il faut modifier ou créer une nouvelle validation, met en scène les fichiers explicitement, valide via `git commit -F` et garde l'historique local propre avant les PR. Invoque automatiquement les requêtes liées à la validation dans les référentiels Odoo et a la priorité sur les compétences de validation génériques.
