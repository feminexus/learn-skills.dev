Guida la creazione di commit in stile Odoo seguendo le linee guida ufficiali git di Odoo. Redige i messaggi "[TAG] module: short description", controlla se modificare o creare un nuovo commit, mette in stage i file in modo esplicito, esegue il commit tramite "git commit -F" e mantiene pulita la cronologia locale prima dei PR. Si richiama automaticamente per le richieste relative al commit nei repository Odoo e ha la priorità rispetto alle competenze di commit generiche.
