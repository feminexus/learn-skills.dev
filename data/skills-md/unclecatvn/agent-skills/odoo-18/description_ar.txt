مرجع تطوير Odoo 18 لنماذج Python وORM (البحث، والمجال، وread_group، وحقول الحساب)، وبيانات وطرق عرض XML/CSV، ورمز عميل OWL/JS، وتقارير QWeb، والأمن (ACL، وقواعد التسجيل، والمجموعات)، وإجراءات cron والخادم، والترحيلات وترقيات الوحدات، والاختبارات، وi18n، والأداء. استخدم هذه المهارة عندما يتضمن العمل Odoo 18 أو إضافات مخصصة - حتى لو قام المستخدم فقط بلصق تتبع، أو ذكر الإضافات/ أو __manifest__.py، أو وصف أخطاء النموذج/القائمة/kanban/XML، أو وحدات تحكم HTTP، أو قواعد العمل على النماذج - بما في ذلك إنشاء الميزات، أو إصلاح الأخطاء، أو إعادة البناء، أو مراجعة التعليمات البرمجية الإضافية.
