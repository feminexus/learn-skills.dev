Utilisez cette compétence pour évaluer et planifier une migration d'AWS MSK (Managed Streaming for Apache Kafka) vers Confluent Cloud. Déclencheurs sur l'intention de l'utilisateur comme « migrer MSK vers Confluent Cloud », « quitter MSK », « basculement MSK vers CC », « migration sans coupure depuis MSK », « kcp scan my MSK » ou toute discussion sur l'évaluation MSK vers CC, la planification, le dimensionnement du cluster, la configuration de la liaison de cluster, le basculement basé sur la passerelle ou la validation après le basculement. Ne déclenchez PAS pour les sources Kafka non MSK (Kafka open source, Aiven, Confluent Platform, Redpanda) – cette compétence est uniquement MSK. Ne déclenchez PAS pour les nouveaux projets Confluent Cloud sans source Kafka existante. Ne déclenchez PAS de questions générales de programmation Kafka (code producteur/consommateur, Kafka Streams) sans rapport avec la migration.
