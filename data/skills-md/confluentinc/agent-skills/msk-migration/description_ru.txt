Используйте этот навык для оценки и планирования миграции с AWS MSK (управляемая потоковая передача для Apache Kafka) в Confluent Cloud. Запускается по намерению пользователя, например «перенести MSK в Confluent Cloud», «отойти от MSK», «переключение MSK на CC», «миграция с нулевым вырезом из MSK», «kcp просканировать мой MSK» или любое обсуждение оценки MSK-CC, планирования, определения размера кластера, настройки связывания кластера, переключения на основе шлюза или проверки после переключения. НЕ активируйте для источников Kafka, отличных от MSK (Kafka с открытым исходным кодом, Aiven, Confluent Platform, Redpanda) — этот навык предназначен только для MSK. НЕ запускайте триггер для новых проектов Confluent Cloud без существующего источника Kafka. НЕ запускайте триггер для общих вопросов по программированию Kafka (код производителя/потребителя, Kafka Streams), не связанных с миграцией.
