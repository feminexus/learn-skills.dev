이 기술을 사용하여 AWS MSK(Apache Kafka용 관리형 스트리밍)에서 Confluent Cloud로의 마이그레이션을 평가하고 계획합니다. "MSK를 Confluent Cloud로 마이그레이션", "MSK에서 이동", "MSK에서 CC 컷오버로", "MSK에서 제로 컷 마이그레이션", "kcp 스캔 내 MSK"와 같은 사용자 의도 또는 MSK-CC 평가, 계획, 클러스터 크기 조정, 클러스터 연결 설정, 게이트웨이 기반 전환 또는 컷오버 후 검증에 대한 논의를 트리거합니다. MSK가 아닌 Kafka 소스(오픈 소스 Kafka, Aiven, Confluent Platform, Redpanda)에 대해서는 트리거하지 마세요. 이 기술은 MSK 전용입니다. 기존 Kafka 소스가 없는 그린필드 Confluent Cloud 프로젝트에 대해 트리거하지 마세요. 마이그레이션과 관련 없는 일반적인 Kafka 프로그래밍 질문(생산자/소비자 코드, Kafka Streams)에 대해서는 트리거하지 마세요.
