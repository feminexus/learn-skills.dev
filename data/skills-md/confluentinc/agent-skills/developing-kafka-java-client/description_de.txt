Verwenden Sie diese Option, wenn der Benutzer einen Kafka-Client in eine vorhandene Anwendung integrieren oder ein Java-Kafka-Client-Projekt (Maven- oder Gradle-basiert) für Confluent Cloud, lokales Docker oder WarpStream aufbauen möchte. Deckt die Apache Kafka Java-Clients (KafkaProducer/KafkaConsumer/KafkaShareConsumer) mit Avro-, JSON-Schema- oder Protobuf-Serialisierern ab. Wird auch verwendet, wenn der Benutzer die Java-Kafka-Clientkonfiguration für WarpStream optimieren möchte. NICHT für Kafka Streams-Apps (verwenden Sie kafka-streams-programming), Flink, Konnektoren oder den Kafka-Python-Client (verwenden Sie development-kafka-python-client) auslösen.
