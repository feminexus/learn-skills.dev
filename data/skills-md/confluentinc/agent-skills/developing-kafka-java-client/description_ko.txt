사용자가 Kafka 클라이언트를 기존 애플리케이션에 통합하거나 Confluent Cloud, 로컬 Docker 또는 WarpStream용 Java Kafka 클라이언트 프로젝트(Maven 또는 Gradle 기반)를 스캐폴드하려는 경우에 사용합니다. Avro, JSON 스키마 또는 Protobuf 직렬 변환기를 사용하여 Apache Kafka Java 클라이언트(KafkaProducer/KafkaConsumer/KafkaShareConsumer)를 다룹니다. 또한 사용자가 WarpStream에 대한 Java Kafka 클라이언트 구성을 최적화하려는 경우에도 사용합니다. Kafka Streams 앱(kafka-streams-programming 사용), Flink, 커넥터 또는 Kafka Python 클라이언트(development-kafka-python-client 사용)에 대해 트리거하지 마세요.
