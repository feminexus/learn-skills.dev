À utiliser lorsque l'utilisateur souhaite intégrer un client Kafka dans une application existante ou échafauder un projet client Java Kafka (basé sur Maven ou Gradle) pour Confluent Cloud, Docker local ou WarpStream. Couvre les clients Java Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) avec les sérialiseurs Avro, JSON Schema ou Protobuf. À utiliser également lorsque l'utilisateur souhaite optimiser la configuration du client Java Kafka pour WarpStream. Ne déclenchez PAS pour les applications Kafka Streams (utilisez kafka-streams-programming), Flink, les connecteurs ou le client Kafka Python (utilisez development-kafka-python-client).
