ユーザーが Kafka クライアントを既存のアプリケーションに統合する場合、または Confluent Cloud、ローカル Docker、または WarpStream 用の Java Kafka クライアント プロジェクト (Maven または Gradle ベース) をスキャフォールディングする場合に使用します。 Avro、JSON スキーマ、または Protobuf シリアライザーを使用した Apache Kafka Java クライアント (KafkaProducer/KafkaConsumer/KafkaShareConsumer) をカバーします。ユーザーが WarpStream 用に Java Kafka クライアント構成を最適化する場合にも使用します。 Kafka Streams アプリ (kafka-streams-programming を使用)、Flink、コネクタ、または Kafka Python クライアント (development-kafka-python-client を使用) に対してトリガーしないでください。
