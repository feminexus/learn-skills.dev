Da utilizzare quando l'utente desidera integrare un client Kafka in un'applicazione esistente o supportare un progetto client Java Kafka (basato su Maven o Gradle) per Confluent Cloud, Docker locale o WarpStream. Copre i client Java Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) con serializzatori Avro, JSON Schema o Protobuf. Utilizzare anche quando l'utente desidera ottimizzare la configurazione del client Java Kafka per WarpStream. NON eseguire l'attivazione per le app Kafka Streams (utilizzare kafka-streams-programming), Flink, connettori o client Kafka Python (utilizzare development-kafka-python-client).
