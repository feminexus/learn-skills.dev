يُستخدم عندما يريد المستخدم دمج عميل Kafka في تطبيق موجود أو دعم مشروع عميل Java Kafka (المعتمد على Maven أو Gradle) لـ Confluent Cloud أو Docker المحلي أو WarpStream. يغطي عملاء Apache Kafka Java (KafkaProducer/KafkaConsumer/KafkaShareConsumer) مع مُسلسلات Avro أو JSON Schema أو Protobuf. يُستخدم أيضًا عندما يريد المستخدم تحسين تكوين عميل Java Kafka لـ WarpStream. لا تقم بتشغيل تطبيقات Kafka Streams (استخدم برمجة kafka-streams) أو Flink أو الموصلات أو عميل Kafka Python (استخدم عميل تطوير Kafka-python).
