當使用者想要將 Kafka 用戶端整合到現有應用程式中或為 Confluence Cloud、本地 Docker 或 WarpStream 建立 Java Kafka 用戶端專案（基於 Maven 或 Gradle）時使用。涵蓋具有 Avro、JSON Schema 或 Protobuf 序列化程式的 Apache Kafka Java 用戶端 (KafkaProducer/KafkaConsumer/KafkaShareConsumer)。當使用者想要優化 WarpStream 的 Java Kafka 用戶端設定時也可以使用。不要觸發 Kafka Streams 應用程式（使用 kafka-streams-programming）、Flink、連接器或 Kafka Python 用戶端（使用development-kafka-python-client）。
