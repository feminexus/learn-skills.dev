Используйте, когда пользователь хочет интегрировать клиент Kafka в существующее приложение или создать проект клиента Java Kafka (на основе Maven или Gradle) для Confluent Cloud, локального Docker или WarpStream. Охватывает Java-клиенты Apache Kafka (KafkaProducer/KafkaConsumer/KafkaShareConsumer) с сериализаторами Avro, JSON Schema или Protobuf. Также используйте, когда пользователь хочет оптимизировать конфигурацию клиента Java Kafka для WarpStream. НЕ запускайте триггер для приложений Kafka Streams (используйте kafka-streams-programming), Flink, соединителей или клиента Kafka Python (используйте development-kafka-python-client).
