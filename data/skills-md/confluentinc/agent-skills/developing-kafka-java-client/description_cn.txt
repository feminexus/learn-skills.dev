当用户想要将 Kafka 客户端集成到现有应用程序中或为 Confluence Cloud、本地 Docker 或 WarpStream 搭建 Java Kafka 客户端项目（基于 Maven 或 Gradle）时使用。涵盖具有 Avro、JSON Schema 或 Protobuf 序列化程序的 Apache Kafka Java 客户端 (KafkaProducer/KafkaConsumer/KafkaShareConsumer)。当用户想要优化 WarpStream 的 Java Kafka 客户端配置时也可以使用。不要触发 Kafka Streams 应用程序（使用 kafka-streams-programming）、Flink、连接器或 Kafka Python 客户端（使用development-kafka-python-client）。
