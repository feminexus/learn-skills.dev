Kafka を介したストリーム処理のために Java で Apache Flink ユーザー定義関数 (UDF) を構築してデプロイします。ユーザーが Java でスカラー UDF、ユーザー定義テーブル関数 (UDTF)、またはプロセス テーブル関数 (PTF) を作成し、それらを Confluent Cloud またはローカル Docker 環境にデプロイし、Flink SQL または Table API から呼び出したい場合は、このスキルを使用します。トリガー: Flink UDF、カスタム Flink 関数、プロセス テーブル関数、PTF、UDTF、Flink ユーザー定義、Flink SQL の拡張、Flink を使用したステートフル ストリーム処理。以下に対してトリガーしないでください: Kafka Streams UDF (kafka-streams-programming スキルを使用)、カスタム関数を使用しない一般的な Flink ジョブ開発、Flink を含む CDC ストリーミング データ パイプライン (confluent-cloud-cdc-tableflow スキルを推奨)、Flink コネクタのセットアップ、または Kafka プロデューサー/コンシューマー コード。
