Erstellen und implementieren Sie benutzerdefinierte Apache Flink-Funktionen (UDFs) in Java für die Stream-Verarbeitung über Kafka. Verwenden Sie diese Fähigkeit, wenn Benutzer skalare UDFs, benutzerdefinierte Tabellenfunktionen (UDTFs) oder Prozesstabellenfunktionen (PTFs) in Java erstellen, sie in Confluent Cloud oder lokalen Docker-Umgebungen bereitstellen und sie über Flink SQL oder die Tabellen-API aufrufen möchten. Trigger auf: Flink UDF, benutzerdefinierte Flink-Funktion, Prozesstabellenfunktion, PTF, UDTF, Flink benutzerdefiniert, Flink SQL erweitern, Stateful Stream-Verarbeitung mit Flink. NICHT auslösen für: Kafka Streams UDFs (verwenden Sie den Kafka-Streams-Programmier-Skill), allgemeine Flink-Jobentwicklung ohne benutzerdefinierte Funktionen, CDC-Streaming-Daten-Piplines, die Flink enthalten (bevorzugen Sie den Confluent-Cloud-CDC-Tableflow-Skill), Flink-Connector-Setup oder Kafka Producer/Consumer-Code.
