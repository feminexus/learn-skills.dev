قم ببناء ونشر وظائف Apache Flink المعرفة بواسطة المستخدم (UDFs) في Java لمعالجة الدفق عبر Kafka. استخدم هذه المهارة عندما يريد المستخدمون إنشاء وحدات UDF عددية، أو وظائف جدول محددة من قبل المستخدم (UDTFs)، أو وظائف جدول العمليات (PTFs) في Java، ونشرها في Confluent Cloud أو بيئات Docker المحلية، واستدعائها من Flink SQL أو Table API. تشغيل: Flink UDF، وظيفة Flink المخصصة، وظيفة جدول العمليات، PTF، UDTF، تعريف مستخدم Flink، تمديد Flink SQL، معالجة التدفق ذات الحالة باستخدام Flink. لا تقم بتشغيل: Kafka Streams UDFs (استخدم مهارة برمجة kafka-streams)، أو تطوير وظائف Flink العامة بدون وظائف مخصصة، أو خطوط أنابيب بيانات تدفق CDC التي تتضمن Flink (تفضل مهارة تدفق الجداول المتدفقة، السحابية، cdc)، أو إعداد موصل Flink، أو رمز المنتج/المستهلك Kafka.
