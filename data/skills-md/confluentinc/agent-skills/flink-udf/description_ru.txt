Создавайте и развертывайте пользовательские функции (UDF) Apache Flink на Java для потоковой обработки через Kafka. Используйте этот навык, когда пользователи хотят создавать скалярные пользовательские функции, определяемые пользователем табличные функции (UDTF) или табличные функции обработки (PTF) на Java, развертывать их в Confluent Cloud или локальных средах Docker и вызывать их из Flink SQL или Table API. Запуск по: Flink UDF, пользовательской функции Flink, функции таблицы обработки, PTF, UDTF, определяемому пользователем Flink, расширению Flink SQL, обработке потока с отслеживанием состояния с помощью Flink. НЕ запускайте для: пользовательских функций Kafka Streams (используйте навыки программирования kafka-streams), общей разработки заданий Flink без пользовательских функций, конвейеров потоковых данных CDC, включающих Flink (предпочитайте навык confluent-cloud-cdc-tableflow), настройки соединителя Flink или кода производителя/потребителя Kafka.
