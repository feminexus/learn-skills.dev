Créez et déployez des fonctions définies par l'utilisateur (UDF) Apache Flink en Java pour le traitement des flux sur Kafka. Utilisez cette compétence lorsque les utilisateurs souhaitent créer des UDF scalaires, des fonctions de table définies par l'utilisateur (UDTF) ou des fonctions de table de processus (PTF) en Java, les déployer sur Confluent Cloud ou dans des environnements Docker locaux, et les appeler à partir de Flink SQL ou de l'API Table. Déclencheur sur : Flink UDF, fonction Flink personnalisée, fonction de table de processus, PTF, UDTF, Flink défini par l'utilisateur, extension Flink SQL, traitement de flux avec état avec Flink. Ne déclenchez PAS pour : les UDF Kafka Streams (utilisez la compétence de programmation kafka-streams), le développement général de tâches Flink sans fonctions personnalisées, les pipelines de données de streaming CDC qui incluent Flink (préférez la compétence confluent-cloud-cdc-tableflow), la configuration du connecteur Flink ou le code producteur/consommateur Kafka.
