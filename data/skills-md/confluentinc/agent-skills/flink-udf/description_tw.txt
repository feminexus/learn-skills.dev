使用 Java 建置和部署 Apache Flink 使用者定義函數 (UDF)，以便透過 Kafka 進行串流處理。當使用者想要用 Java 建立標量 UDF、使用者定義表函數 (UDTF) 或行程表函數 (PTF)，將它們部署到 Confluence Cloud 或本機 Docker 環境，並從 Flink SQL 或 Table API 呼叫它們時，請使用此技能。觸發：Flink UDF、自訂 Flink 函數、處理表函數、PTF、UDTF、Flink 使用者定義、擴充 Flink SQL、使用 Flink 有狀態流程處理。請勿觸發：Kafka Streams UDF（使用 kafka-streams-programming 技能）、不含自訂函數的常規 Flink 作業開發、包含 Flink 的 CDC 串流資料管道（首選 confluence-cloud-cdc-tableflow 技能）、Flink 連接器設定或 Kafka 生產者/消費者代碼。
