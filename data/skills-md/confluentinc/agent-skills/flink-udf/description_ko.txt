Kafka를 통한 스트림 처리를 위해 Java로 Apache Flink 사용자 정의 함수(UDF)를 구축하고 배포합니다. 사용자가 Java에서 스칼라 UDF, 사용자 정의 테이블 함수(UDTF) 또는 프로세스 테이블 함수(PTF)를 생성하고 이를 Confluent Cloud 또는 로컬 Docker 환경에 배포하고 Flink SQL 또는 Table API에서 호출하려는 경우 이 기술을 사용합니다. 트리거 대상: Flink UDF, 사용자 정의 Flink 함수, 프로세스 테이블 함수, PTF, UDTF, Flink 사용자 정의, Flink SQL 확장, Flink를 통한 상태 저장 스트림 처리. Kafka Streams UDF(kafka-streams-programming 기술 사용), 사용자 지정 기능이 없는 일반 Flink 작업 개발, Flink를 포함하는 CDC 스트리밍 데이터 파이프라인(confluent-cloud-cdc-tableflow 기술 선호), Flink 커넥터 설정 또는 Kafka 생산자/소비자 코드에 대해서는 트리거하지 마세요.
