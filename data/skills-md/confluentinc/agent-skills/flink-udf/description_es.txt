Cree e implemente funciones definidas por el usuario (UDF) de Apache Flink en Java para el procesamiento de transmisiones a través de Kafka. Utilice esta habilidad cuando los usuarios quieran crear UDF escalares, funciones de tabla definidas por el usuario (UDTF) o funciones de tabla de proceso (PTF) en Java, implementarlas en Confluent Cloud o entornos Docker locales e invocarlas desde Flink SQL o Table API. Activación: Flink UDF, función de Flink personalizada, función de tabla de proceso, PTF, UDTF, Flink definido por el usuario, extensión de Flink SQL, procesamiento de flujo con estado con Flink. NO active para: UDF de Kafka Streams (use la habilidad de programación kafka-streams), desarrollo general de trabajos de Flink sin funciones personalizadas, líneas de datos de transmisión de CDC que incluyan Flink (prefiera la habilidad confluent-cloud-cdc-tableflow), configuración del conector de Flink o código de productor/consumidor de Kafka.
