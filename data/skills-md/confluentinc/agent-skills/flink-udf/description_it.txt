Crea e distribuisci funzioni definite dall'utente (UDF) Apache Flink in Java per l'elaborazione del flusso su Kafka. Utilizza questa competenza quando gli utenti desiderano creare UDF scalari, funzioni di tabella definite dall'utente (UDTF) o funzioni di tabella di processo (PTF) in Java, distribuirle in Confluent Cloud o ambienti Docker locali e richiamarle da Flink SQL o dall'API Table. Attivazione: Flink UDF, funzione Flink personalizzata, funzione tabella di processo, PTF, UDTF, Flink definito dall'utente, estensione Flink SQL, elaborazione del flusso con stato con Flink. NON eseguire l'attivazione per: UDF Kafka Streams (utilizzare la competenza di programmazione kafka-streams), sviluppo generale di processi Flink senza funzioni personalizzate, pipeline di dati di streaming CDC che includono Flink (preferire la competenza confluent-cloud-cdc-tableflow), configurazione del connettore Flink o codice produttore/consumatore Kafka.
