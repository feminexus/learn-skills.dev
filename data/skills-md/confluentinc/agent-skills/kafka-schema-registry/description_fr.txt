Analysez un projet pour identifier les applications Kafka, extrayez les schémas des modèles de données, marquez les champs PII, générez l'enregistrement Terraform pour Confluent Schema Registry et produisez un rapport de migration avec l'ordre de déploiement. Utilisez cette compétence lorsqu'un utilisateur demande d'analyser un dossier ou un dépôt pour une utilisation Kafka, d'extraire des schémas, d'auditer les configurations producteur/consommateur ou de générer Terraform pour le registre de schémas.
