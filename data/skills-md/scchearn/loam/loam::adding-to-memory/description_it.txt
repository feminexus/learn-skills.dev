Leggere un file sorgente locale o sintetizzare il contesto di una conversazione, quindi integrare il contenuto ammesso direttamente nelle pagine di argomenti, entità, concetti e analisi nella memoria esistente (il substrato wiki). Utilizzalo quando l'utente desidera aggiungere una fonte al wiki, aggiungere un documento, importare una nota locale, una trascrizione, un articolo, un rapporto o un PDF o preservare esplicitamente la conversazione corrente come nota sull'argomento. Per l'instradamento dell'apprendimento della sessione attraverso wiki, guida, punto di controllo, annotazione di attività o eliminazione, utilizzare /loam::learning-from-session. Non deve importare un obiettivo all'ingrosso; ammettere solo risultati riutilizzabili in modo indipendente.
