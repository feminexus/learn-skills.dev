Corrija o actualice el contenido wiki existente cuando evidencia más reciente muestre que el wiki es incorrecto, obsoleto, incompleto o contradictorio. Use esto cuando el agente descubra que el wiki dice X pero ahora sabemos Y, cuando el código o los cambios en el mundo real invalidan un reclamo del wiki, o cuando el usuario solicita arreglar o modificar el wiki. No para agregar nuevas fuentes, capturar aprendizajes de rutina, normalización estructural o controles de salud; use /loam::adding-to-memory, /loam::learning-from-session, /loam::normalizing-memory o /loam::linting-memory.
