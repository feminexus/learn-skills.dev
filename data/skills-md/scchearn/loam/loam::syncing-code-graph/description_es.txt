Concilie el gráfico de código en la memoria (sustrato wiki) con el código base real. En el modo --touched, resume solo los archivos que un plan completo tocó (barato, puerta posterior al plan). En el modo --sweep, recorre todo el repositorio y los parches derivan de las ediciones fuera de banda. Se acepta deriva entre puertas; esta habilidad es el único lugar donde el gráfico de código se reconcilia con el árbol de repositorio.
