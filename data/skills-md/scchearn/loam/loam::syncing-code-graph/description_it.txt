Riconciliare il grafico del codice in memoria (substrato wiki) con la base di codice effettiva. Nella modalità --touched, riassume solo i file toccati da un piano completato (cancello economico, post-piano). Nella modalità --sweep, percorre l'intero repository e le patch derivano dalle modifiche fuori banda. La deriva è accettata tra i cancelli; questa abilità è l'unico posto in cui il grafico del codice viene riconciliato con l'albero dei repository.
