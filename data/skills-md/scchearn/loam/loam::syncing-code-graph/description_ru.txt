Согласуйте график кода в памяти (вики-подложку) с фактической кодовой базой. В режиме --touched повторно суммируются только файлы, к которым был применен завершенный план (дешевый, ворота после плана). В режиме --sweep обходит весь репозиторий и патчи отклоняются от нестандартных изменений. Между воротами допускается занос; этот навык — единственное место, где граф кода согласовывается с деревом репо.
