Gleichen Sie den Codegraphen im Speicher (Wiki-Substrat) mit der tatsächlichen Codebasis ab. Im --touched-Modus werden nur Dateien neu zusammengefasst, die ein abgeschlossener Plan berührt hat (billig, Post-Plan-Gate). Durchläuft im --sweep-Modus das gesamte Repo und Patches weichen von Out-of-Band-Bearbeitungen ab. Drift wird zwischen Toren akzeptiert; Diese Fähigkeit ist der einzige Ort, an dem der Codegraph mit dem Repo-Baum abgeglichen wird.
