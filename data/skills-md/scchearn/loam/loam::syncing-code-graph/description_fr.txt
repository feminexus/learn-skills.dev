Réconciliez le graphe de code en mémoire (substrat wiki) avec la base de code réelle. En mode --touched, résume uniquement les fichiers d'un plan terminé touché (pas cher, porte post-plan). En mode --sweep, parcourt l'ensemble du dépôt et les correctifs dérivent des modifications hors bande. La dérive est acceptée entre les portes ; cette compétence est le seul endroit où le graphe de code est rapproché de l'arborescence du référentiel.
