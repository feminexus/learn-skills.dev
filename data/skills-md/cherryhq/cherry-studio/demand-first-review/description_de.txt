Wird verwendet, wenn ein PR, eine API, ein IPC-Kanal, ein Endpunkt, ein Parameter, ein Typ, eine Konfiguration oder ein architektonischer Erweiterungspunkt überprüft wird, der eine gemeinsame Oberfläche hinzufügt oder erweitert, insbesondere wenn Verbraucher abwesend sind, Exporte ungenutzt oder spekulativ sind, vorhandene Verbraucher hacklastig sind, Vorwärtskompatibilität beansprucht wird oder mehrere ähnliche APIs eine Anforderung zum Ausdruck bringen können.
