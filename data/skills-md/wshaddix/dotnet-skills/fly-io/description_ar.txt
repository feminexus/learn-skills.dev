نشر التطبيقات وتكوينها وإدارتها على منصة Fly.io باستخدام flyctl CLI، وتكوين fly.toml، وFly Machines، وFly Volumes، والشبكات الخاصة، والأسرار، والفحوصات الصحية، والقياس التلقائي، وGitHub Actions CI/CD. يُستخدم عند نشر أي تطبيق على Fly.io، أو كتابة أو تعديل تكوين fly.toml، أو إدارة Fly Machines أو وحدات التخزين، أو تكوين الشبكات (الخدمات العامة، أو 6PN الخاص، أو Flycast، أو المجالات المخصصة، أو TLS)، أو إعداد الأسرار، أو تكوين عمليات التحقق من الصحة، أو إعداد الإيقاف التلقائي/التشغيل التلقائي أو القياس التلقائي القائم على المقاييس، أو النشر باستخدام GitHub Actions، أو إدارة قواعد بيانات Fly Postgres، أو إعداد تطبيق للإنتاج على Fly.io.
