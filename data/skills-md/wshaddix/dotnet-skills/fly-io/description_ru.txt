Развертывайте, настраивайте и управляйте приложениями на платформе Fly.io с помощью интерфейса командной строки Flyctl, конфигурации Fly.toml, Fly Machines, Fly Volumes, частной сети, секретов, проверок работоспособности, автоматического масштабирования и GitHub Actions CI/CD. Используйте при развертывании любого приложения в Fly.io, написании или изменении конфигурации Fly.toml, управлении Fly Machines или Volumes, настройке сети (публичные службы, частные 6PN, Flycast, пользовательские домены, TLS), настройке секретов, настройке проверок работоспособности, настройке автостопа/автозапуска или автомасштабирования на основе метрик, развертывании с помощью GitHub Actions, управлении базами данных Fly Postgres или подготовке приложения к работе на Fly.io.
