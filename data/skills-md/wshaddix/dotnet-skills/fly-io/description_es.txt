Implemente, configure y administre aplicaciones en la plataforma Fly.io utilizando flyctl CLI, configuración fly.toml, Fly Machines, Fly Volumes, redes privadas, secretos, comprobaciones de estado, escalado automático y GitHub Actions CI/CD. Úselo al implementar cualquier aplicación en Fly.io, escribir o modificar la configuración de fly.toml, administrar máquinas o volúmenes Fly, configurar redes (servicios públicos, 6PN privado, Flycast, dominios personalizados, TLS), configurar secretos, configurar controles de estado, configurar la parada/inicio automático o el escalado automático basado en métricas, implementar con acciones de GitHub, administrar bases de datos de Fly Postgres o preparar una aplicación para producción en Fly.io.
