Комплексные шаблоны обработки исключений для приложений ASP.NET Core Razor Pages. Охватывает глобальную обработку исключений, API-интерфейс IssueDetails, настраиваемые страницы ошибок, промежуточное программное обеспечение исключений и стратегии постепенного снижения производительности. Используйте при реализации обработки ошибок в приложениях Razor Pages, настройке глобального промежуточного программного обеспечения исключений или создании удобных для пользователя страниц ошибок и ответов на ошибки API.
