Configurez Aspire AppHost pour émettre une configuration d'application explicite via des variables d'environnement tout en gardant le code d'application exempt de clients Aspire et de découverte de services. À utiliser lors du câblage des ressources AppHost à la configuration de l'application, en garantissant que la configuration de production est transparente et portable en dehors d'Aspire, ou en évitant les packages clients Aspire dans le code de l'application.
