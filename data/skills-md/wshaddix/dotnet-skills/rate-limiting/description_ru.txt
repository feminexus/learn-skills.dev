Шаблоны ограничения скорости для приложений ASP.NET Core Razor Pages. Охватывает фиксированное окно, скользящее окно, алгоритмы сегмента токенов и распределенное ограничение скорости с помощью Redis. Используйте при реализации ограничения скорости в приложениях ASP.NET Core, выборе между различными алгоритмами ограничения скорости или настройке распределенного ограничения скорости с помощью Redis.
