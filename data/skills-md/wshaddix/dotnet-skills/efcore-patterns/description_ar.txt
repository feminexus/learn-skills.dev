أفضل ممارسات Entity Framework Core بما في ذلك NoTracking افتراضيًا، وتقسيم الاستعلام لمجموعات التنقل، وإدارة الترحيل، وخدمات الترحيل المخصصة، والاعتراضات، والاستعلامات المجمعة، ومرونة الاتصال. يُستخدم عند إعداد EF Core في مشروع جديد، أو تحسين أداء الاستعلام، أو إدارة عمليات ترحيل قاعدة البيانات، أو دمج EF Core مع .NET Aspire، أو تصحيح مشكلات تتبع التغيير.
