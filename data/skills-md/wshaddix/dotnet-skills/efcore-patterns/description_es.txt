Las mejores prácticas de Entity Framework Core incluyen NoTracking de forma predeterminada, división de consultas para colecciones de navegación, administración de migración, servicios de migración dedicados, interceptores, consultas compiladas y resiliencia de conexión. Úselo al configurar EF Core en un nuevo proyecto, optimizar el rendimiento de las consultas, administrar migraciones de bases de datos, integrar EF Core con .NET Aspire o depurar problemas de seguimiento de cambios.
