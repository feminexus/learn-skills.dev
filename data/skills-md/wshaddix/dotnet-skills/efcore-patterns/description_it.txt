Best practice di Entity Framework Core, tra cui NoTracking per impostazione predefinita, suddivisione delle query per raccolte di navigazione, gestione della migrazione, servizi di migrazione dedicati, intercettori, query compilate e resilienza della connessione. Da utilizzare durante la configurazione di EF Core in un nuovo progetto, l'ottimizzazione delle prestazioni delle query, la gestione delle migrazioni dei database, l'integrazione di EF Core con .NET Aspire o il debug dei problemi di rilevamento delle modifiche.
