Modelli IHttpClientFactory con Polly per tentativi, interruttori automatici, timeout e comunicazione HTTP resiliente. Include le migliori pratiche per la configurazione del client HTTP e la gestione degli errori. Da utilizzare durante la configurazione di client HTTP resilienti in ASP.NET Core, l'implementazione di criteri di ripetizione con Polly o la configurazione di interruttori di circuito per le chiamate di servizio esterne.
