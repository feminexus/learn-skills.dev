Patrones IHttpClientFactory con Polly para reintentos, disyuntores, tiempos de espera y comunicación HTTP resistente. Úselo al configurar clientes HTTP resistentes en ASP.NET Core, implementar políticas de reintento con Polly o configurar disyuntores para llamadas de servicio externo.
