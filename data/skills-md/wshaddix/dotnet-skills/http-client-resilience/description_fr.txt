Modèles IHttpClientFactory avec Polly pour les tentatives, les disjoncteurs, les délais d'attente et la communication HTTP résiliente. Inclut les meilleures pratiques pour la configuration du client HTTP et la gestion des erreurs. À utiliser lors de la configuration de clients HTTP résilients dans ASP.NET Core, de la mise en œuvre de stratégies de nouvelle tentative avec Polly ou de la configuration de disjoncteurs pour les appels de service externes.
