Шаблоны IHttpClientFactory с Polly для повторных попыток, автоматических выключателей, тайм-аутов и устойчивой HTTP-связи. Включает лучшие практики по настройке HTTP-клиента и обработке ошибок. Используйте при настройке отказоустойчивых HTTP-клиентов в ASP.NET Core, реализации политик повторных попыток с помощью Polly или настройке автоматических выключателей для вызовов внешних служб.
