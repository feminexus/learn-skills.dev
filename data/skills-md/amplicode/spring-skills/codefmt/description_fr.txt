Reformatez le code source de ce projet en utilisant ses propres paramètres de style de code - via l'IDE IntelliJ lorsqu'il est en cours d'exécution, sinon via le propre formateur du projet (Spotless / google-java-format / palantir-java-format) comme solution de secours. Utilisez-le chaque fois que l'utilisateur demande de formater, reformater, ranger, « embellir », corriger l'indentation ou optimiser les importations sur Java/Kotlin/XML/etc. fichiers - qu'il s'agisse d'un seul fichier nommé, d'un bloc ou d'une plage de lignes sélectionnée, d'un groupe de fichiers nommés ou de tous les fichiers non validés (modifiés par git). Cette compétence est également normalement invoquée après toute modification de fichiers : appliquez-la aux fichiers que vous venez de créer ou de modifier une fois les modifications terminées, afin que le résultat reste cohérent avec le style de code du projet.
