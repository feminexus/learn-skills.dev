자체 코드 스타일 설정을 사용하여 이 프로젝트의 소스 코드 형식을 다시 지정합니다. 실행 중일 때는 IntelliJ IDE를 통해, 그렇지 않으면 프로젝트 자체 포맷터(Spotless / google-java-format / palantir-java-format)를 대체 수단으로 사용합니다. 사용자가 Java/Kotlin/XML/등에서 형식 지정, 재형식 지정, 정리, "가꾸기", 들여쓰기 수정 또는 가져오기 최적화를 요청할 때마다 이 기능을 사용하세요. 파일 — 이름이 지정된 단일 파일, 선택한 블록 또는 줄 범위, 이름이 지정된 파일 그룹 또는 커밋되지 않은 모든(git-changed) 파일인지 여부. 이 기술은 일반적으로 파일을 편집한 후에도 호출됩니다. 편집이 완료된 후 방금 생성하거나 변경한 파일에 적용하면 결과가 프로젝트의 코드 스타일과 일관되게 유지됩니다.
