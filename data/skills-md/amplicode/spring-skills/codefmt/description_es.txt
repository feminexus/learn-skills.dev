Vuelva a formatear el código fuente en este proyecto usando su propia configuración de estilo de código, a través del IDE de IntelliJ cuando se está ejecutando; de lo contrario, a través del formateador propio del proyecto (Spotless / google-java-format / palantir-java-format) como alternativa. Úselo siempre que el usuario solicite formatear, reformatear, ordenar, "embellecer", corregir sangrías u optimizar las importaciones en Java/Kotlin/XML/etc. archivos: ya sea un archivo con un solo nombre, un bloque seleccionado o rango de líneas, un grupo de archivos con nombre o todos los archivos no confirmados (cambiados por git). Esta habilidad normalmente también se invoca después de cualquier edición de archivos: aplíquela a los archivos que acaba de crear o modificó una vez realizadas las ediciones, para que el resultado sea consistente con el estilo de código del proyecto.
