Riformatta il codice sorgente in questo progetto utilizzando le proprie impostazioni di stile di codice, tramite l'IDE IntelliJ quando è in esecuzione, altrimenti tramite il formattatore del progetto (Spotless / google-java-format / palantir-java-format) come fallback. Utilizzalo ogni volta che l'utente chiede di formattare, riformattare, riordinare, "abbellire", correggere il rientro o ottimizzare le importazioni su Java/Kotlin/XML/ecc. file: che si tratti di un singolo file con nome, di un blocco selezionato o di un intervallo di righe, di un gruppo di file con nome o di tutti i file non salvati (modificati con git). Questa abilità viene normalmente richiamata anche dopo qualsiasi modifica dei file: applicala ai file appena creati o modificati una volta eseguite le modifiche, in modo che il risultato rimanga coerente con lo stile del codice del progetto.
