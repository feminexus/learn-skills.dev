Generación y configuración de código OpenAPI de Worma. Utilice esta habilidad siempre que el usuario mencione la configuración de worma, la generación de código API, la integración OpenAPI/Swagger, la CLI de worma o la migración desde @alova/wormhole, axios o ky. Activador para preguntas sobre worma.config, npx worma init/gen, generación de código API a partir de especificaciones de OpenAPI o cambio de @alova/wormhole, axios o ky a worma.
