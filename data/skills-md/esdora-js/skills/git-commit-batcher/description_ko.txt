현재 Git 변경 사항을 분석하고 이를 취소 가능한 최소 커밋 배치로 분할하고 명시적인 확인 후 기존 커밋 초안을 작성하거나 실행합니다. 사용자가 Git 변경 사항을 검사하고, 커밋 메시지를 생성하고, 의도에 따라 커밋을 분할하고, 단계적 또는 단계적이지 않은 작업을 커밋하거나 "帮我提交", "生成提交批次", "commit Changes", "split commits", "拆分 commit", "按 Conventional Commits 提交" 또는 "生成 commit message"와 같은 문구를 말하고 싶을 때 트리거됩니다. 모든 에이전트 도구에서 작동합니다. 에이전트별 항목 파일은 이러한 규칙을 복사하는 대신 여기로 라우팅되는 얇은 셸을 유지해야 합니다.
