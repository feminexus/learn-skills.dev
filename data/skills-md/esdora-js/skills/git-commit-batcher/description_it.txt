Analizza le modifiche Git attuali, suddividile in batch di commit minimi reversibili e redige o esegui commit convenzionali dopo la conferma esplicita. Si attiva quando l'utente desidera ispezionare le modifiche Git, generare messaggi di commit, dividere i commit per intento, eseguire il commit di lavoro in fasi o non, o pronuncia frasi come "帮我提交", "生成提交批次", "commit modifiche", "split commits", "拆分 commit", "按 Conventional Commits 提交" o "生成 commit" messaggio". Funziona con qualsiasi strumento agente; i file di ingresso specifici dell'agente devono rimanere shell sottili che instradano qui invece di copiare queste regole.
