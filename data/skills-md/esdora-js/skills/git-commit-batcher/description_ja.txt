現在の Git の変更を分析し、それらを元に戻せる最小限のコミット バッチに分割し、明示的な確認後に従来のコミットを作成または実行します。ユーザーが Git の変更の検査、コミット メッセージの生成、意図によるコミットの分割、ステージングされた作業またはステージングされていない作業のコミットを希望する場合、または「帮我提交」、「生成提交批次」、「コミット変更」、「分割コミット」、「拆分コミット」、「按従来型コミット提交」、または「生成コミット メッセージ」などのフレーズを言ったときにトリガーします。どのエージェント ツールでも機能します。エージェント固有のエントリ ファイルは、これらのルールをコピーするのではなく、ここにルーティングするシン シェルのままでなければなりません。
