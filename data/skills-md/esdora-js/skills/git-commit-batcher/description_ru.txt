Анализируйте текущие изменения Git, разбивайте их на минимальные обратимые пакеты коммитов и составляйте проекты или выполняйте обычные коммиты после явного подтверждения. Срабатывает, когда пользователь хочет проверить изменения Git, сгенерировать сообщения о фиксации, разделить коммиты по намерению, зафиксировать промежуточную или непроиндексированную работу или произнес такие фразы, как «帮我提交», «生成提交批次», «зафиксировать изменения», «разделить коммиты», «拆分 commit», «按 Обычные коммиты 提交» или «生成 commit». сообщение». Работает для любого агентского инструмента; файлы записей, специфичные для агента, должны оставаться тонкими оболочками, которые направляются сюда, а не копируют эти правила.
