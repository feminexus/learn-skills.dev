Стандарты разработки Vue 3 + TypeScript. Используйте этот навык при создании приложений Vue 3 с помощью Composition API, Pinia, UnoCSS и SCSS. Охватывает именование, архитектуру CSS, структуру компонентов, шаблоны API и качество кода. Независимость от UI-библиотеки (Element Plus, Ant Design Vue и т. д.).
