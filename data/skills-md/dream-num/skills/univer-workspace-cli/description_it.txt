Da utilizzare durante l'installazione o l'utilizzo dell'applicazione CLI Univer Workspace indipendente (`univer-workspace-cli`) per file di Workspace remoti, spazi personali o del team, alberi di lavoro delle attività, unità foglio/documento/diapositiva, creazione di facciate, ispezione, verifica, importazione/esportazione, screenshot o trasferimento di revisione. Non utilizzare per target locali gestiti da "univer".
