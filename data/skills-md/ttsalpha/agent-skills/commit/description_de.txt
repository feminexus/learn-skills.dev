Führen Sie Git-Commits mit herkömmlicher Commit-Nachrichtenanalyse und -generierung aus. Verwenden Sie diese Option, wenn der Benutzer Änderungen festschreiben, eine Festschreibungsnachricht schreiben oder bereitgestellte Änderungen überprüfen möchte. Unterstützt die automatische Erkennung von Typ/Bereich aus Diff, das Generieren von Nachrichten und das intelligente Staging von Dateien.
