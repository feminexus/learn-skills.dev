Выполняйте коммиты git с помощью обычного анализа и генерации сообщений о коммитах. Используйте, когда пользователь просит зафиксировать изменения, написать сообщение о фиксации или просмотреть поэтапные изменения. Поддерживает автоматическое определение типа/области на основе различий, генерацию сообщений и интеллектуальное размещение файлов.
