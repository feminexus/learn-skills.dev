Debuggen Sie CI-Fehler im Rstack-Ökosystem und weisen Sie die tatsächliche Quell-PR oder nachgelagerte Änderung zu. Verwenden Sie diese Fähigkeit immer, wenn der Benutzer Rspack eco-ci, rstack-ecosystem-ci, eine rot werdende Suite, eine Downstream-Regression, einen Grün-zu-Rot-Pivot, Canary Bisect, @rspack-canary/core oder die tägliche Eco-CI-Triage erwähnt – auch wenn er nur fragt: „Warum schlägt diese Suite fehl“, „welcher PR sie kaputt gemacht hat“ oder „Ist dieser Rspack schuld?“. Verwenden Sie es, um zu vermeiden, dass dem ersten Rspack-Commit, der in den Statusdaten rot angezeigt wird, zu viele Vorwürfe gemacht werden.
