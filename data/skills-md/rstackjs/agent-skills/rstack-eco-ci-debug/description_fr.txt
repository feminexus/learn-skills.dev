Déboguez les échecs de CI de l’écosystème Rstack et attribuez le véritable PR source ou le changement en aval. Utilisez toujours cette compétence lorsque l'utilisateur mentionne Rspack eco-ci, rstack-ecosystem-ci, une suite tournant au rouge, une régression en aval, un pivot vert vers rouge, une bissecte canari, @rspack-canary/core ou un tri éco-ci quotidien - même s'il demande seulement « pourquoi cette suite échoue-t-elle », « quel PR l'a cassé » ou « est-ce la faute de Rspack ». Utilisez-le pour éviter de trop blâmer le premier commit Rspack qui apparaît en rouge dans les données d'état.
