Rstack エコシステム CI の障害をデバッグし、実際のソース PR またはダウンストリームの変更の原因を特定します。ユーザーが Rspack eco-ci、rstack-ecosystem-ci、赤になったスイート、ダウンストリーム回帰、緑から赤へのピボット、カナリア二分法、@rspack-canary/core、または毎日の Eco-CI トリアージについて言及した場合は、常にこのスキルを使用してください。たとえ「このスイートが失敗した理由」、「どの PR が問題を破ったのか」、または「この Rspack のせいですか」と尋ねただけの場合でも同様です。これを使用して、ステータス データで赤色で表示される最初の Rspack コミットを過度に非難しないようにします。
