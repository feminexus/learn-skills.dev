تحسين ورق الذكاء الاصطناعي الطبي لمحركات بحث الذكاء الاصطناعي (Perplexity، وChatGPT web، وElicit، وConsensus، وSciSpace) وأدوات الأدب المستندة إلى RAG. ينطبق عند صياغة أو مراجعة العناوين والملخصات ومربعات الملخصات المنظمة (النقاط الرئيسية / البحث في السياق / ملخص اللغة البسيطة)، والمخطوطات الخاصة بمجلات الذكاء الاصطناعي الطبية عالية التأثير (Lancet Digital Health، Radiology، Radiology-AI، npj Digital Medicine، Nature Medicine)، المطبوعات الأولية (medRxiv/arXiv)، GitHub README + CITATION.cff + أرشيفات Zenodo، وبطاقات نماذج/مجموعة بيانات Hugging Face. يدمج متطلبات إعداد التقارير TRIPOD+AI وCLAIM 2024 وSTARD-AI وTRIPOD-LLM وDECIDE-AI مع مبادئ تحسين المحرك التوليدي (GEO). يُنتج قائمة مرجعية مرئية للنجاح/الفشل.
