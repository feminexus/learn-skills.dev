Оптимизация медицинских статей по искусственному интеллекту для поисковых систем искусственного интеллекта (Perplexity, ChatGPT web, Elicit, Consensus, SciSpace) и литературных инструментов на основе RAG. Применяется при составлении или рецензировании заголовков, рефератов, структурированных сводных блоков (ключевые моменты / исследования в контексте / краткое изложение на простом языке), рукописей для влиятельных медицинских журналов по искусственному интеллекту (Lancet Digital Health, Radiology, Radiology-AI, npj Digital Medicine, Nature Medicine), препринтов (medRxiv/arXiv), архивов GitHub README + CITATION.cff + Zenodo и карточек моделей/наборов данных Hugging Face. Интегрирует требования к отчетности TRIPOD+AI, CLAIM 2024, STARD-AI, TRIPOD-LLM, DECIDE-AI с принципами генеративной оптимизации двигателя (GEO). Создает видимый контрольный список «прошел/не прошел».
