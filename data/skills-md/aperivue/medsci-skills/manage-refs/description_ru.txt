Менеджер по сквозным ссылкам на медицинские рукописи. Единая точка входа для проверки ключа цитирования, рендеринга pandoc журнала-CSL, контроля качества рукописи ↔ перекрестных ссылок DOCX, преобразования маркеров (``[N]`` ↔ ``[@key]``) и встроенного кода поля Zotero CWYW. Заменяет встроенную обработку ссылок, которая ранее существовала в ``/write-paper`` Фазе 7.6 и повторно используется ``/revise``, ``/peer-review``, ``/sync-submission`` и любыми навыками, которые создают публикацию в журнале. Проверка только для аудита остается в ``/verify-refs`` — этот навык записывает (рендерит, внедряет, конвертирует); этот навык только читает.
