Rendu des documents académiques Markdown (anglais ou coréen) au format PDF de qualité publication via pandoc + xelatex. Cible les artefacts non bibliographiques : propositions de recherche, lettres d'accompagnement de l'IRB, documents d'information, documents d'ancrage (grilles de questions-réponses) et tableaux de référence. Déduit automatiquement les largeurs de colonnes de la table pipe à partir du contenu (la colonne d'étiquettes se rétrécit pour s'adapter, les colonnes de données partagent la largeur restante). Police de secours compatible CJK pour le texte coréen (Apple SD Gothic Neo sur macOS, Noto Sans CJK KR sous Linux). PAS pour : les manuscrits avec bibliographie (utilisez /manage-refs render_pandoc.sh), le remplissage de formulaires Word (/fill-protocol), les figures (/make-figures).
