Интерактивный помощник по профилированию и очистке данных для медицинских исследований. Трехэтапный рабочий процесс (профиль, флаг, генерация кода) с воротами одобрения пользователя на каждом этапе. Обрабатывает пропущенные значения, выбросы, дубликаты и несоответствия типов в клинических данных CSV/Excel. НЕ выполняет автоматическую очистку — все решения требуют подтверждения исследователя.
