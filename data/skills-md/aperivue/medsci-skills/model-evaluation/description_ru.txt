Вычисление и отчетность по заданным заданным метрикам для обученной модели медицинской визуализации — сегментация (Dice плюс граничная метрика, такая как HD95 или NSD, для каждой структуры), классификация (AUROC плюс AUPRC и чувствительность/специфичность с бутстреп-CI при распространенности развертывания), обнаружение (FROC или mAP с установленным критерием IoU), интерактивная/быстрая сегментация (оси количества взаимодействий, конвергенции и времени для каждого случая — статический Dice опускается) или оценка генеративного/синтетического изображения (сходство плюс сходство эффективности последующих задач само по себе установить невозможно) — плюс калибровка и срезы подгрупп. Создает таблицу результатов для каждого случая, которая преобразуется в статистику анализа в таблицы публикаций и сравнивает выбор метрик с Metrics Reloaded, CLAIM 2024 и Park et al. 2024 г. (нет пиксельной точности для сегментации, нет голой точности при дисбалансе, нет статического Dice для интерактивного метода, нет утверждения только о сходстве для генеративной модели). Числа берутся только из исполняемого кода, а не вводятся вручную.
