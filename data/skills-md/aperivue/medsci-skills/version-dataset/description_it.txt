Controllo della versione del set di dati per la riproducibilità della ricerca. Crea un manifest deterministico dell'hash del contenuto di un set di dati (file SHA-256 + schema tabulare + hash dei valori per colonna), verifica una copia successiva rispetto ad esso per rilevare la deriva (modifica dello schema, modifica del conteggio delle righe, modifiche dei valori) e differenzia due manifest. Da utilizzare per dimostrare che un'analisi è stata eseguita sui dati desiderati, bloccare una versione del set di dati o demo in bundle per bloccare la riproducibilità.
