Contrôle de version des ensembles de données pour la reproductibilité de la recherche. Crée un manifeste de hachage de contenu déterministe d'un ensemble de données (fichier SHA-256 + schéma tabulaire + hachages de valeur par colonne), vérifie une copie ultérieure par rapport à celui-ci pour détecter la dérive (changement de schéma, changement du nombre de lignes, changements de valeur) et compare deux manifestes. Utilisez-le pour prouver qu'une analyse a été exécutée sur les données prévues, verrouiller une version d'un ensemble de données ou verrouiller la reproductibilité des démos groupées.
