Контроль версий набора данных для воспроизводимости исследований. Создает детерминированный манифест хэша содержимого набора данных (файл SHA-256 + табличная схема + хэши значений для каждого столбца), проверяет более позднюю копию на соответствие ему для обнаружения отклонений (изменение схемы, изменение количества строк, изменения значений) и сравнивает два манифеста. Используйте для подтверждения того, что анализ проводился на нужных данных, блокировки версии набора данных или комплексных демонстраций с блокировкой воспроизводимости.
