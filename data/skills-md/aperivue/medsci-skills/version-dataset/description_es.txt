Control de versiones del conjunto de datos para la reproducibilidad de la investigación. Crea un manifiesto de hash de contenido determinista de un conjunto de datos (archivo SHA-256 + esquema tabular + hash de valor por columna), verifica una copia posterior para detectar desviaciones (cambio de esquema, cambio de recuento de filas, cambios de valor) y diferencia dos manifiestos. Úselo para demostrar que se ejecutó un análisis con los datos deseados, bloquear una versión de conjunto de datos o demostraciones empaquetadas con bloqueo de reproducibilidad.
