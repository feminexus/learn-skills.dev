モデリングの決定が行われる前に、取得グリッド、ボクセルの間隔と方向の広がり、強度ドメイン、実際に存在するラベル値、ターゲットが占める体積の量、およびターゲットの大きさ（ミリリットル）などの医療画像データセットのプロファイルを作成し、研究者が宣言した計画に対してそのプロファイルをゲートします。まだ安価な時点で、トレーニング実行後に表面化するデータセットの事実を捕捉します。つまり、グラウンド トゥルースを持たない「テスト セット」、グリッドがイメージと一致しないラベル、迷走するラベル インデックス、精度がメトリクスとして計画されている間にパーセントの何分の 1 を占めるターゲット、誰もリサンプリングの決定を宣言していない取得の不均一性などです。データセット プロファイル JSON とそれを読み取る決定論的ゲートを出力します (stdlib のみなので、監査は JSON とともに送信されます)。データを説明し、それに対して計画を監査します。前処理、分割、トレーニングは行いません。
