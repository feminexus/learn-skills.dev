Полное зеркало исходной документации Fumadocs из fuma-nama/fumadocs.
Fumadocs — это платформа документации для Next.js, React Router, TanStack Start и Vite.
Используйте этот навык, когда вам нужен точный исходный справочный материал — установка, настройка,
настройка пользовательского интерфейса, настройка поиска, интеграций (OpenAPI, источники контента, изображения OG),
интернационализация, автономные API или обработка MDX.
Это не специальное руководство; это необработанные исходные документы, организованные по темам.
