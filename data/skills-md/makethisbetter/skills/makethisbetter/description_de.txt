Richten Sie MakeThisBetter-Feedback von Claude Code ein, authentifizieren und verwalten Sie es. Wird verwendet, wenn der Benutzer „/makethisbetter“ ausführt, gefolgt von „setup“, „setup-auth“, „login“, „signup“, „list“, „pick“, „dismiss“, „resolve“ oder einem beliebigen Befehl zur Feedbackverwaltung. Wird auch bei der MakeThisBetter-Einrichtung ausgelöst, indem ausstehendes Feedback aufgelistet wird, Feedback zum Korrigieren ausgewählt wird, Feedback übersprungen wird, Feedback als gelöst markiert wird oder ein PR mit Feedback verknüpft wird.
