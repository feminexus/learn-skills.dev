Configure, autentique y administre los comentarios de MakeThisBetter de Claude Code. Úselo cuando el usuario ejecute /makethisbetter seguido de configuración, configuración de autenticación, inicio de sesión, registro, lista, selección, descarte, resolución o cualquier comando de administración de comentarios. También se activa la configuración de MakeThisBetter, enumerar comentarios pendientes, elegir comentarios para corregir, omitir comentarios, marcar comentarios resueltos o vincular un PR a comentarios.
