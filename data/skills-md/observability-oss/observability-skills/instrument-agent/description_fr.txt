Ajoutez l'instrumentation Progress Observability à un agent d'IA ou une application LLM existante (Python, TypeScript/JavaScript ou .NET, y compris LangChain, LangGraph, LlamaIndex, CrewAI, OpenAI Agents, Haystack, les serveurs MCP et Microsoft.Extensions.AI) avec la plus petite différence possible, puis transmettez l'endroit où confirmer les traces. À utiliser lorsque l'utilisateur demande « d'instrumenter mon agent », « d'ajouter de l'observabilité », « d'ajouter un traçage/télémétrie à ce dépôt », de « le connecter à Progress Observability » ou a un projet non instrumenté existant qu'il souhaite sur la plate-forme. Pas pour créer un projet à partir de zéro – cela modifie uniquement le code qui existe déjà.
