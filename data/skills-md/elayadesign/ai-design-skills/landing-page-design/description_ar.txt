نظام كامل لإنشاء صفحات مقصودة عالية التحويل: أسئلة القبول، وبنية الصفحة، واختيار التخطيط، وكتابة الإعلانات التحويلية، وتحسين محركات البحث، بالإضافة إلى القواعد المرئية الصارمة للطباعة، والتباعد، ونصف قطر الزاوية، والخلفيات، وتخطيط البطل، والأيقونات، والحركة. استخدم هذه المهارة عند إنشاء نسخة أو تحريرها أو تصميمها أو مراجعتها أو كتابتها لأي صفحة مقصودة أو موقع تسويق أو واجهة مستخدم ويب أو قسم صفحة أو مكون أو نموذج أولي، حتى عندما لا يذكر المستخدم التصميم أو التحويل أو الرموز المميزة أو نظام التصميم. استشرها دائمًا قبل اختيار أقسام الصفحة أو العناوين أو عبارات الحث على اتخاذ إجراء أو الخطوط أو أحجام الخطوط أو قيم التباعد أو نصف قطر الحدود أو ألوان الخلفية أو الرموز أو التحولات.
