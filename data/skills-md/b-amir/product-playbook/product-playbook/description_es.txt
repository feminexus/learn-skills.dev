Cree, concilie, audite o verifique por agentes manuales de prueba manuales respaldados por evidencia desde cualquier base de código de producto (pruebas, contratos, Swagger, documentos, fuente, interfaces en vivo). Utilícelo cuando el usuario solicite un manual de estrategias del producto, un manual de control de calidad manual, un script UAT, escenarios de cara al evaluador, una conciliación del manual de estrategias, una auditoría del manual de estrategias o una verificación de desviaciones con respecto a un manual de estrategias existente. No lo utilice para escribir pruebas unitarias, diseñar API o estrategias genéricas de control de calidad sin un repositorio. Nunca inventes etiquetas o comportamientos de interfaz. Publicar únicamente Markdown orientado al probador más un JSON de estado portátil; PDF/HTML opcional y hallazgos de hermanos solo cuando se le solicite.
