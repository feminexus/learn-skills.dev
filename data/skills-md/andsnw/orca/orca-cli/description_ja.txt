パブリック `orca` CLI を使用して、Orca が管理するワークツリー、フォルダー コンテキスト、ターミナル、リポジトリ、オートメーション、ワークツリー コメント、および Orca アプリ内に埋め込まれたブラウザーを操作します。ユーザーが「$orca-cli」、「orca cli を使用」、「Orca ワークツリー」、「子ワークツリー」、「cardStatus」、「ワークツリーでコーデックス/クロードを生成」、「Orca ターミナルの読み取り/待機/送信」、「ターミナル送信」、「フル ハンドオフ」、「ハンドオーバー」、「これを別のエージェントに渡す」、「別のワークツリー」、「Orca ブラウザ」、または「Orca 内のブラウザを制御する」と言うときに使用します。タスクが Orca 管理状態になる場合は、生の `git worktree`、アドホック PTY、Playwright、または Computer Use よりもこれを優先します。コンピュータを使用 Orca の組み込みブラウザの外部のブラウザ ウィンドウ、Web ビュー、またはデスクトップ UI に使用します。
