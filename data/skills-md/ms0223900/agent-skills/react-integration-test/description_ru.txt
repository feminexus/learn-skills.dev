Руководства по написанию тестов компонентов React/Next.js с помощью библиотеки тестирования React (RTL) + @testing-library/user-event（不使用 Enzyme／shallow render）。Используется, когда пользователь хочет протестировать компонент/интеграцию для компонента React или Next.js или просит проверить визуализированный вывод/взаимодействие пользователя с компонентом.
