Руководства по написанию интеграционных тестов компонентов Vue 2 с помощью @vue/test-utils + Jest + Vuex. Используйте, когда пользователь хочет добавить `.integration.test.ts`/`.js` для компонента Vue, проверить визуализированный вывод на соответствие фикстурам или проверить пути рендеринга, управляемые хранилищем.
