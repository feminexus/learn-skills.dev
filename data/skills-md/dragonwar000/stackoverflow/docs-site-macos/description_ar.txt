أنشئ موقع توثيق جميل مستوحى من نظام التشغيل macOS (ملف HTML واحد) باستخدام نظام سطح من الزجاج السائل (شكل زجاجي متدرج: سلم العتامة، ومقياس التمويه، وإبراز الحواف)، ورسومات تخطيطية SVG متحركة، ونافذة ضوء حركة المرور من الكروم، ولوحة من الزجاج السائل باللون الأزرق الفاتح + الأبيض (أسطح زجاجية بيضاء فوق حقل متدرج أزرق ناعم، سمات ذات درجة لون زرقاء لكل قسم). قم أيضًا بتشغيل طلبات "الزجاج السائل" أو "الزجاج المصنفر" أو "واجهة المستخدم الشفافة" للمستندات/صفحات العرض. يتم تشغيله عندما يريد المستخدم إنشاء موقع مستندات، أو صفحة مقصودة، أو واجهة عرض، أو محفظة، أو دليل، أو موقع تعليمي، أو نظرة عامة على الميزات، أو وثائق المنتج - خاصةً عندما يذكر رغبته في أن يبدو "نظيفًا" أو "حديثًا" أو "شبيهًا بـ Apple" أو "نمط macOS" أو "زجاجيًا" أو "متجمدًا" أو "رسومًا تخطيطية متحركة" أو "ملف HTML فردي". يُستخدم أيضًا عندما يكون لدى المستخدم ملفات تخفيض متعددة ويريد عرضها في صفحة HTML مرئية متماسكة تحتوي على أقسام. إذا قال المستخدم "6 ملف" أو أراد صفحات منفصلة لكل موضوع، فقم بإنشاء ملف HTML واحد لكل ملف wiki (index.html كملفات نظرة عامة + ملفات مواضيع N)، وليس صفحة واحدة مدمجة.
