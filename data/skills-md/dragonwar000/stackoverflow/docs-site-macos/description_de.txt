Wird auch bei „Flüssigglas“-, „Milchglas“- oder „transluzenten UI“-Anfragen für Dokumenten-/Showcase-Seiten ausgelöst. Wird ausgelöst, wenn der Benutzer eine Dokumentenseite, eine Landingpage, ein Schaufenster, ein Portfolio, einen Leitfaden, eine Tutorialseite, eine Funktionsübersicht oder eine Produktdokumentation erstellen möchte – insbesondere, wenn er erwähnt, dass sie „sauber“, „modern“, „Apple-ähnlich“, „macOS-Stil“, „Glas“, „gefrostet“, „animierte Diagramme“ oder „einzelne HTML-Datei“ aussehen soll. Verwenden Sie es auch, wenn der Benutzer über mehrere Markdown-Dateien verfügt und diese in einer zusammenhängenden visuellen HTML-Seite mit Abschnitten gerendert werden möchte. Wenn der Benutzer „6 Dateien“ sagt oder separate Seiten pro Thema möchte, generieren Sie eine HTML-Datei pro Wiki-Datei (index.html als Übersicht + N Themendateien), KEINE einzelne kombinierte Seite.
