Создайте красивый сайт документации в стиле macOS (один HTML-файл) с системой поверхностей из жидкого стекла (многоуровневый морфизм стекла: лестница непрозрачности, масштаб размытия, блики по краям), анимированными SVG-диаграммами, хромированными окнами светофора и светло-голубой + белой палитрой жидкого стекла (белые стеклянные поверхности над мягким синим градиентным полем, тематика синих тонов для каждого раздела). Также активируется при запросах «жидкое стекло», «матовое стекло» или «полупрозрачный пользовательский интерфейс» для страниц документов/витрин. Срабатывает, когда пользователь хочет создать сайт документации, целевую страницу, витрину, портфолио, руководство, обучающий сайт, обзор функций или документацию по продукту, особенно когда он упоминает, что хочет, чтобы он выглядел «чистым», «современным», «по-яблочному», «в стиле MacOS», «стеклянным», «матовым», «анимированными диаграммами» или «одним HTML-файлом». Также используйте, когда у пользователя есть несколько файлов уценки и он хочет, чтобы они были отображены в единую визуальную HTML-страницу с разделами. Если пользователь говорит «6 файлов» или хочет отдельные страницы для каждой темы, сгенерируйте один HTML-файл для каждого вики-файла (index.html как обзор + N файлов тем), а НЕ одну объединенную страницу.
