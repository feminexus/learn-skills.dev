Créez un magnifique site de documentation inspiré de macOS (un seul fichier HTML) avec un système de surface en verre liquide (morphisme de verre à plusieurs niveaux : échelle d'opacité, échelle de flou, surbrillance des bords), des diagrammes SVG animés, du chrome de fenêtre de feu de circulation et une palette de verre liquide bleu clair + blanc (surfaces en verre blanc sur un champ de dégradé bleu doux, thème de ton bleu par section). Déclenchez également les requêtes « verre liquide », « verre dépoli » ou « interface utilisateur translucide » pour les pages de documents/vitrines. Déclenchez lorsque l'utilisateur souhaite créer un site de documentation, une page de destination, une vitrine, un portfolio, un guide, un site de didacticiel, un aperçu des fonctionnalités ou une documentation produit, en particulier lorsqu'il mentionne vouloir qu'il ait l'air « propre », « moderne », « de type Apple », « style macOS », « verre », « givré », « diagrammes animés » ou « fichier HTML unique ». À utiliser également lorsque l'utilisateur dispose de plusieurs fichiers de démarque et souhaite qu'ils soient rendus dans une page HTML visuelle cohérente avec des sections. Si l'utilisateur dit "6 fichiers" ou souhaite des pages séparées par sujet, générez un fichier HTML par fichier wiki (index.html comme aperçu + N fichiers de sujet), PAS une seule page combinée.
