液体ガラス サーフェス システム (段階的なガラスモーフィズム: 不透明ラダー、ぼかしスケール、エッジ ハイライト)、アニメーション SVG ダイアグラム、信号窓クロム、および水色 + 白の液体ガラス パレット (柔らかい青のグラデーション フィールド上の白いガラス サーフェス、セクションごとの青トーンのテーマ) を使用して、macOS にインスピレーションを得た美しいドキュメント サイト (単一の HTML ファイル) を構築します。ドキュメント/ショーケース ページの「液体ガラス」、「曇りガラス」、または「半透明 UI」リクエストでもトリガーされます。ユーザーがドキュメント サイト、ランディング ページ、ショーケース、ポートフォリオ、ガイド、チュートリアル サイト、機能概要、または製品ドキュメントを作成したい場合、特に「クリーン」、「モダン」、「Apple 風」、「macOS スタイル」、「ガラス」、「つや消し」、「アニメーション図」、または「単一の HTML ファイル」の外観を希望する場合にトリガーします。ユーザーが複数のマークダウン ファイルを持っていて、それらをセクションを含むまとまりのあるビジュアル HTML ページにレンダリングしたい場合にも使用します。ユーザーが「6 ファイル」と言う場合、またはトピックごとに個別のページを希望する場合は、結合された 1 つのページではなく、Wiki ファイルごとに 1 つの HTML ファイル (概要としてのindex.html + N 個のトピック ファイル) を生成します。
