Attiva anche le richieste di "vetro liquido", "vetro smerigliato" o "interfaccia utente traslucida" per pagine di documenti/vetrina. Si attiva quando l'utente desidera creare un sito di documenti, una pagina di destinazione, una vetrina, un portfolio, una guida, un sito di tutorial, una panoramica delle funzionalità o una documentazione di prodotto, soprattutto quando menziona il desiderio che appaia "pulito", "moderno", "simile ad Apple", "stile macOS", "vetro", "smerigliato", "diagrammi animati" o "singolo file HTML". Da utilizzare anche quando l'utente dispone di più file di markdown e desidera che vengano visualizzati in una pagina HTML visiva coerente con sezioni. Se l'utente dice "6 file" o desidera pagine separate per argomento, genera un file HTML per file wiki (index.html come panoramica + N file di argomenti), NON una singola pagina combinata.
