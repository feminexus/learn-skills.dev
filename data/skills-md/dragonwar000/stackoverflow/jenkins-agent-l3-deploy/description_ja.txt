Docker シークレット「L3」強化を使用して、ターゲット サーバー (コントローラーからの SSH なし) で実行されている Jenkins INBOUND AGENT 経由で docker-compose アプリをデプロイします。ランタイム シークレットは tmpfs 上に存在し、「docker Inspection」にも「.env」にも表示されません。ユーザーが「jenkins エージェント経由でデプロイ」、「no-ssh デプロイ」、「agent thay vì ssh」、「docker Secrets L3」、「ẩn Secret khỏi docker Inspection」、「secret không nằm trên đĩa」を希望する場合、または docker-compose を Linux ホストにデプロイする Jenkins パイプラインを接続する場合に使用します。実際の 1:1 実行から学んだ注意点をエンコードします (Java 21、0444 シークレット パーマ、0400 ファイル資格情報、エージェント ユーザーには docker+sudo が必要)。
