Разверните приложение для создания Docker через Jenkins INBOUND AGENT, работающий на целевом сервере (без SSH от контроллера), с усилением секретов Docker "L3" — секреты времени выполнения живут в tmpfs и никогда не отображаются ни в `docker Inspect`, ни в `.env`. Используйте, когда пользователь хочет: «развертывание через агента Дженкинса», «развертывание без SSH», «Агент через ssh», «Секреты Docker L3», «Секретная проверка докера», «Секретный код для проверки» или при подключении конвейера Jenkins, который развертывает docker-compose на хосте Linux. Кодирует ошибки, полученные в ходе реального запуска 1:1 (Java 21, секретные разрешения 0444, учетные данные файла 0400, пользователю агента требуется docker+sudo).
