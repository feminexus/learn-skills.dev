Distribuisci un'app docker-compose tramite un INBOUND AGENT Jenkins in esecuzione sul server di destinazione (nessun SSH dal controller), con protezione avanzata "L3" dei segreti Docker: i segreti di runtime risiedono su tmpfs e non vengono mai visualizzati in "docker inspect" né in ".env". Utilizzare quando l'utente desidera: "deploy via jenkins agent", "no-ssh deploy", "agent thay vì ssh", "docker secrets L3", "secret khỏi docker inspect", "secret không nằm trên đĩa" o sta collegando una pipeline Jenkins che distribuisce docker-compose a un host Linux. Codifica i trucchi appresi da una vera esecuzione 1:1 (Java 21, 0444 permessi segreti, credenziali file 0400, l'utente dell'agente necessita di docker+sudo).
