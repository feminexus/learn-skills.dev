Déployez une application docker-compose via un Jenkins INBOUND AGENT exécuté sur le serveur cible (pas de SSH du contrôleur), avec le renforcement des secrets Docker "L3" — les secrets d'exécution vivent sur tmpfs et n'apparaissent jamais dans `docker inspect` ni dans `.env`. À utiliser lorsque l'utilisateur souhaite : "déployer via l'agent jenkins", "déploiement sans ssh", "agent qui utilise ssh", "docker secrets L3", "un secret que docker inspect", "secret ne fonctionne pas", ou connecte un pipeline Jenkins qui déploie docker-compose sur un hôte Linux. Encode les pièges appris lors d'une véritable exécution 1:1 (Java 21, autorisations secrètes 0444, informations d'identification de fichier 0400, l'utilisateur de l'agent a besoin de docker+sudo).
