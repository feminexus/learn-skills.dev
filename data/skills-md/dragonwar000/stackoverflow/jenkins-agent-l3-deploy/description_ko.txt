Docker 비밀 "L3" 강화를 사용하여 대상 서버에서 실행 중인 Jenkins INBOUND AGENT(컨트롤러의 SSH 없음)를 통해 docker-compose 앱을 배포합니다. 런타임 비밀은 tmpfs에 있으며 `dockerspect` 또는 `.env`에 표시되지 않습니다. 사용자가 "jenkins 에이전트를 통해 배포", "no-ssh 배포", "ssh를 통한 에이전트", "docker secrets L3", "ẩn secret khỏi docker Inspection", "secret không nằm trên đĩa"를 원하거나 Linux 호스트에 docker-compose를 배포하는 Jenkins 파이프라인을 연결하는 경우에 사용하세요. 실제 1:1 실행에서 배운 정보를 인코딩합니다(Java 21, 0444 비밀 권한, 0400 파일 자격 증명, 에이전트 사용자는 docker+sudo 필요).
