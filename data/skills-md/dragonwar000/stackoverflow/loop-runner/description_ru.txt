Драйвер агентного цикла с детерминированным ограждением — оберните любой шаг с помощью предложения → детерминированной проверки → (критика → пересмотр) и обеспечения жесткой защиты завершения (max_iter, бюджет настенных часов, отсутствие прогресса через хэш состояния, эскалация до человека). Контур управления + защита + обнаружение прогресса являются детерминированными; этап критики/пересмотра LLM — это один адаптер, помещенный в карантин. Запускается, когда фиксированный цикл агента не должен вращаться вечно и не должен иметь возможности обходить неудачный тест.
