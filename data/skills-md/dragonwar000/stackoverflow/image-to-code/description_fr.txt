Compétence d'élite en matière de conversion d'image en code pour le Codex. Pour les tâches Web visuellement importantes, il doit d’abord générer lui-même la ou les images de conception, les analyser en profondeur, puis mettre en œuvre le site Web pour qu’il les corresponde le plus possible. Dans le Codex, il doit préférer les grandes images lisibles spécifiques à une section plutôt que de minuscules tableaux compressés, générer de nouvelles images autonomes pour les sections ou les vues détaillées au lieu de recadrer les anciennes, éviter la sous-génération paresseuse, éviter l'interface utilisateur des cartes à l'intérieur des cartes et garder le héros propre, spacieux, lisible et visible sur un petit ordinateur portable.
