Elite-Website-Image-to-Code-Fähigkeit für Codex. Für visuell wichtige Webaufgaben muss es zunächst das/die Designbild(er) selbst generieren, diese gründlich analysieren und dann die Website so implementieren, dass sie ihnen so genau wie möglich entspricht. Im Codex muss es große, lesbare, abschnittsspezifische Bilder anstelle von winzigen komprimierten Tafeln bevorzugen, neue eigenständige Bilder für Abschnitte oder Detailansichten generieren, anstatt alte zu beschneiden, eine träge Untergenerierung vermeiden, die Benutzeroberfläche „Karten-in-Karten-in-Karten“ vermeiden und den Helden auf einem kleinen Laptop sauber, geräumig, lesbar und sichtbar halten.
