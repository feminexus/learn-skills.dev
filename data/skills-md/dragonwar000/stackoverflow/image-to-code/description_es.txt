Habilidad de élite de conversión de imagen a código de sitios web para Codex. Para tareas web visualmente importantes, primero debe generar las imágenes de diseño, analizarlas en profundidad y luego implementar el sitio web para que coincida lo más posible con ellas. En Codex, debe preferir imágenes grandes, legibles y específicas de cada sección en lugar de pequeños tableros comprimidos, generar nuevas imágenes independientes para secciones o vistas detalladas en lugar de recortar las antiguas, evitar la subgeneración perezosa, evitar la interfaz de usuario de tarjetas dentro de tarjetas dentro de tarjetas y mantener al héroe limpio, espacioso, legible y visible en una computadora portátil pequeña.
