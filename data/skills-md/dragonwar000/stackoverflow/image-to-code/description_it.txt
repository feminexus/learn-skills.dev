Competenza di image-to-code del sito Web Elite per Codex. Per le attività web visivamente importanti, è necessario prima generare le immagini di progettazione stesse, analizzarle in modo approfondito, quindi implementare il sito Web per adattarle il più fedelmente possibile. Nel Codex, deve preferire immagini grandi, leggibili e specifiche per sezione invece di piccole schede compresse, generare nuove immagini autonome per sezioni o viste di dettaglio invece di ritagliare quelle vecchie, evitare pigre sottogenerazioni, evitare l'interfaccia utente di carte dentro carte dentro carte e mantenere l'eroe pulito, spazioso, leggibile e visibile su un piccolo laptop.
