Навыки создания имиджа премиум-класса для создания высококачественных досок с рекомендациями по бренду, систем логотипов, презентаций визуального мира. Обучался работе с минималистскими, кинематографическими, редакционными, темными технологиями, роскошными, культурными, безопасностью, игровыми системами, инструментами для разработчиков и брендами потребительских приложений. Оптимизирован для продуманной концепции логотипа, изысканной композиции, скудной типографики, сильного символического значения, макетов премиум-класса, художественных изображений и гибких макетов сетки.
