Cloner un site Web – deux modes. SNAPSHOT = une copie hors ligne fidèle et autonome d'une page (HTML+CSS+JS+images dans un seul fichier, octets exacts, style SingleFile). RECONSTRUCT = IA rétro-ingénierie de la page dans une base de code Next.js/Tailwind propre et modifiable (jetons de conception → spécifications des composants → constructeurs parallèles → contrôle qualité visual-diff, la méthode ai-website-cloner-template). À utiliser lorsque l'utilisateur souhaite « cloner ce site », copier la conception/l'interface utilisateur + les interactions d'une page, mettre en miroir une mise en page, enregistrer hors ligne ou reconstruire un site sous forme de code modifiable. Construit maintenant, adapté plus tard : l'instantané intégré fonctionne maintenant ; la capture fidèle en direct + le pipeline de reconstruction sont des adaptateurs de moteur à une configuration.
