Klonen Sie eine Website – zwei Modi. SNAPSHOT = eine originalgetreue, eigenständige Offline-Kopie einer Seite (HTML+CSS+JS+Bilder in einer Datei, genaue Bytes, SingleFile-Stil). RECONSTRUCT = KI-Reverse-Engineering der Seite in eine sauber bearbeitbare Next.js/Tailwind-Codebasis (Design-Tokens → Komponentenspezifikationen → parallele Builder → Visual-Diff-QA, die Methode ai-website-cloner-template). Verwenden Sie diese Option, wenn der Benutzer „diese Site klonen“, das Design/die Benutzeroberfläche + Interaktionen einer Seite kopieren, ein Layout spiegeln, offline speichern oder eine Site als bearbeitbaren Code neu erstellen möchte. Built-now-adapt-later: Snapshot-Built funktioniert jetzt; Die originalgetreue Live-Erfassung + die Rekonstruktionspipeline sind Engine-Adapter mit einer Konfiguration.
