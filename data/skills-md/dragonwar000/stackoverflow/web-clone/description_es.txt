Clonar un sitio web: dos modos. SNAPSHOT = una copia fiel y autónoma sin conexión de una página (HTML+CSS+JS+imágenes en un archivo, bytes exactos, estilo SingleFile). RECONSTRUCCIÓN = AI realiza ingeniería inversa de la página en una base de código limpia y editable Next.js/Tailwind (tokens de diseño → especificaciones de componentes → constructores paralelos → control de calidad visual-diff, el método ai-website-cloner-template). Úselo cuando el usuario quiera "clonar este sitio", copiar el diseño/UI + interacciones de una página, reflejar un diseño, guardar sin conexión o reconstruir un sitio como código editable. Construido ahora, adaptado más tarde: la instantánea incorporada funciona ahora; La captura en vivo fiel + la canalización de reconstrucción son adaptadores de motor de una configuración.
