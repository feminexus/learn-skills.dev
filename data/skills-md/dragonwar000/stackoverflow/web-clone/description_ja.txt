Web サイトのクローンを作成する — 2 つのモード。スナップショット = ページの忠実な自己完結型オフライン コピー (1 つのファイル内の HTML+CSS+JS+画像、正確なバイト数、SingleFile スタイル)。 RECONSTRUCT = AI がページをリバース エンジニアリングしてクリーンな編集可能な Next.js/Tailwind コードベースにします (デザイン トークン → コンポーネント仕様 → 並列ビルダー → Visual-diff QA、ai-website-cloner-template メソッド)。ユーザーが「このサイトのクローンを作成する」、ページのデザイン/UI + インタラクションをコピーする、レイアウトをミラーリングする、オフラインで保存する、または編集可能なコードとしてサイトを再構築する場合に使用します。 Build-now-adapt-later: スナップショット組み込み機能が機能するようになりました。忠実なライブ キャプチャと再構築パイプラインは、1 つの構成のエンジン アダプターです。
