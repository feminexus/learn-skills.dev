Клонировать сайт — два режима. SNAPSHOT = точная, автономная копия страницы (HTML+CSS+JS+изображения в одном файле, точные байты, в стиле SingleFile). РЕКОНСТРУКЦИЯ = искусственный интеллект преобразует страницу в чистую редактируемую кодовую базу Next.js/Tailwind (токены дизайна → спецификации компонентов → параллельные компоновщики → контроль качества визуальных различий, метод ai-website-cloner-template). Используйте, когда пользователь хочет «клонировать этот сайт», скопировать дизайн страницы/пользовательский интерфейс + взаимодействие, отразить макет, сохранить в автономном режиме или перестроить сайт в виде редактируемого кода. Встроенный сейчас-адаптируем позже: встроенная функция моментальных снимков теперь работает; точный захват в реальном времени + конвейер реконструкции — это адаптеры ядра с одной конфигурацией.
