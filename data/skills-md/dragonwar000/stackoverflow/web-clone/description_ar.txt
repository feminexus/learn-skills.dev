استنساخ موقع ويب – وضعان. SNAPSHOT = نسخة مخلصة ومكتفية ذاتيًا من الصفحة (HTML+CSS+JS+صور في ملف واحد، بايتات دقيقة، نمط SingleFile). RECONSTRUCT = إجراء هندسة عكسية للصفحة بواسطة الذكاء الاصطناعي وتحويلها إلى قاعدة بيانات Next.js/Tailwind نظيفة وقابلة للتحرير (رموز التصميم → مواصفات المكونات → أدوات إنشاء متوازية → visual-diff QA، طريقة قالب ai-website-cloner). يُستخدم عندما يريد المستخدم "استنساخ هذا الموقع"، أو نسخ تصميم الصفحة/تفاعلات واجهة المستخدم +، أو عكس التخطيط، أو الحفظ في وضع عدم الاتصال، أو إعادة بناء الموقع كرمز قابل للتحرير. مدمج الآن - قابل للتكيف لاحقًا: تعمل ميزة اللقطة المضمنة الآن؛ الالتقاط المباشر المخلص + خط أنابيب إعادة البناء عبارة عن محولات محرك ذات تكوين واحد.
