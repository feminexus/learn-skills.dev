MUSS VERWENDET werden, wenn der Benutzer etwas im Internet recherchieren/suchen/nachschlagen/finden möchte – z. B. „Recherchieren Sie dieses Thema“, „tauchen Sie eingehend in X ein“, „suchen Sie im Internet nach X“, „sehen Sie, was die Leute über X sagen“, „schlagen Sie nach“.
MUSS auch verwendet werden, wenn der Benutzer eine Plattform erwähnt oder eine URL/einen Link teilt: Twitter/X, Reddit, Facebook, Instagram, YouTube, GitHub, Bilibili, XiaoHongShu, Xiaoyuzhou Podcast, LinkedIn/jobs/recruiting, V2EX, Xueqiu (Aktien), RSS.
15 Plattformen, Multi-Backend-Routing (OpenCLI / plattformspezifische CLIs / APIs). Nullkonfiguration für 6 Kanäle. Führen Sie „agent-reach doctor --json“ aus, um zu sehen, welches Backend die jeweilige Plattform gerade bedient.
NICHT für: das Verfassen von Berichten/Analysen/Übersetzungen (diese Fertigkeit ruft nur Internetinhalte ab); Posten/Kommentieren/Liken (Schreibvorgänge); Plattformen, auf denen bereits ein dedizierter Skill installiert ist (bevorzugen Sie diesen Skill).
