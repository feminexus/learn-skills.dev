Gestisci qualsiasi spazio di lavoro Busabase come una knowledge base di prima approvazione: proponi modifiche come ChangeRequest, attendi la revisione umana, quindi unisci. Utilizza busabase-cli per comandi ergonomici, curl per il ciclo API rapido o le specifiche OpenAPI/MCP per l'intera superficie. Legge l'URL di base, la chiave API e lo spazio di destinazione da ~/.busabase/.env.
