Pilotez n'importe quel espace de travail Busabase comme une base de connaissances axée sur l'approbation : proposez des modifications sous forme de demandes de changement, attendez l'examen humain, puis fusionnez. Utilisez busabase-cli pour les commandes ergonomiques, curl pour la boucle API rapide ou la spécification OpenAPI/MCP pour la surface complète. Lit l'URL de base, la clé API et l'espace cible à partir de ~/.busabase/.env.
