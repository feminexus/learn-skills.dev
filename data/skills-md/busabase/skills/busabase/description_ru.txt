Используйте любое рабочее пространство Busabase как базу знаний, требующую одобрения: предлагайте изменения в виде запросов на изменение, ждите проверки человеком, а затем объединяйте. Используйте busabase-cli для эргономичных команд, Curl для быстрого цикла API или спецификацию OpenAPI/MCP для всей поверхности. Считывает базовый URL-адрес, ключ API и целевое пространство из ~/.busabase/.env.
