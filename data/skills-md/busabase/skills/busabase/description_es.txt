Impulse cualquier espacio de trabajo de Busabase como una base de conocimientos en la que la aprobación es prioritaria: proponga cambios como solicitudes de cambio, espere la revisión humana y luego fusione. Utilice busabase-cli para comandos ergonómicos, curl para el bucle API rápido o OpenAPI spec/MCP para la superficie completa. Lee la URL base, la clave API y el espacio de destino de ~/.busabase/.env.
