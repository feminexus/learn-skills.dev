Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Mistral Vibe-CLI („vibe“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Vibe übergeben möchte – Formulierungen wie „Lassen Sie Vibe NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
