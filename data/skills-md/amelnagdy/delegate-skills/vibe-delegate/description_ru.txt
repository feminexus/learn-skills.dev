Делегируйте задачу кодирования Mistral Vibe CLI («vibe») в качестве фонового реализатора, затем просмотрите ее различия и реализуйте ее самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации Vibe — такие фразы, как «попросить Vibe реализовать X», «делегировать это Vibe», «запустить это через Mistral Vibe», «использовать Vibe для реализации/исправления/рефакторинга» – или хочет запустить очередь задач по кодированию через Vibe, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
