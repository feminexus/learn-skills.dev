Делегируйте задачу кодирования CLI агента кодирования Pi (`pi`) в качестве фонового реализатора, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет делегировать работу по реализации Pi — такие фразы, как «заставить Pi реализовать X», «делегировать это pi», «запустить это через Pi» или «использовать pi для реализации/исправления/рефакторинга» – или хочет запустить очередь задач кодирования через Pi, оставаясь при этом рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
