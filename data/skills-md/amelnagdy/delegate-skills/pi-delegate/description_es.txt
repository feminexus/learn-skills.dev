Delegue una tarea de codificación a la CLI del agente de codificación Pi ("pi") como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Use esto siempre que el usuario quiera delegar el trabajo de implementación a Pi (frases como "hacer que Pi implemente X", "delegar esto a pi", "ejecutarlo a través de Pi" o "usar pi para implementar/reparar/refactorizar") - o quiera ejecutar una cola de tareas de codificación a través de Pi mientras sigue siendo el revisor. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, o cuando el usuario quiera que el código se escriba directamente sin delegar.
