Delegieren Sie eine Codierungsaufgabe an die Pi-Coding-Agent-CLI („pi“) als Hintergrundimplementierer, überprüfen Sie dann dessen Diff und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer Implementierungsarbeiten an Pi delegieren möchte – Formulierungen wie „Lass Pi X implementieren“, „delegiere dies an Pi“, „führe es über Pi aus“ oder „verwende Pi zum Implementieren/Reparieren/Umgestalten“ – oder möchte eine Warteschlange von Codierungsaufgaben über Pi ausführen und dabei der Prüfer bleiben. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
