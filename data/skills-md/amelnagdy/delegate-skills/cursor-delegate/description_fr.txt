Déléguez une tâche de codage à la CLI Cursor Agent (« curseur-agent ») en tant qu'implémenteur en arrière-plan, puis examinez sa différence et atterrissez-la vous-même. Utilisez-le chaque fois que l'utilisateur souhaite confier le travail d'implémentation à Cursor - des expressions telles que "demander au Cursor d'implémenter X", "déléguer cela au Cursor", "l'exécuter via Cursor Agent" ou "utiliser Cursor pour implémenter/réparer/refactoriser" - ou souhaite exécuter une file d'attente de tâches de codage via Cursor tout en restant le réviseur. NE PAS UTILISER pour des tâches suffisamment petites pour être exécutées en ligne, ou lorsque l'utilisateur souhaite que le code soit écrit directement sans déléguer.
