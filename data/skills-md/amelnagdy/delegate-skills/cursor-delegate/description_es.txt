Delegue una tarea de codificación a la CLI del Agente de cursor ("cursor-agent") como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Use esto siempre que el usuario quiera entregar el trabajo de implementación a Cursor (frases como "hacer que Cursor implemente X", "delegar esto a Cursor", "ejecutarlo a través de Cursor Agent" o "usar Cursor para implementar/arreglar/refactorizar"), o quiera ejecutar una cola de tareas de codificación a través de Cursor mientras sigue siendo el revisor. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, o cuando el usuario quiera que el código se escriba directamente sin delegar.
