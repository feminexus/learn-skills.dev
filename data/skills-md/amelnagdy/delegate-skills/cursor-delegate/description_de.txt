Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Cursor-Agent-CLI („cursor-agent“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Cursor übergeben möchte – Formulierungen wie „Cursor X implementieren lassen“, „dies an Cursor delegieren“, „über den Cursor-Agenten ausführen“ oder „Cursor zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über Cursor ausführen möchte, während er gleichzeitig Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
