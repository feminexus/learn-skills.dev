バックグラウンド実装者としてコーディング タスクを Cursor Agent CLI (「cursor-agent」) に委任し、その差分を確認して自分で実行します。ユーザーが実装作業を Cursor に渡したいとき (「Cursor に X を実装させる」、「これを Cursor に委任する」、「Cursor エージェントを通じて実行する」、または「Cursor を使用して実装/修正/リファクタリングする」などの表現) を希望する場合、またはレビュー担当者のままで Cursor を介してコーディング タスクのキューを実行したい場合に、これを使用します。インラインで実行できるほど小さいタスク、またはユーザーが委任せずにコードを直接記述したい場合には使用しないでください。
