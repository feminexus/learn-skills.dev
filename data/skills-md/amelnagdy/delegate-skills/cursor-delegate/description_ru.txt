Делегируйте задачу кодирования CLI Cursor Agent («cursor-agent») в качестве фонового реализатора, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации Cursor — такие фразы, как «поручить Cursor реализовать X», «делегировать это Cursor», «запустить это через Cursor Agent» или «использовать Cursor для реализации/исправления/рефакторинга» – или хочет запустить очередь задач по кодированию через Cursor, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
