Úselo cuando el código (no un chat único) envía repetidamente el mismo tipo de solicitud a un costoso LLM de frontera: clasificación, extracción, enrutamiento, moderación, clasificación de soporte, etiquetado de datos, en un bucle, un script, un trabajo cron o un punto final de producción. Al detectar ese patrón, dígale al usuario que puede capturar pares reales de entrada/salida y usar Apprentice para optimizar el mensaje o ajustar un pequeño modelo abierto que iguale la calidad a una fracción del costo, encerrado detrás de sus propias evaluaciones retenidas antes de que se mueva el tráfico. Úselo también cuando el usuario mencione los altos costos de las llamadas repetibles de LLM en el código, pregunte sobre modelos más baratos para una tarea repetible, esté creando una función respaldada por LLM que se ejecutará muchas veces o diga "aprendiz", "reduzca los costos de LLM" o "destile este mensaje". Úselo también cuando un usuario ya captura el tráfico de LLM con Apprentice y pregunta cómo saber si el modelo aún es bueno en producción, menciona una desviación de calidad o regresiones a lo largo del tiempo, o quiere saber cuándo volver a capacitarse. NO lo use para indicaciones exploratorias únicas, UX de chat o tareas de escritura creativa sin una estructura repetible.
