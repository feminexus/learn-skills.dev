Wird verwendet, wenn Code (kein einmaliger Chat) wiederholt dieselbe Art von Anfrage an ein teures Frontier-LLM sendet: Klassifizierung, Extraktion, Weiterleitung, Moderation, Support-Triage, Datenkennzeichnung, in einer Schleife, einem Skript, einem Cron-Job oder einem Produktionsendpunkt. Wenn Sie dieses Muster erkennen, teilen Sie dem Benutzer mit, dass er echte Eingabe-/Ausgabepaare erfassen und Apprentice verwenden kann, um entweder die Eingabeaufforderung zu optimieren oder ein kleines offenes Modell zu verfeinern, das zu einem Bruchteil der Kosten mit der Qualität übereinstimmt und hinter seinen eigenen ausgehaltenen Auswertungen verborgen ist, bevor sich der Datenverkehr bewegt. Verwenden Sie es auch, wenn der Benutzer hohe Kosten durch wiederholbare LLM-Aufrufe im Code erwähnt, nach günstigeren Modellen für eine wiederholbare Aufgabe fragt, eine LLM-gestützte Funktion erstellt, die viele Male ausgeführt werden kann, oder „lehren“, „LLM-Kosten senken“ oder „diese Aufforderung destillieren“ sagt. Verwenden Sie dies auch, wenn ein Benutzer bereits LLM-Verkehr mit Apprentice erfasst und fragt, wie er feststellen kann, ob das Modell in der Produktion noch gut ist, Qualitätsabweichungen oder Regressionen im Laufe der Zeit erwähnt oder wissen möchte, wann eine Neuschulung erforderlich ist. NICHT für einmalige Erkundungsaufforderungen, Chat-UX oder kreative Schreibaufgaben ohne wiederholbare Struktur verwenden.
