Cargue esta habilidad siempre que el proyecto contenga elementos <img>, SVG en línea utilizados como imágenes de contenido, imágenes de fondo CSS que transmitan significado o fuentes de iconos. Bajo ninguna circunstancia omita el texto alternativo en imágenes significativas. Absolutamente siempre proporcione un atributo alt significativo o alt="" vacío para imágenes decorativas. Aplique WCAG 2.2 SC 1.1.1: cada elemento que no sea de texto requiere una alternativa de texto.
