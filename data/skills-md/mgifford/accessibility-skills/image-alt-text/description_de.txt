Laden Sie diesen Skill immer dann, wenn das Projekt <img>-Elemente, Inline-SVGs, die als Inhaltsbilder verwendet werden, CSS-Hintergrundbilder, die Bedeutung vermitteln, oder Symbolschriftarten enthält. Lassen Sie auf aussagekräftigen Bildern auf keinen Fall Alternativtext weg. Stellen Sie unbedingt immer ein aussagekräftiges Alt-Attribut bereit oder leeren Sie alt="" für dekorative Bilder. Wenden Sie WCAG 2.2 SC 1.1.1 an – jedes Nicht-Text-Element erfordert eine Textalternative.
