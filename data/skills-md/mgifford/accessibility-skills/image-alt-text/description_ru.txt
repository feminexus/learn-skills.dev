Загрузите этот навык всякий раз, когда проект содержит элементы <img>, встроенные SVG-изображения, используемые в качестве изображений контента, фоновые изображения CSS, передающие смысл, или шрифты значков. Ни при каких обстоятельствах не опускайте замещающий текст на значимых изображениях. Абсолютно всегда указывайте значимый атрибут alt или пустой alt="" для декоративных изображений. Примените WCAG 2.2 SC 1.1.1 — для каждого нетекстового элемента требуется текстовая альтернатива.
