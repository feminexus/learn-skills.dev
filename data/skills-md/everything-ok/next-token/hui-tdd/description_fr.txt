Discipline de développement piloté par les tests : ROUGE-VERT-REFACTOR. Écrivez d'abord un test qui échoue, regardez-le échouer pour la bonne raison, écrivez un minimum de code à réussir, regardez-le réussir, puis refactorisez. Refuse de prétendre « terminé » jusqu'à ce qu'un test existe et réussisse. Déclencheur : /hui-tdd, "utiliser tdd", "écrire le test en premier", "refactorer vert rouge".
