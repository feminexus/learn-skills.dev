اصطلاحات Docker لتشغيل أحمال عمل حاوية NVIDIA GPU - مصادقة NGC، وعلامة --gpus، وأنماط التثبيت، وعبور env-var، وفحص الحاوية، ونقل جذر البيانات لمضيفي القرص المقسم، وأوضاع الأخطاء الشائعة. يُستخدم عندما تتطلب مهارة أخرى تشغيل حاوية nvcr.io أو أي أمر تشغيل عامل إرساء على مضيف وحدة معالجة الرسومات. تشغيل الكلمات الرئيسية - docker، docker run، nvcr.io، NGC، --gpus، nvidia-container-toolkit، صورة الحاوية، تسجيل الدخول إلى docker، سحب docker.
