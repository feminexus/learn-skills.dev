Соглашения Docker для запуска рабочих нагрузок контейнера NVIDIA GPU — аутентификация NGC, флаг --gpus, шаблоны монтирования, передача env-var, проверка контейнера, перемещение корня данных для хостов с разделенным диском и типичные режимы ошибок. Используйте, когда другой навык требует запуска контейнера nvcr.io или любой команды запуска Docker на хосте графического процессора. Ключевые слова-триггеры — docker, docker run, nvcr.io, NGC, --gpus, nvidia-container-toolkit, образ контейнера, вход в docker, получение docker.
