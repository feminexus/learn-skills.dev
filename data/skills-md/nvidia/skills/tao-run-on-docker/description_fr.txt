Conventions Docker pour l'exécution des charges de travail de conteneurs GPU NVIDIA : authentification NGC, indicateur --gpus, modèles de montage, passthrough env-var, inspection des conteneurs, relocalisation de la racine des données pour les hôtes à disque divisé et modes d'erreur courants. À utiliser lorsqu'une autre compétence nécessite l'exécution d'un conteneur nvcr.io ou de toute commande d'exécution Docker sur un hôte GPU. Mots-clés déclencheurs : docker, docker run, nvcr.io, NGC, --gpus, nvidia-container-toolkit, image du conteneur, connexion docker, docker pull.
