Convenzioni Docker per l'esecuzione di carichi di lavoro di contenitori GPU NVIDIA: autenticazione NGC, flag --gpus, modelli di montaggio, passthrough env-var, ispezione del contenitore, riposizionamento della radice dei dati per host con disco diviso e modalità di errore comuni. Da utilizzare quando un'altra competenza richiede l'esecuzione di un contenitore nvcr.io o di qualsiasi comando di esecuzione docker su un host GPU. Parole chiave di attivazione: docker, docker run, nvcr.io, NGC, --gpus, nvidia-container-toolkit, immagine contenitore, docker login, docker pull.
