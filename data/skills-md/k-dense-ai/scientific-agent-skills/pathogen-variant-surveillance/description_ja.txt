GenSpectrum LAPIS API を通じてライブ病原体ゲノム監視データをクエリして、どのウイルス系統が現在流行しているか、どのくらいの速度で増殖しているか、どのような変異を持っているかを調べます。質問が、記憶されている事実ではなく、病原体集団の現在の状態に依存する場合には必ず使用してください。どの SARS-CoV-2 変異株が優勢であるか、パンゴ系統がまだ指定されているか取り消されたか、宿主または地域における H5N1 の分岐群または遺伝子型は何か、PCR プライマーまたはアッセイのターゲットが依然として循環配列と一致するかどうか、または系統の蔓延が週ごとにどのように推移したかなどです。トリガーには、「変異株サーベイランス」、「ゲノムサーベイランス」、「どの変異株が流行しているか」、「優勢変異株」、「パンゴ系統」、「系統有病率」、「成長優位性」、「SARS-CoV-2変異株」、「XFG」、「クレード2.3.4.4b」、「H5N1遺伝子型」、「インフルエンザクレード」、 「RSV/mpox/麻疹/デング熱系統」、「CoV-Spectrum」、「LAPIS」、「Nextclade」、「pango-designation」、および今日の病原体集団の様子を報告するあらゆるリクエスト。
