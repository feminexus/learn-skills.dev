透過 GenSpectrum LAPIS API 查詢活病原體基因組監測數據，以查找目前正在傳播的病毒譜系、它們的生長速度以及它們攜帶的突變。每當問題取決於病原體種群的當前狀態而不是記住的事實時使用 - 哪種 SARS-CoV-2 變體占主導地位、Pango 譜係是否仍被指定或已被撤回、宿主或區域中 H5N1 的進化枝或基因型、PCR 引物或檢測目標是否仍與循環序列匹配，或者譜系的流行率每週如何變化。觸發因素包括「變異監測」、「基因組監測」、「正在傳播的變異是什麼」、「顯性變異」、「Pango譜系」、「譜系流行率」、「生長優勢」、「SARS-CoV-2變異」、「XFG」、「進化枝2.3.4.4b」、「H5N1基因型」、「革登（Min-Tox/Hox）/1391,基因型」 「CoV-Spectrum」、「LAPIS」、「Nextclade」、「pango-designation」以及任何報告當今病原體族群狀況的請求。
