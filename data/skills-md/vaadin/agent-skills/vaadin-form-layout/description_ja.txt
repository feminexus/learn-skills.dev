Vaadin Flow (Java) のフォーム、エンティティ エディター、またはデータ入力ビューの視覚的な構造とレイアウトを、Figma URL、スクリーンショット、テキスト、またはプロンプトなどの仕様ソースからフィールドとコンポーネント、FormLayout セクション、および応答性の高い列レイアウトを選択して構築します。 Vaadin でフォーム、エンティティ エディター、またはデータ入力ビューを作成、実装、構築、または生成するように求められた場合、「フィールドを追加する」、「フォームを追加する」、または「編集用のレイアウトを構築する」場合、またはユーザーが「フォーム」という言葉を明示的に言わなくても、ユーザーから構造化された入力を収集することについて説明する場合に使用します。このスキルはフォームのレイアウトとコンポーネントのみをカバーします。バインダー、コンバーター、および検証を使用してフィールドを Java Bean に接続するには、Vaadin ドキュメント MCP (search_vaadin_docs) を介してバインダーおよびフォーム検証ガイドを参照してください。
