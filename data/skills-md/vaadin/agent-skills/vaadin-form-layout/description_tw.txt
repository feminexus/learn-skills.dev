從任何規範來源（Figma URL、螢幕截圖、文字或提示）在 Vaadin Flow (Java) 中建立表單、實體編輯器或資料輸入視圖的視覺結構和佈局，選擇欄位和元件、FormLayout 分割區和響應式列佈局。當被要求在 Vaadin 中創建、實現、構建或生成表單、實體編輯器或資料輸入視圖時使用，以“添加字段”、“添加表單”或“構建用於編輯的佈局”，或者當用戶描述從用戶收集結構化輸入時 - 即使他們沒有明確說出“表單”一詞。此技能僅涵蓋表單的佈局和元件；若要將欄位連接到具有 Binder、轉換器和驗證的 Java bean，請透過 Vaadin 文件 MCP (search_vaadin_docs) 尋找 Binder 和表單驗證指南。
