ينشئ البنية المرئية والتخطيط لنموذج أو محرر كيان أو طريقة عرض إدخال البيانات في Vaadin Flow (Java) من أي مصدر مواصفات - عنوان URL لـ Figma، أو لقطة شاشة، أو نص، أو موجه - اختيار الحقول والمكونات، وتقسيم FormLayout، وتخطيط العمود المستجيب. يُستخدم عندما يُطلب منك إنشاء أو تنفيذ أو إنشاء أو إنشاء نموذج أو محرر كيان أو طريقة عرض إدخال البيانات في Vaadin، من أجل "إضافة حقول" أو "إضافة نموذج" أو "إنشاء تخطيط للتحرير"، أو عندما يصف المستخدم جمع المدخلات المنظمة من المستخدمين - حتى لو لم يذكروا كلمة "نموذج" بشكل صريح. تغطي هذه المهارة تخطيط النموذج ومكوناته فقط؛ لتوصيل الحقول بفاصوليا Java باستخدام Binder والمحولات والتحقق من الصحة، ابحث عن أدلة Binder والتحقق من صحة النموذج عبر Vaadin docs MCP (search_vaadin_docs).
