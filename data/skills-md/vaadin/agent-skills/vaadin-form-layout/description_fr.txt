Construit la structure visuelle et la mise en page d'un formulaire, d'un éditeur d'entité ou d'une vue de saisie de données dans Vaadin Flow (Java) à partir de n'importe quelle source de spécifications - URL Figma, capture d'écran, texte ou invite - en choisissant les champs et les composants, la section FormLayout et la disposition des colonnes réactives. À utiliser lorsqu'il est invité à créer, implémenter, construire ou générer un formulaire, un éditeur d'entité ou une vue de saisie de données dans Vaadin, pour « ajouter des champs », « ajouter un formulaire » ou « créer une mise en page pour l'édition », ou lorsque l'utilisateur décrit la collecte d'entrées structurées des utilisateurs — même s'ils ne prononcent pas explicitement le mot « formulaire ». Cette compétence couvre uniquement la mise en page et les composants du formulaire ; pour câbler les champs à un bean Java avec Binder, convertisseurs et validation, recherchez les guides Binder et Form Validation via le Vaadin docs MCP (search_vaadin_docs).
