Costruisce la struttura visiva e il layout di un modulo, un editor di entità o una vista di immissione dati in Vaadin Flow (Java) da qualsiasi fonte specifica (URL Figma, screenshot, testo o prompt) scegliendo i campi e i componenti, la sezionamento di FormLayout e il layout delle colonne reattive. Utilizzare quando viene richiesto di creare, implementare, costruire o generare un modulo, un editor di entità o una vista di immissione dati in Vaadin, per "aggiungere campi", "aggiungere un modulo" o "creare un layout per la modifica" o quando l'utente descrive la raccolta di input strutturati dagli utenti, anche se non pronuncia esplicitamente la parola "modulo". Questa competenza copre solo il layout e i componenti del modulo; per collegare i campi a un bean Java con Binder, convertitori e convalida, consultare le guide Binder e Form Validation tramite Vaadin docs MCP (search_vaadin_docs).
