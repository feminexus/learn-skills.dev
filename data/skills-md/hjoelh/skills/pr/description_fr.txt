Créez un brouillon de demande d'extraction GitHub à partir de l'état git actuel vers la branche par défaut du référentiel à l'aide de la CLI gh. À utiliser lorsque l'utilisateur demande à ouvrir ou à créer un PR, souhaite que la branche de base corresponde automatiquement à la branche principale/par défaut du dépôt, souhaite un bref résumé du PR ou demande explicitement d'omettre un plan de test.
