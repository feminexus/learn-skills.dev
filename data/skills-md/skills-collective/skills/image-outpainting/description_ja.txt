`runco​​mfy` CLI を介して RunComfy 上で画像を塗りつぶす — 元のキャンバスを超えて静止画を拡張し、カメラがキャプチャしなかった部分を塗りつぶし、元のコンテンツを保持しながらアスペクト比を変更します (正方形 → 16:9、ポートレート → ランドスケープ)。 Nano Banana 2 Edit (デフォルト、空間言語駆動)、GPT Image 2 Edit (参照スタイルのマッチングによるマルチ参照)、FLUX Kontext Pro (シングルショットの最大保存)、およびブランド編集エンドポイント (Seedream / Dreamina / Qwen / FLUX 2) にわたるルート。アウトペイントが散文主導、参照主導、またはブランド固定のいずれであるかに基づいて、適切なルートを選択します。 「アウトペイント」、「アウトペイント」、「イメージ キャンバスの拡張」、「イメージの拡張」、「写真の周囲を塗りつぶす」、「トリミング解除」、「アスペクト比の変更」、「フレームの拡張」、「正方形からワイドスクリーン」、または既存の静止画の周囲にキャンバスを追加するための明示的な要求でトリガーされます。
