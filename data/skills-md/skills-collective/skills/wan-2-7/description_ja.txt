RunComfy の Wan 2.7 (Wan-AI の主力モーション モデル) を使用してテキストからビデオへの変換を生成します。 Wan 2.7 の強み (マルチリファレンス コンディショニング、`audio_url` によるオーディオ主導のリップシンク、スムーズなトランジション、プロンプト拡張)、継続時間 / 解像度 / アスペクト比スキーマ、および代わりに HappyHorse 1.0 / Seedance 2.0 / Kling / LTX 2 にルーティングするタイミングについて文書化します。ローカルの RunComfy CLI を介して「runco​​mfy run wan-ai/wan-2-7/text-to-video」を呼び出します。 「wan」、「wan 2.7」、「wan-2-7」、「wan video」、またはこのモデルでビデオを生成するための明示的な要求でトリガーされます。
