RunComfy で画像を編集する — このスキルは、ユーザーの意図を RunComfy カタログ内の適切な編集モデルに一致させるスマート ルーターです。 Nano Banana Edit (バッチ最大 20、アイデンティティ保持のデフォルト)、OpenAI GPT Image 2 Edit (多言語画像内テキスト書き換え、複数参照の合成、レイアウトの精度)、Flux Kontext Pro (単一参照の高忠実度ローカル編集)、または Z-Image Turbo Inpaint (マスク駆動の正確な領域編集) を選択します。各モデルの文書化されたプロンプト パターンをバンドルすることで、間違ったモデルでイテレーションを書き込むことなく、スキルがよりシャープな編集を行うことができます。ローカルの RunComfy CLI を介して `runco​​mfy run <vendor>/<model>/edit` を呼び出します。 「画像編集」、「画像編集」、「画像間」、「i2i」、「背景の交換」、「オブジェクトの削除」、「見出しの書き換え」、または単一またはバッチの画像を編集するための明示的な要求でトリガーされます。
