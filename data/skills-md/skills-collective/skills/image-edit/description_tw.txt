在 RunComfy 上編輯圖像 - 這項技能是一個智慧路由器，可以將使用者的意圖與 RunComfy 目錄中的正確編輯模型相匹配。選擇 Nano Banana Edit（批量最多 20 個，預設保留身份）、OpenAI GPT Image 2 Edit（多語言圖像內文字重寫、多參考合成、佈局精度）、Flux Kontext Pro（單參考高保真本地編輯）或 Z-Image Turbo Inpaint（掩模驅動的精確區域編輯）。捆綁每個模型記錄的提示模式，以便技能得到更清晰的編輯，而無需在錯誤的模型上進行迭代。透過本地 RunComfy CLI 呼叫「runco​​mfy run <vendor>/<model>/edit」。在「影像編輯」、「編輯影像」、「影像到影像」、「i2i」、「交換背景」、「刪除物件」、「重寫標題」或任何編輯單一或一批影像的明確要求時觸發。
