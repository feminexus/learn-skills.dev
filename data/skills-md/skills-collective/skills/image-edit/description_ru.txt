Редактирование изображений в RunComfy — этот навык представляет собой интеллектуальный маршрутизатор, который сопоставляет намерение пользователя с правильной моделью редактирования в каталоге RunComfy. Выбирает Nano Banana Edit (пакет до 20, по умолчанию с сохранением идентичности), OpenAI GPT Image 2 Edit (многоязычное перезапись текста в изображении, композиция из нескольких ссылок, точность макета), Flux Kontext Pro (высокоточное локальное редактирование с одной ссылкой) или Z-Image Turbo Inpaint (точное редактирование области на основе маски). Объединяет документированные шаблоны подсказок каждой модели, чтобы навык можно было более точно редактировать без записи итераций на неправильную модель. Вызывает `runcomfy run <vendor>/<model>/edit` через локальный интерфейс командной строки RunComfy. Запускается при «редактировании изображения», «редактировании изображения», «изображении к изображению», «i2i», «замене фона», «удалении объекта», «переписывании заголовка» или любом явном запросе на редактирование одного или пакета изображений.
