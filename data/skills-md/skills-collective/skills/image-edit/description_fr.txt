Modifier des images sur RunComfy — cette compétence est un routeur intelligent qui fait correspondre l'intention de l'utilisateur au bon modèle d'édition dans le catalogue RunComfy. Choisit Nano Banana Edit (lot jusqu'à 20, préservation de l'identité par défaut), OpenAI GPT Image 2 Edit (réécriture de texte multilingue dans l'image, composition multi-réf., précision de mise en page), Flux Kontext Pro (édition locale haute fidélité à référence unique) ou Z-Image Turbo Inpaint (édition de région précise pilotée par masque). Regroupe les modèles d'invite documentés de chaque modèle afin que la compétence obtienne des modifications plus précises sans graver d'itérations sur le mauvais modèle. Appelle « runcomfy run <vendor>/<model>/edit » via la CLI RunComfy locale. Déclencheurs sur "modifier l'image", "modifier l'image", "image à image", "i2i", "échanger l'arrière-plan", "supprimer l'objet", "réécrire le titre" ou toute demande explicite de modifier une seule ou un lot d'images.
