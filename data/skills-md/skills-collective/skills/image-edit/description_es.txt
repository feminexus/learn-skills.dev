Edite imágenes en RunComfy: esta habilidad es un enrutador inteligente que hace coincidir la intención del usuario con el modelo de edición correcto en el catálogo de RunComfy. Elige Nano Banana Edit (lotes de hasta 20, valor predeterminado para preservar la identidad), OpenAI GPT Image 2 Edit (reescritura de texto multilingüe en la imagen, composición de múltiples referencias, precisión de diseño), Flux Kontext Pro (edición local de alta fidelidad de referencia única) o Z-Image Turbo Inpaint (edición de región precisa basada en máscara). Agrupa los patrones de indicaciones documentados de cada modelo para que la habilidad obtenga ediciones más nítidas sin grabar iteraciones en el modelo incorrecto. Llama a `runcomfy run <proveedor>/<modelo>/edit` a través de la CLI RunComfy local. Activadores de "edición de imagen", "editar imagen", "imagen a imagen", "i2i", "intercambiar fondo", "eliminar objeto", "reescribir título" o cualquier solicitud explícita para editar una sola imagen o un lote de imágenes.
