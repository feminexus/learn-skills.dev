Документы. Сильные стороны GPT Image Edit (язык сохранения, многоязычное редактирование текста в изображении, множественные ссылки до 10 изображений, точность макета/типографики), схема и когда вместо этого следует направить на Nano Banana Edit / Flux Kontext / GPT Image 2 t2i. Вызывает `runcomfy run openai/gpt-image-2/edit` через локальный CLI RunComfy. Срабатывает при «редактировании изображения gpt», «gpt-image-edit», «редактировании изображения Chatgpt», «редактировании с помощью изображения GPT 2» или любом явном запросе на редактирование с помощью этой модели.
