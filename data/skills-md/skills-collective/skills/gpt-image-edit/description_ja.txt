RunComfy 上の OpenAI GPT Image 2 (ChatGPT Images 2.0 の `/edit` エンドポイント) を使用して画像を編集します。モデルの文書化されたプロンプト パターンにバンドルされているため、スキルは同じモデルに対する単純なプロンプトよりも鮮明な出力を得ることができます。 GPT Image Edit の強み (保存言語、多言語画像内テキスト編集、最大 10 個の画像の複数参照、レイアウト/タイポグラフィの精度)、スキーマ、および代わりに Nano Banana Edit / Flux Kontext / GPT Image 2 t2i にルーティングするタイミングについて文書化します。ローカルの RunComfy CLI を介して「runco​​mfy run openai/gpt-image-2/edit」を呼び出します。 「gpt image edit」、「gpt-image-edit」、「chatgpt image edit」、「edit with gpt image 2」、またはこのモデルで編集するための明示的な要求でトリガーされます。
