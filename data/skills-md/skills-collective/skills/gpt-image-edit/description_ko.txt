RunComfy에서 OpenAI GPT 이미지 2(ChatGPT Images 2.0의 `/edit` 엔드포인트)를 사용하여 이미지를 편집합니다. 모델의 문서화된 프롬프트 패턴과 함께 번들로 제공되므로 동일한 모델에 대해 순진한 프롬프트보다 기술이 더 선명한 출력을 얻을 수 있습니다. GPT Image Edit의 장점(보존 언어, 다국어 이미지 내 텍스트 편집, 최대 10개 이미지의 다중 참조, 레이아웃/타이포그래피 정밀도), 스키마 및 Nano Banana Edit/Flux Kontext/GPT Image 2 t2i로 라우팅하는 시기를 문서화합니다. 로컬 RunComfy CLI를 통해 `runcomfy run openai/gpt-image-2/edit`를 호출합니다.
