在 RunComfy 上使用 OpenAI GPT Image 2（ChatGPT Images 2.0 的「/edit」端點）編輯影像 - 與模型記錄的提示模式捆綁在一起，因此與針對相同模型的簡單提示相比，該技能可以獲得更清晰的輸出。記錄 GPT Image Edit 的優勢（保存語言、多語言圖像內文字編輯、最多 10 個圖像的多重引用、佈局/排版精度）、架構以及何時路由到 Nano Banana Edit / Flux Kontext / GPT Image 2 t2i。透過本地 RunComfy CLI 調用“runco​​mfy run openai/gpt-image-2/edit”。在「gpt image edit」、「gpt-image-edit」、「chatgpt image edit」、「edit with gpt image 2」或任何明確要求使用此模型進行編輯的情況下觸發。
