在 RunComfy 上使用 Google Nano Banana 2（Gemini 系列闪存层文本到图像）生成图像 - 与模型记录的提示模式捆绑在一起，因此该技能可以获得比针对同一模型的天真的提示更清晰的输出。记录 Nano Banana 2 的优势（快速迭代、图像内排版渲染、可预测的框架、可选的基于网络的上下文）、分辨率等级定价、安全容差刻度盘以及何时路由到 Nano Banana Pro / GPT Image 2 / Flux 2 / Seedream。通过本地 RunComfy CLI 调用“runco​​mfy run google/nano-banana-2/text-to-image”。在“nanobanana”、“nano-banana-2”、“nanobanana2”、“google image gen”、“gemini image”或任何使用此模型生成的明确要求上触发。
