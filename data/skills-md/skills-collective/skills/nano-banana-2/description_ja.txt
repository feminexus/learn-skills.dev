RunComfy で Google Nano Banana 2 (Gemini ファミリーのフラッシュ層テキストから画像へ) を使用して画像を生成します。これにはモデルの文書化されたプロンプト パターンがバンドルされているため、スキルは同じモデルに対する単純なプロンプトよりも鮮明な出力を得ることができます。 Nano Banana 2 の強み (迅速なイテレーション、画像内タイポグラフィー レンダリング、予測可能なフレーミング、オプションの Web ベースのコンテキスト)、解像度レベルの価格設定、安全性許容ダイヤル、および代わりに Nano Banana Pro / GPT Image 2 / Flux 2 / Seedream にルーティングするタイミングについて文書化します。ローカルの RunComfy CLI を介して「runco​​mfy run google/nano-banana-2/text-to-image」を呼び出します。 「nano Banana」、「nano-banana-2」、「nano Banana 2」、「google image gen」、「gemini image」、またはこのモデルで生成するための明示的な要求でトリガーされます。
