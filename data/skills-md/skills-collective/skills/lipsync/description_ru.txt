Синхронизируйте лицо по губам с определенной звуковой дорожкой в ​​RunComfy через интерфейс командной строки runcomfy. Маршруты через ByteDance OmniHuman (аватар в полный рост, управляемый звуком из портрета + аудио), Sync Labs sync v2 / Pro (современная синхронизация рта с видео), Kling Lipsync (аудио-видео и текст-видео с синхронизированной речью) и Creatify Lipsync. Навык выбирает правильную конечную точку для фактического намерения пользователя — портретный снимок + аудио (стиль аватара), исходное видео + аудио (замена рта на существующих кадрах) или создание и синхронизация из сценария. Запускается по «синхронизации губ», «синхронизации губ», «заставить это видео говорить», «сопоставить звук со ртом», «дублировать видео», «синхронизировать губы с голосом», «Синхронизировать лаборатории», «синхронизировать голос за кадром» или любой явной просьбе выделить рот лица из звуковой дорожки.
