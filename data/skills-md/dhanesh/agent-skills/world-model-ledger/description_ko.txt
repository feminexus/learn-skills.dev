일회성 설정: 코딩 에이전트에 대한 영구 SQLite 지원 WORLD MODEL을 프로젝트(또는 전역 ~/.claude)에 설치합니다. 사용자가 에이전트가 세션 전반에 걸쳐 코드베이스를 기억하고, 모순을 감지하고, 수정 사항을 제안하고, 시간이 지남에 따라 정확성을 향상시키기를 원할 때 사용합니다. "에이전트에게 세계 모델 제공", "검증된 것과 가정된 것 추적", "자신있게 코드베이스 지식 유지". 2개의 신뢰 축(관찰 및 규범), 검증 상태 및 PROV 스타일 증거를 통해 엔터티(기호/파일/모듈/외부 참조 대상), 상호 작용 및 제약 조건을 추적합니다. 부하 베어링 규칙: 코드 관찰은 실제 진실이 아닙니다. Oracle 증거(테스트/CI/문서/사람)만이 규범적 신뢰도를 높이고 관찰되었지만 확인되지 않음을 표시합니다. 모든 트리플은 삽입 전에 술어 온톨로지(RDFS 스타일 도메인/범위)에 대해 확인됩니다. 환각 동사와 불가능한 쌍은 저장되지 않고 거부됩니다. 4개의 후크를 통한 제로 구성 캡처(PreToolUse 사전 편집 요약, UNIVERSAL PostToolUse 모든 도구 호출 관찰, 중지/세션 시작 통합 + 다이제스트 주입, 자동 부트스트랩) 한 번 호출합니다. 후크가 자동으로 실행됩니다. 린터, LSP 서버, RAG 벡터 저장소 또는 모델 기반 사실 추출기가 아닙니다.
