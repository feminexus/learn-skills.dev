CONFIGURATION unique : installe un MODÈLE MONDIAL persistant basé sur SQLite pour un agent de codage dans un projet (ou global ~/.claude). À utiliser lorsque l'utilisateur souhaite qu'un agent se souvienne d'une base de code au fil des sessions, détecte les contradictions, propose des correctifs et améliore l'exactitude au fil du temps : "donner à l'agent un modèle mondial", "suivre ce qui est vérifié par rapport à ce qui est supposé", "conserver les connaissances de la base de code en toute confiance". Suit les entités (symboles/fichiers/modules/référents externes), les interactions et les contraintes avec DEUX axes de confiance (observé vs normatif), l'état de validation et les preuves de style PROV. Règle porteuse : l'observation du code n'est PAS une vérité terrain — seules les preuves oracles (tests/CI/docs/humains) augmentent la confiance normative, signalant les observations observées mais non vérifiées. Chaque triplet est vérifié par rapport à une ontologie de prédicat (domaine/plage de style RDFS) avant l'insertion — les verbes hallucinés et les appariements impossibles sont rejetés et non stockés. Capture sans configuration via quatre hooks (résumés de pré-édition PreToolUse ; UNIVERSAL PostToolUse observant chaque appel d'outil ; Stop/SessionStart consolider + injecter le résumé, auto-bootstrap) ; invoquer UNE FOIS ; les crochets s’exécutent automatiquement. Il ne s'agit pas d'un linter, d'un serveur LSP, d'un magasin de vecteurs RAG ou d'un extracteur de faits basé sur un modèle.
