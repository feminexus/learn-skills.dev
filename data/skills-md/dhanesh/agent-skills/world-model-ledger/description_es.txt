CONFIGURACIÓN única: instala un MODELO MUNDIAL persistente respaldado por SQLite para un agente de codificación en un proyecto (o global ~/.claude). Úselo cuando el usuario quiera que un agente recuerde una base de código en todas las sesiones, detecte contradicciones, proponga correcciones y mejore la corrección con el tiempo: "darle al agente un modelo mundial", "seguir lo que se verifica y lo que se supone", "persistir en el conocimiento de la base de código con confianza". Realiza un seguimiento de entidades (símbolos/archivos/módulos/referentes externos), interacciones y restricciones con DOS ejes de confianza (observado versus normativo), estado de validación y evidencia de estilo PROV. Regla de carga: la observación del código NO es una verdad fundamental; solo la evidencia de Oracle (pruebas/CI/docs/humanos) genera confianza normativa, señalando lo observado pero no verificado. Cada triplete se compara con una ontología de predicados (dominio/rango estilo RDFS) antes de la inserción: los verbos alucinados y los pares imposibles se rechazan, no se almacenan. Captura de configuración cero a través de cuatro ganchos (PreToolUse resúmenes de preedición; UNIVERSAL PostToolUse observando cada llamada de herramienta; Stop/SessionStart consolidar + inyectar resumen, arranque automático); invocar UNA VEZ; Los ganchos se ejecutan automáticamente. No es un linter, un servidor LSP, un almacén de vectores RAG o un extractor de hechos basado en modelos.
