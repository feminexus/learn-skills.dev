تحقق من مهارات ThreadWave Twitter/X التي تم إصدارها بشكل مستقل مقابل فهرس إصدار GitHub الرسمي دون تشغيل CLI أو تثبيت التعليمات البرمجية. يُستخدم لتحديثات مهارات ThreadWave، أو التحقق من أحدث إصدارات المهارات، أو مهارات Twitter القديمة أو المفقودة، أو توافق الإصدار، أو تشخيصات تثبيت المهارات المسطحة، أو كبوابة الإصدار الإلزامية التي يطلق عليها الاختبار المبدئي لموجة الخيط. المصدر: 用于检查 ThreadWave اختبار مبدئي لموجة الخيط شكرا جزيلا.
