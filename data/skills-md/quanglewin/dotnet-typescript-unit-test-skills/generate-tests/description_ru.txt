Используйте, когда пользователь просит сгенерировать, создать или написать модульные тесты для кода. Анализирует целевой код, создает структурированный список тестовых примеров для проверки, а затем генерирует тестовый код. Поддерживает C#/.NET (xUnit, NSubstitute, AwesomeAssertions) и TypeScript/JavaScript (Vitest или Jest).
