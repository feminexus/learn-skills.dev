Используйте, когда пользователь запрашивает создание, создание или запись тестов драматурга (компонента или API) для кода TypeScript/JavaScript. Анализирует целевой компонент или маршрут API, создает структурированный список тестовых примеров для проверки, а затем генерирует спецификации драматурга с использованием объектной модели страницы (POM).
