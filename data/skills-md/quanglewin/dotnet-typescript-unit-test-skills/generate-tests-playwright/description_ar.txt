يُستخدم عندما يطلب المستخدم إنشاء اختبارات Playwright أو إنشائها أو كتابتها (مكون أو واجهة برمجة التطبيقات) لتعليمات TypeScript/JavaScript البرمجية. يحلل المكون الهدف أو مسار واجهة برمجة التطبيقات (API)، وينتج قائمة حالات اختبار منظمة للمراجعة، ثم ينشئ مواصفات Playwright باستخدام نموذج كائن الصفحة (POM).
