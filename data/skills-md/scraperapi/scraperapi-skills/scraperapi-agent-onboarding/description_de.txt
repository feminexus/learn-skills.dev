Einstiegspunkt für Agenten und Entwickler, die neu bei ScraperAPI sind. Lesen Sie zuerst, wenn Sie ScraperAPI in einen Agenten oder eine App integrieren, den MCP-Server für Claude Code oder andere LLM-Tools einrichten, das richtige ScraperAPI-Produkt auswählen oder einen API-Schlüssel erhalten. Auslöser für: „Wie verwende ich ScraperAPI“, „ScraperAPI einrichten“, „ScraperAPI mit Claude verbinden“, „Welches ScraperAPI-Produkt soll ich verwenden“, „Webdaten für meinen Agenten abrufen“, „Eine Website in meiner App scrapen“, „Web-Scraping zu meinem Projekt hinzufügen“, „ScraperAPI wird gestartet“. Leiten Sie nach dem Lesen zu dem engeren Skill weiter, der den ausgewählten Pfad besitzt.
Hinweis: Überträgt vom Benutzer bereitgestellte Abfragen, URLs und Inhalte an ScraperAPI.
