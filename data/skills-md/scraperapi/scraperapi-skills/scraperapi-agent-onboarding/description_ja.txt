ScraperAPI を初めて使用するエージェントと開発者のためのエントリ ポイント。 ScraperAPI をエージェントまたはアプリに統合するとき、Claude Code または他の LLM ツール用に MCP サーバーを設定するとき、適切な ScraperAPI 製品を選択するとき、または API キーを取得するときに、最初にお読みください。トリガー: 「ScraperAPI の使用方法」、「ScraperAPI をセットアップする」、「ScraperAPI を Claude に接続する」、「どの ScraperAPI 製品を使用すればよいか」、「エージェント用の Web データを取得する」、「アプリで Web サイトをスクレイピングする」、「プロジェクトに Web スクレイピングを追加する」、「ScraperAPI を開始する」。読み取った後、選択したパスを所有するより狭いスキルにルーティングします。
注: ユーザーが指定したクエリ、URL、およびコンテンツを ScraperAPI に送信します。
