قم بإجراء تدقيق شامل لتحسين محركات البحث (SEO) باستخدام أدوات SERP المباشرة وأدوات الكشط الخاصة بـ ScraperAPI - دون الحاجة إلى أي إعداد. استخدم هذه المهارة عندما يريد المستخدم: تدقيق تحسين محركات البحث لموقع ويب، أو فهم سبب عدم تصنيف الصفحة، أو التحقق من صحة تحسين محركات البحث، أو تحليل تصنيفات الكلمات الرئيسية، أو المقارنة مع المنافسين في نتائج البحث، أو العثور على فجوات المحتوى، أو مراجعة الإشارات الموجودة على الصفحة (العناوين، التعريف، العناوين، المخطط)، أو تشخيص انخفاض حركة المرور، أو التحقق من الفهرسة، أو الحصول على توصيات تحسين محركات البحث ذات الأولوية. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "لماذا لا أظهر على Google"، أو "انخفضت حركة المرور الخاصة بي"، أو "كيف أرتب لـ X"، أو "ما الخطأ في تحسين محركات البحث الخاصة بي"، أو "فحص تحسين محركات البحث"، أو "مراجعة تحسين محركات البحث". تعمل هذه المهارة بشكل غير تقليدي — فهي تستخدم أدوات ScraperAPI MCP المتصلة بالفعل بهذه الجلسة، دون الحاجة إلى إعداد مفتاح CLI أو API.
ملاحظة: ينقل الاستعلامات التي يقدمها المستخدم وعناوين URL والمحتوى إلى ScraperAPI.
