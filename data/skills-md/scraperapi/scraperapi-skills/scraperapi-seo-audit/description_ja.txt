ScraperAPI のライブ SERP およびスクレイピング ツールを使用して包括的な SEO 監査を実行します。セットアップは必要ありません。 Web サイトの SEO を監査する、ページがランキングされない理由を理解する、SEO の健全性をチェックする、キーワードのランキングを分析する、検索結果で競合他社と比較する、コンテンツのギャップを見つける、ページ上のシグナル (タイトル、メタ、見出し、スキーマ) を確認する、トラフィックの減少を診断する、インデックス作成をチェックする、優先順位の高い SEO の推奨事項を取得するなど、ユーザーが望むときにこのスキルを使用します。また、ユーザーが「なぜ Google に表示されないのですか」、「トラフィックが減少しました」、「X にランクインするにはどうすればよいですか」、「SEO のどこが悪いのですか」、「SEO チェック」、または「SEO レビュー」などの発言をしたときにもトリガーされます。このスキルはすぐに使用できます。このセッションにすでに接続されている ScraperAPI MCP ツールを使用し、CLI や API キーのセットアップは必要ありません。
注: ユーザーが指定したクエリ、URL、およびコンテンツを ScraperAPI に送信します。
