Exécutez un audit SEO complet à l’aide des outils SERP et scraping en direct de ScraperAPI – aucune configuration n’est requise. Utilisez cette compétence chaque fois que l'utilisateur souhaite : auditer le référencement d'un site Web, comprendre pourquoi une page n'est pas classée, vérifier la santé du référencement, analyser le classement des mots clés, comparer avec les concurrents dans les résultats de recherche, trouver des lacunes dans le contenu, examiner les signaux sur la page (titres, méta, titres, schéma), diagnostiquer une baisse de trafic, vérifier l'indexation ou obtenir des recommandations de référencement prioritaires. Déclenchez également lorsque l'utilisateur dit des choses telles que "pourquoi est-ce que je n'apparais pas sur Google", "mon trafic a chuté", "comment puis-je me classer pour X", "qu'est-ce qui ne va pas avec mon référencement", "vérification SEO" ou "révision SEO". Cette compétence fonctionne immédiatement : elle utilise les outils ScraperAPI MCP déjà connectés à cette session, sans qu'aucune configuration de clé CLI ou API ne soit nécessaire.
Remarque : transmet les requêtes, les URL et le contenu fournis par l'utilisateur à ScraperAPI.
