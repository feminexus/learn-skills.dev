Referencia de uso del producto para la herramienta de línea de comandos oficial ScraperAPI (`sapi`, distribuida como `scraperapi-cli`). Utilice esta habilidad siempre que el usuario quiera extraer, ejecutar trabajos asíncronos, recuperar datos estructurados, administrar rastreos, verificar créditos de cuentas o impulsar proyectos de DataPipeline desde una terminal o un script de shell; en cualquier lugar, una sola línea es más conveniente que escribir código SDK. Cubre la instalación, el orden de resolución de autenticación, todos los comandos de nivel superior (`scrape`, `cost`, `jobs`, `structured`, `crawler`, `pipeline`, `account`, `config`, `init`), comportamiento JSON/piping, verificaciones de costos previas al vuelo y recetas de shell comunes.
