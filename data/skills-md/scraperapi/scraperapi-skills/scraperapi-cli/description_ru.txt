Справочник по использованию продукта для официального инструмента командной строки ScraperAPI («sapi», распространяется как Scraperapi-cli). Используйте этот навык всякий раз, когда пользователь хочет выполнить очистку, выполнить асинхронные задания, получить структурированные данные, управлять сканированием, проверить кредиты на счете или запустить проекты DataPipeline из терминала или сценария оболочки — везде, где однострочный код удобнее, чем написание кода SDK. Запуск по: «очистить этот URL-адрес с терминала», «использовать sapi для получения X», «ScraperAPI CLI», «ScraperAPI из bash», «sapi Scraping», «стоимость sapi», «sapi jobs», «sapi структурированный Amazon», «перенаправить ScraperAPI в jq», «оболочка однострочника для очистки Y», «очистить из Makefile / cron / CI», «проверить мои кредиты ScraperAPI из командная строка", "отправить 10 000 URL-адресов пакетом из файла". Охватывает установку, порядок разрешения аутентификации, каждую команду верхнего уровня (`scrape`, `cost`, `jobs`, `structured`, `crawler`, `pipeline`, `account`, `config`, `init`), поведение JSON/конвейера, предварительные проверки стоимости и общие рецепты оболочки.
Примечание. Передаёт пользовательские запросы, URL-адреса и контент в ScraperAPI.
