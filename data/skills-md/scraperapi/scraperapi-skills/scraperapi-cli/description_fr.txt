Utilisez cette compétence chaque fois que l'utilisateur souhaite gratter, exécuter des tâches asynchrones, récupérer des données structurées, gérer des analyses, vérifier les crédits de compte ou piloter des projets DataPipeline à partir d'un terminal ou d'un script shell - partout où une seule ligne est plus pratique que d'écrire du code SDK. Couvre l'installation, l'ordre de résolution d'authentification, chaque commande de niveau supérieur (`scrape`, `cost`, `jobs`, `structured`, `crawler`, `pipeline`, `account`, `config`, `init`), le comportement JSON/piping, les vérifications des coûts avant le vol et les recettes shell courantes.
