Автономный агент веб-исследований — задает исследовательский вопрос, использует ScraperAPI для обнаружения и очистки соответствующих источников, загружает контент в виде файловых артефактов в API Anthropic Files, а затем передает все Клоду для синтеза в цитируемый исследовательский отчет. Все в одном потоке. Используйте, когда пользователь просит: «изучите для меня X и дайте мне процитированный отчет», «изучите Y онлайн и подведите итог тому, что вы найдете», «сделайте глубокое погружение в Z, используя реальные веб-источники», «найдите информацию о X на нескольких веб-сайтах и ​​процитируйте свои источники», «запустите исследовательский агент Scraperapi по этой теме». Создает структурированный отчет об уценке со встроенными цитатами и нумерованным списком источников. Вызов всякий раз, когда пользователю нужно веб-исследование из нескольких источников, требующее очистки реальных страниц, а не просто ответа по памяти.
Примечание. Передаёт пользовательские запросы, URL-адреса и контент в ScraperAPI; загружает очищенный контент в API Anthropic Files.
