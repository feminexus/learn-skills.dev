自律型 Web リサーチ エージェント — リサーチの質問を受け取り、ScraperAPI を使用して関連するソースを検出およびスクレイピングし、コンテンツをファイル アーティファクトとして Anthropic Files API にアップロードし、引用されたリサーチ レポートに合成するためにすべてを Claude にフィードします。すべてを 1 つの流れにまとめます。ユーザーが「X を調査して引用レポートを提供してください」、「Y をオンラインで調査し、得られた内容を要約してください」、「実際の Web ソースを使用して Z について詳しく調査してください」、「複数の Web サイトから X に関する情報を検索し、ソースを引用してください」、「このトピックに関して Scraperapi リサーチ エージェントを実行してください」と要求する場合に使用します。インライン引用と番号付きソースリストを含む構造化されたマークダウンレポートを作成します。ユーザーが単に記憶から回答するのではなく、実際のページをスクレイピングする必要があるマルチソース Web リサーチを必要とするときにいつでも呼び出します。
注: ユーザーが指定したクエリ、URL、およびコンテンツを ScraperAPI に送信します。スクレイピングしたコンテンツを Anthropic Files API にアップロードします。
