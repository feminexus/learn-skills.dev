Autonomer Web-Recherche-Agent – ​​nimmt eine Forschungsfrage auf, verwendet ScraperAPI, um relevante Quellen zu entdecken und zu crawlen, lädt Inhalte als Dateiartefakte auf die Anthropic Files API hoch und leitet alles dann an Claude zur Synthese in einem zitierten Forschungsbericht weiter. Alles in einem Fluss. Verwenden Sie diese Option, wenn der Benutzer Folgendes fragt: „Recherchieren Sie Erstellt einen strukturierten Markdown-Bericht mit Inline-Zitaten und einer nummerierten Quellenliste. Rufen Sie es immer dann auf, wenn der Benutzer eine Webrecherche aus mehreren Quellen wünscht, die das Scrapen echter Seiten und nicht nur das Beantworten aus dem Gedächtnis erfordert.
Hinweis: Überträgt vom Benutzer bereitgestellte Abfragen, URLs und Inhalte an ScraperAPI; lädt gescrapte Inhalte in die Anthropic Files API hoch.
