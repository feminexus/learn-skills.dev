자율적 웹 연구 에이전트 — 연구 질문을 받고, ScraperAPI를 사용하여 관련 소스를 검색 및 스크랩하고, 콘텐츠를 Anthropic Files API에 파일 아티팩트로 업로드한 다음, 인용된 연구 보고서에 합성하기 위해 모든 것을 Claude에 제공합니다. 하나의 흐름으로 모두 가능합니다. 사용자가 "나를 위해 X를 조사하고 인용 보고서를 제공합니다.", "온라인으로 Y를 조사하고 찾은 내용을 요약합니다.", "실제 웹 소스를 사용하여 Z에 대해 심층 분석합니다.", "여러 웹사이트에서 X에 대한 정보를 찾고 소스를 인용합니다.", "이 주제에 대해 scraperapi 연구 에이전트를 실행합니다."라고 요청할 때 사용합니다. 인라인 인용 및 번호가 매겨진 소스 목록이 포함된 구조화된 마크다운 보고서를 생성합니다. 사용자가 단순히 메모리에서 응답하는 것이 아니라 실제 페이지를 스크랩해야 하는 다중 소스 웹 조사를 원할 때마다 호출합니다.
참고: 사용자가 제공한 쿼리, URL 및 콘텐츠를 ScraperAPI로 전송합니다. 스크랩한 콘텐츠를 Anthropic Files API에 업로드합니다.
