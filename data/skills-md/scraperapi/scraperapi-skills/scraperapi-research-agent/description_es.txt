Agente de investigación web autónomo: toma una pregunta de investigación, utiliza ScraperAPI para descubrir y extraer fuentes relevantes, carga contenido como artefactos de archivos en la API de Anthropic Files y luego envía todo a Claude para que lo sintetice en un informe de investigación citado. Todo en un solo flujo. Úselo cuando el usuario pregunte: "investiga X por mí y dame un informe citado", "investiga Y en línea y resume lo que encuentres", "profundiza en Z utilizando fuentes web reales", "busca información sobre X en varios sitios web y cita tus fuentes", "ejecuta el agente de investigación scraperapi sobre este tema". Produce un informe de rebajas estructurado con citas en línea y una lista de fuentes numerada. Invocar siempre que el usuario desee una investigación web de múltiples fuentes que requiera extraer páginas reales, no solo responder de memoria.
Nota: Transmite consultas, URL y contenido proporcionados por el usuario a ScraperAPI; carga contenido extraído a la API de Anthropic Files.
