Utilisez cette compétence chaque fois que l'utilisateur souhaite vérifier, suivre ou être alerté des prix des produits sur Amazon, Walmart ou via Google Shopping. Déclenchez sur : "surveiller le prix de ce produit Amazon", "le prix a-t-il baissé sur [URL Walmart] ?", "suivre ces ASIN", "comparer les prix d'aujourd'hui avec ceux de la semaine dernière", "alertez-moi si [produit] descend en dessous de X $", "quel est le prix actuel de [produit] ?", "vérifiez ma liste de surveillance des prix", "grattez le prix de [URL]". Accepte les ASIN, les URL de produits Amazon/Walmart ou les requêtes de produits en texte libre pour Google Shopping. Lit un fichier JSON de référence facultatif pour détecter les changements, récupère les prix en direct via les points de terminaison structurés de ScraperAPI et signale les augmentations, les diminutions, les réapprovisionnements et les transitions en rupture de stock dans un rapport de modification structuré.
Remarque : transmet les requêtes, les URL et le contenu fournis par l'utilisateur à ScraperAPI.
