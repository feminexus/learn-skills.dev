每當用戶想要檢查、追蹤亞馬遜、沃爾瑪或透過 Google 購物上的產品價格或收到有關產品價格的提醒時，請使用此技能。觸發條件：「監控此亞馬遜產品的價格」、「[Walmart URL] 上的價格下降了嗎？」、「追蹤這些 ASIN」、「將今天的價格與上週進行比較」、「如果 [產品] 低於 X 美元，則提醒我」、「[產品] 的當前價格是多少？」、「檢查我的價格監視清單」、「抓取 [URL] 的價格」。接受 ASIN、亞馬遜/沃爾瑪產品 URL 或 Google 購物的自由文字產品查詢。讀取可選的基線 JSON 檔案以偵測更改，透過 ScraperAPI 的結構化端點取得即時價格，並在結構化變更報告中報告增加、減少、補貨和缺貨轉換。
注意：將使用者提供的查詢、URL 和內容傳輸到 ScraperAPI。
