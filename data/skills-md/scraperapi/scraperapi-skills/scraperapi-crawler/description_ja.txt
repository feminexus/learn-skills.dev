ScraperAPI の Crawler の製品使用リファレンス — リンクを自動的にたどることで、サイト全体またはセクションをクロールします。ユーザーが事前に URL を知らなくても、サイトの多くのページからデータを抽出する必要がある場合に相談してください。ユーザーが「ScraperAPI を使用して Web サイト全体をクロールする」、「ドメイン上のすべてのページをスクレイピングする」、「リンクをたどって各ページをスクレイピングする」、「ScraperAPI クローラー API の使用方法」、「サイト マップをスクレイピングする」、「サイト上のすべての製品ページからデータを抽出する」、「ScraperAPI クローラー ジョブ API」を尋ねる場合に使用します。ジョブの作成、URL 正規表現パターン、深さと予算、ページごとのスクレイピング パラメーター、ステータス ポーリング、Webhook、スケジューリング、クレジット コストについて説明します。また、ユーザーがサイト全体のスクレイパーを構築し、どの ScraperAPI 製品を使用するかを尋ねるときにも呼び出します。
注: ユーザーが指定したクエリ、URL、およびコンテンツを ScraperAPI に送信します。
