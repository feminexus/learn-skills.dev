Référence d'utilisation du produit pour le robot d'exploration de ScraperAPI : explorez automatiquement un site ou une section entière en suivant les liens. Consultez lorsque l'utilisateur a besoin d'extraire des données de plusieurs pages d'un site sans connaître les URL au préalable. À utiliser lorsque l'utilisateur demande : "explorer un site Web entier avec ScraperAPI", "gratter toutes les pages d'un domaine", "suivre les liens et gratter chaque page", "comment utiliser l'API du robot d'exploration ScraperAPI", "gratter un plan du site", "extraire les données de chaque page de produit d'un site", "API de travail d'exploration ScraperAPI". Couvre la création de tâches, les modèles d'expression régulière d'URL, la profondeur par rapport au budget, les paramètres de scraping par page, les sondages d'état, les webhooks, la planification et les coûts de crédit. Invoquez également lorsque l'utilisateur crée un scraper à l'échelle du site et demande quel produit ScraperAPI utiliser.
Remarque : transmet les requêtes, les URL et le contenu fournis par l'utilisateur à ScraperAPI.
