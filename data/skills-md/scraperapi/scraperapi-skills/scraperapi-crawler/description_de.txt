Produktnutzungsreferenz für den Crawler von ScraperAPI – Crawlen Sie eine gesamte Website oder einen gesamten Abschnitt, indem Sie Links automatisch folgen. Konsultieren Sie, wenn der Benutzer Daten von vielen Seiten einer Website extrahieren muss, ohne die URLs im Voraus zu kennen. Verwenden Sie diese Option, wenn der Benutzer fragt: „Eine gesamte Website mit ScraperAPI crawlen“, „Alle Seiten einer Domain scannen“, „Links folgen und jede Seite scrapen“, „Wie verwende ich die ScraperAPI-Crawler-API“, „Eine Sitemap scrapen“, „Daten von jeder Produktseite einer Website extrahieren“, „ScraperAPI-Crawler-Job-API“. Deckt Joberstellung, URL-Regex-Muster, Tiefe vs. Budget, Scraping-Parameter pro Seite, Statusabfrage, Webhooks, Terminplanung und Kreditkosten ab. Wird auch aufgerufen, wenn der Benutzer einen standortweiten Scraper erstellt und fragt, welches ScraperAPI-Produkt verwendet werden soll.
Hinweis: Überträgt vom Benutzer bereitgestellte Abfragen, URLs und Inhalte an ScraperAPI.
