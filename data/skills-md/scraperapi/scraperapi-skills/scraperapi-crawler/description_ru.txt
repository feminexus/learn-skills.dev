Справочник по использованию продукта для сканера ScraperAPI — сканируйте весь сайт или раздел, автоматически переходя по ссылкам. Проконсультируйтесь, когда пользователю необходимо извлечь данные со многих страниц сайта, не зная заранее URL-адресов. Используйте, когда пользователь спрашивает: «сканировать весь веб-сайт с помощью ScraperAPI», «очистить все страницы в домене», «перейти по ссылкам и очистить каждую страницу», «как использовать API-сканер ScraperAPI», «очистить карту сайта», «извлечь данные из каждой страницы продукта на сайте», «API задания сканера ScraperAPI». Охватывает создание рабочих мест, шаблоны регулярных выражений URL-адресов, глубину и бюджет, параметры очистки страниц, опрос статуса, веб-перехватчики, планирование и стоимость кредитов. Также вызывается, когда пользователь создает парсер для всего сайта и спрашивает, какой продукт ScraperAPI использовать.
Примечание. Передаёт пользовательские запросы, URL-адреса и контент в ScraperAPI.
