Создавайте и внедряйте веб-скраперы с помощью ScraperAPI. Используйте этот навык всякий раз, когда пользователь просит создать, написать, создать или внедрить парсер или хочет запустить код, извлекающий данные с веб-сайта. Триггер: «создайте мне парсер для [веб-сайта]», «напишите парсер, который извлекает страницы товаров с [сайта электронной торговли]», «Мне нужно парсить [данные] с [веб-сайта]», «создайте скрипт, который извлекает [поля] из [URL]», «помогите мне парсить [веб-сайт] — мне нужны [поля]», «напишите код для парсинга [веб-сайта]», «создайте скрипт, который парсит [веб-сайт]», «внедрите парсер для [URL]». Направляет архитектурные решения (структурированная конечная точка или необработанный HTML, рендеринг JS, уровень прокси, синхронизация или асинхронный пакет), а затем генерирует полный работоспособный скрипт Python или Node.js с логикой повтора, обработкой ошибок, нумерацией страниц и оценкой кредитоспособности.
Примечание. Передаёт пользовательские запросы, URL-адреса и контент в ScraperAPI.
