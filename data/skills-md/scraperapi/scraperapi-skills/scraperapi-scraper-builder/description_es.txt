Cree e implemente raspadores web utilizando ScraperAPI. Utilice esta habilidad siempre que el usuario solicite crear, escribir, crear o implementar un raspador, o desee un código ejecutable que extraiga datos de un sitio web. Activar: "constrúyeme un raspador para [sitio web]", "escribe un raspador que obtenga páginas de productos de [sitio de comercio electrónico]", "Necesito raspar [datos] de [sitio web]", "crear un script que extraiga [campos] de [URL]", "ayúdame a raspar [sitio web] - necesito [campos]", "escribir código para raspar [sitio web]", "crear un script que raspe [sitio web]", "implementar un raspador para [URL]". Guía las decisiones arquitectónicas (punto final estructurado versus HTML sin formato, representación JS, nivel de proxy, sincronización versus lote asíncrono) y luego genera un script Python o Node.js ejecutable completo con lógica de reintento, manejo de errores, paginación y estimación de crédito.
Nota: Transmite consultas, URL y contenido proporcionados por el usuario a ScraperAPI.
