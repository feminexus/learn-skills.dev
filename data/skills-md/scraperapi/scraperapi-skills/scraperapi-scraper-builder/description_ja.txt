ScraperAPI を使用して Web スクレイパーを構築および実装します。ユーザーがスクレイパーの構築、作成、作成、実装を要求する場合、または Web サイトからデータを抽出する実行可能なコードが必要な場合は常に、このスキルを使用します。トリガー: 「[ウェブサイト] 用のスクレイパーを構築してください」、「[e コマース サイト] から商品ページを取得するスクレイパーを作成します」、「[ウェブサイト] から [データ] をスクレイピングする必要があります」、「[URL] から [フィールド] を抽出するスクリプトを作成します」、「[ウェブサイト] のスクレイピングを手伝ってください — [フィールド] が必要です」、「[ウェブサイト] をスクレイピングするコードを作成します」、「[ウェブサイト] をスクレイピングするスクリプトを作成します」、 「[URL] のスクレイパーを実装します。」アーキテクチャ上の決定 (構造化エンドポイントと生の HTML、JS レンダリング、プロキシ層、同期バッチと非同期バッチ) をガイドし、再試行ロジック、エラー処理、ページネーション、クレジット推定を備えた完全な実行可能な Python または Node.js スクリプトを生成します。
注: ユーザーが指定したクエリ、URL、およびコンテンツを ScraperAPI に送信します。
