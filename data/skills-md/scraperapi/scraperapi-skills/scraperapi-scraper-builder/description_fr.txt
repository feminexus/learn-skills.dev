Créez et implémentez des web scrapers à l'aide de ScraperAPI. Utilisez cette compétence chaque fois que l'utilisateur demande à créer, écrire, créer ou implémenter un scraper, ou souhaite obtenir un code exécutable qui extrait les données d'un site Web. Déclenchez sur : "créez-moi un scraper pour [site Web]", "écrivez un scraper qui récupère les pages de produits de [site de commerce électronique]", "Je dois récupérer [données] de [site Web]", "créer un script qui extrait [champs] de [URL]", "aidez-moi à gratter [site Web] - j'ai besoin de [champs]", "écrire du code pour gratter [site Web]", "créer un script qui gratte [site Web]", "implémenter un scraper pour [URL]". Guide les décisions architecturales (point de terminaison structuré par rapport au HTML brut, rendu JS, niveau proxy, synchronisation par rapport au lot asynchrone), puis génère un script Python ou Node.js exécutable complet avec logique de nouvelle tentative, gestion des erreurs, pagination et estimation du crédit.
Remarque : transmet les requêtes, les URL et le contenu fournis par l'utilisateur à ScraperAPI.
