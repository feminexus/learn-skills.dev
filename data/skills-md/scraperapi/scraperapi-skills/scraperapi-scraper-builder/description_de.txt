Erstellen und implementieren Sie Web-Scraper mit ScraperAPI. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Scraper erstellen, schreiben, erstellen oder implementieren möchte oder ausführbaren Code möchte, der Daten von einer Website extrahiert. Auslösen bei: „Erstellen Sie mir einen Scraper für [Website]“, „Schreiben Sie einen Scraper, der Produktseiten von [E-Commerce-Website] abruft“, „Ich muss [Daten] von [Website] scrapen“, „Erstellen Sie ein Skript, das [Felder] aus [URL] extrahiert“, „Helfen Sie mir beim Scrapen von [Website] – ich brauche [Felder]“, „Schreiben Sie Code zum Scrapen von [Website]“, „Erstellen Sie ein Skript, das [Website] scrapen kann“, „Implementieren Sie einen Scraper für [URL]“. Leitet Architekturentscheidungen (strukturierter Endpunkt vs. rohes HTML, JS-Rendering, Proxy-Ebene, synchronisierter vs. asynchroner Batch) und generiert dann ein vollständig ausführbares Python- oder Node.js-Skript mit Wiederholungslogik, Fehlerbehandlung, Paginierung und Kreditschätzung.
Hinweis: Überträgt vom Benutzer bereitgestellte Abfragen, URLs und Inhalte an ScraperAPI.
