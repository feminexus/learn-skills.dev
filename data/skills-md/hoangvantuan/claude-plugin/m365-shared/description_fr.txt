CLI pour Microsoft 365 (m365) : modèles partagés pour l'authentification, l'installation, le formatage de sortie et les indicateurs communs. À utiliser lorsque l'utilisateur mentionne « connexion m365 », « configuration m365 », « installation Microsoft 365 », « statut m365 », « contact avec Microsoft » ou lorsqu'une autre compétence m365-* nécessite une référence d'authentification/modèle commun.
