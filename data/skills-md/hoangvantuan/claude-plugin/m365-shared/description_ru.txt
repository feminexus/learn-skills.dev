CLI для Microsoft 365 (m365): общие шаблоны для аутентификации, установки, форматирования вывода и общие флаги. Используйте, когда пользователь упоминает «Вход в m365», «Настройка m365», «Подключение к Microsoft 365», «Состояние m365», «Kết nối Microsoft» или когда для другого навыка m365-* требуется ссылка на аутентификацию или общий шаблон.
