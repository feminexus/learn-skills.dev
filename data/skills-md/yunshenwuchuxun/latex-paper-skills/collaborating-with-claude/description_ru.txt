Используйте интерфейс командной строки Claude Code в качестве второго пилотного проекта глубинного анализа для процесса «бумага с нуля». Основная роль: сжатие дерева утверждений, обнаружение логических дыр, аудит достаточности доказательств и проверка/эмпирическое решение о маршрутизации. Также поддерживает совместную работу над общим кодом в качестве резерва.
