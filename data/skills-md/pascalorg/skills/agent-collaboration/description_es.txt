Orquestación de agentes multimodelo utilizando agentes especializados para planificación, codificación, investigación, matemáticas y ciencias, análisis visual y revisión adversaria. Úselo cuando las tareas sean lo suficientemente complejas como para beneficiarse de las fortalezas de diferentes modelos, cuando desee una revisión contradictoria para detectar puntos ciegos o cuando coordine flujos de trabajo de varios pasos entre las funciones de los agentes. Se activa en proyectos complejos, tareas de varios pasos, decisiones de arquitectura o cuando se solicita explícitamente.
